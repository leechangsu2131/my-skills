## #192 받아쓰기 사전 화면 칸
**확인한 것**
- 시험 Python 65(`test_stt_words_api`·`test_stt_words`·`test_transcribe`)·Node 9 통과.
- 읽기는 `transcribe.load_words` 를 그대로 써서 받아쓰기가 읽는 모양과 같음. 저장은 임시 파일 → `os.replace` 로 통째 바꿔 쓰기(`write_json`), 모양·개수·길이 검사가 쓰기 **앞**에 있어 틀리면 파일이 그대로. POST 는 기존 `_trusted()`(다른 사이트 요청 403)를 그대로 거침.
- 사전 파일은 데이터 폴더에만(저장소엔 예시만). 개인정보·비밀값 모양 없음.
- 직접 눌러 본 저장 입력: 빈 값·같은 말(`a→a`)은 조용히 뺌, 숫자·None·공백 낱말 정리됨, `words` 가 글이면 `ValueError`("사전 모양이 잘못됐어요"), 같은 틀린 말이 두 번이면 뒤가 이김 — 모두 의도대로.

**🟡 알아 둘 점**
1. **저장 안 한 글이 접었다 펴면 사라짐**: 칸을 펼칠 때마다 서버 값으로 두 칸을 덮어씀(`toggle` → `sttFill`). 사전을 고치다 실수로 칸을 접으면 저장 전 글이 날아감. 처음 한 번만 채우거나 저장한 값이 바뀐 뒤에만 채우면 해결.
2. **"틀린 말 →"(오른쪽 비움)은 '지우기'로 저장됨**: 시험으로 확인(`교한을 봅니다 교한` → `을 봅니다`). 의도한 기능이면 칸 안내 글에 한 줄(예: "오른쪽을 비우면 그 말을 지워요")이 있으면 실수로 비운 줄을 막을 수 있음.
- (이미 있던 일) 본문이 JSON 배열이면 `body.get` 에서 `AttributeError` — 다른 라우트도 같은 꼴이라 이 PR 의 문제는 아님.
