## #209 `speaker_level.py`
- 시험 42 통과. 1초마다 `시각,dB` 한 줄만 적음 — 소리 자체는 저장·전송하지 않음(코드로 확인: `rms_db` 만 파일에 감). 짧은 알림음은 `MIN_VIDEO_SECONDS` 로 빠지고, 장면 사이 조용한 부분은 `JOIN_GAP_SECONDS` 로 이어 붙음. 기록이 비는 시간(PC 잠듦)은 끊김으로 봄 — 안전한 쪽.
- **🟡 ① 장치를 못 읽으면 약 10초 뒤 영구 정지**: `run_loop` 가 연달아 10번(실제로는 `on_error` 의 1초 쉼 때문에 10초) 실패하면 멈추고 아무도 다시 켜지 않음. 블루투스·이어폰 연결을 바꾸는 사이에 걸릴 수 있음(직접 12번 실패로 재현). #208 처럼 "몇 번까지는 다시 켠다"를 두거나 멈춘 일을 상태 화면(`status`)에 남기면 좋음.
- **🟡 ② 기본 스피커를 시작할 때 한 번만 잡음**: `open_loopback_reader` 가 켤 때의 기본 스피커 루프백을 계속 씀. 수업 중 스피커↔이어폰을 바꾸면 새 장치 소리를 놓침(추정 — 교사 PC 에서 확인). 그리고 TASKS T121 의 "T117 상주 녹음과 **같이 켜지게**"는 #209 에는 없음(그때 T117 이 없었음) → #208 이 합쳐진 뒤 `day_recorder.start/stop` 이 `speaker_level.start/stop` 도 불러 주는 작은 후속(제가 이어서 할 수 있음)이 필요.
- 확인 필요(추정): 윈도우 루프백은 장치가 아무 소리도 안 낼 때 기록 줄 사이가 벌어질 수 있음 → 이 코드는 기록 없는 시간을 '소리 없음'으로 봐 결과는 같지만 `status` 의 "마지막으로 적은 때"가 오래돼 보일 수 있음. `LOUD_DB` 값(-45)도 교실 PC 에서 영상을 틀어 보고 맞출 것.
