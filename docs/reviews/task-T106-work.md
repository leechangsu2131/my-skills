| 화면 너비 | ◀ 이전 | 수업 시작 | 다음 ▶ |

| 1366px | 0% | 0% | 60% |
| 640px | 0% | 67% | 100% |
| 375px | 100% | 100% | 100% |

일반 화면도 맨 아래까지 내리면 640px 에서 `timerReset`·🛠 교실 도구, 375px 에서 타이머·나이스·하이클래스·진도 미루기 단추가 칸 밑에 깔려 더 내릴 수 없다.
