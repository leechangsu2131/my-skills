## 🟡 작은 것

1. 시험이 못 잡은 변경 2개: ① `os.replace(tmp, path)` → `tmp.rename(path)` — 리눅스에서는 같은 동작이라 못 잡지만 **윈도우에서는 파일이 이미 있으면 실패**하므로 교사 PC 에서 두 번째 저장이 되는지 확인 필요(`os.replace` 가 맞음, 지금 코드 그대로 두면 됨). ② 제목 길이 60자 제한 — 긴 제목 시험이 없음.
2. 윈도우 예약 이름(`con`·`nul`·`prn` 등)은 `slug()` 가 거르지 않아 그 제목으로 만들면 파일 저장이 실패할 수 있음(추정, 오류는 서버가 400 으로 알려 줌). 실제로 쓸 일은 거의 없음.
3. 표를 두 탭에서 동시에 누르면 나중 저장이 앞 저장을 덮을 수 있음(읽고-고치고-쓰기). 교사 한 명이 한 PC 로 쓰는 앱이라 위험은 낮음.
4. `roster.txt` 이름이 화면에 나오는 것은 의도이나, 점검표에 "명단 있는 PC 화면 공유(교실 큰 화면)에서 이름이 보이는지" 한 줄이 있으면 좋음.
