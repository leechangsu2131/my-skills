## 🟢 알아 둘 것 (합치기를 막지 않음)
- **제목 60자 제한이 예약 이름에서는 61자**: 60자로 자른 뒤 `_` 를 붙임. `con.` + 긴 글 → 61자(`slug('con.'+'가'*100)`). 파일 이름으로는 문제없음. 시험 이름이 "제목 60자 제한"이면 이 경우는 빠져 있음.
- **윈도우 예약 이름에는 위첨자 숫자도 있음**(`COM¹`·`COM²`·`COM³`·`LPT¹…`, 마이크로소프트 문서 기억에 따른 것이라 **확인 필요**). 지금은 `com¹` 이 그대로 통과함. 제목에 그런 글자를 쓸 일은 거의 없음.
- **`con` 과 `_con` 이 같은 파일 이름**(`_con`)이 됨. 원래도 `_a` 와 `a` 는 앞의 `_` 를 지워서 같았으므로 새 문제는 아님. 같은 제목 안내("이미 있어요")가 뜰 뿐.
- 말로 \"타이머 한 시간\"·\"1시간\" 은 모양이 아니라서 조용히 무시됨(이 PR 이전과 같음). 상한이 60분이 되었으니 '한 시간'을 알아듣게 할지는 나중에 교사가 정할 일.
