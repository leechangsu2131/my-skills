## 🟡

1. **한 채널(`channels=1`) 녹음은 윈도우에서 값이 엉터리일 수 있음 (라이브러리 설명서)**: [SoundCard README](https://github.com/bastibe/SoundCard/blob/master/README.rst) 의 알려진 문제에 "Windows/WASAPI currently records garbage if you record only a single channel." 이라고 적혀 있음. `open_loopback_reader` 가 `channels=1` 을 씀. 맞다면 조용해도 '소리 남'으로 잡혀 수업 말이 영상 구간이 되거나 그 반대가 됨. 지금 설치판에서도 그런지는 **확인 필요**.
   - 고치는 법: `channels=2` 로 받고 그대로 `reshape(-1)` 해서 크기를 재면 됨(`rms_db` 는 그대로, 시험의 `rec_args` 기대값만 바뀜).
2. **남은 `speaker_level.pid` (가짜로 재현)**: 끄지 않고 PC 를 끈 뒤 같은 번호를 다른 프로그램이 받으면 `start` 는 "이미 켜져 있어요."(실제로는 안 적음), `stop` 은 그 프로그램을 `taskkill /F`. PR #208 검토의 1번과 같음.
3. **영상이 아닌 PC 소리도 20초 넘으면 '영상' (재현: 30초 소리 → 구간)**: 활동 배경 음악·타이머 음악, 이어폰으로 혼자 듣는 소리(마이크에는 안 들어감)도 같음. 아직 표시만 하지만, 다음 단계 ③(`transcribe.py --skip-video`)에서 이 구간을 **빼면 그동안의 선생님·학생 말도 빠짐**. ③ 은 '지우기'보다 표에 표시하고 교사가 되살릴 수 있게 하길 권함.
4. **`start` 의 "켰어요"는 확인 전 말 (코드 읽음)**: 패키지는 있는데 장치를 열다 실패하면 본체가 조용히 끝남(출력 버림). 몇 초 뒤 첫 줄이 적혔는지 확인하거나 오류를 파일에 남기기.
