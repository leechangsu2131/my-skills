## 🔴 1. `남은 시간 …분 …초` 모양을 못 읽음 (재현)

| 화면 글(가정) | 읽은 결과 |
|---|---|
| `남은 시간 59:12` | 3552초 ✅ |
| `남은 시간 59분 12초` | 못 읽음 |
| `남은시간 4분` | 못 읽음 |
| `로그아웃까지 45초 남음` | 못 읽음 |
| `남은 시간 1시간 2분` | 못 읽음 |

- 원인: `parseRemainingSeconds` 의 세 번째 정규식은 시·분·초가 모두 '없어도 됨'이라, 글 맨 앞에서 빈 글자와 먼저 맞고 끝남. 숫자로 시작하는 글(`4분 남음`)만 읽힘.
- 그런데 `findRemainingSeconds` 는 "남은·세션·로그아웃" 같은 말이 든 글만 보고, 이런 말은 보통 숫자 **앞**에 옴.
- ISSUES 의 교사 PC 점검표 2번 예시 `남은시간 59분 12초`도 읽히지 않음.
- 영향: 표시는 `🟡 남은 시간을 못 읽음`, 단추를 누르지 않아 로그인이 풀림. NEIS 실제 글자 모양은 **확인 필요** — `mm:ss` 라면 동작함.
- 고치는 법 예(임시 복사본에서 확인: 위 표가 모두 읽히고 기존 시험 20개 통과):

```js
m = s.match(/(\d{1,3})\s*시간(?:\s*(\d{1,3})\s*분)?(?:\s*(\d{1,3})\s*초)?|(\d{1,3})\s*분(?:\s*(\d{1,3})\s*초)?|(\d{1,3})\s*초/);
if (m) return Number(m[1] || 0) * 3600 + Number(m[2] || m[4] || 0) * 60 + Number(m[3] || m[5] || m[6] || 0);
```

  위 표의 글자를 시험에도 넣을 것.

## 🟡

2. **시계 시각을 남은 시간으로 읽음 (재현)**: `마지막 접속 시간 03:10` → 190초(5분 이하라 '연장'을 누르려 함). `접속시간 2026-11-28 04:05:00` → 14700초(진짜 타이머와 함께 있으면 값이 둘이라 **영영 안 누름**). `KEYWORDS` 의 `로그인 시간|접속 시간`을 빼거나, 날짜가 함께 있는 글은 건너뛰기.
3. **시간이 팝업에서만 보이면 4번째부터 멈춤 (함수로 재현)**: 누른 횟수는 5분 **넘는** 시간을 읽어야 0으로 돌아감. 누른 뒤 팝업이 닫혀 시간을 못 읽으면 횟수가 쌓여 3번 뒤 `눌렀는데 안 늘어남`에서 새로 고칠 때까지 안 누름. NEIS 가 항상 시간을 보여 주는지 **확인 필요**. 못 읽는 상태가 한동안 이어지면 횟수를 되돌리는 방법이 있음.
4. **끄기가 다른 탭에 안 전해짐 (코드 읽음)**: 켜짐/멈춤을 처음 한 번만 읽고 `chrome.storage.onChanged` 를 듣지 않음. NEIS 탭이 둘이면 한쪽에서 멈춰도 다른 탭은 계속 누름.
5. **확장을 끄거나 다시 불러와도 옛 탭은 계속 누름 (추정)**: 15초 반복이 `chrome.runtime.id` 를 확인하지 않음. 교사가 "껐다"고 생각해도 새로 고치기 전까지 로그인이 유지될 수 있음 — 컴퓨터를 비울 때 중요.
6. **'연장' 단추가 로그인 타이머와 이어져 있지 않음 (코드 읽음)**: 화면에 글자가 `연장`·`자동연장`뿐인 단추가 하나면, 업무 화면의 다른 연장 단추(예: 기간 연장 칸의 `연장`)나 켜고 끄는 `자동연장` 스위치를 누를 수 있음(실제로 그런 단추가 있는지 **확인 필요**). `연장 근무`·`기간 연장`처럼 다른 글자가 붙은 것은 안 누름(재현). 타이머 글 가까이에 있는 단추만 고르면 안전함.
