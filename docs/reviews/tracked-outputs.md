## 스킬별 상세 확인

### classmanage-exam-grader

- ISSUES.md에는 42개 파일이 임시 답안·영역·빈 양식 디버깅 결과일 것으로 추정된다고 기록되어 있다.
- 그림 안에 학생 이름이나 답안이 있는지는 아직 확인되지 않았다.
- 교사가 로컬 PC에서 파일을 확인한 뒤, 불필요하고 학생 정보가 없다면 추적 해제와 `.gitignore` 추가를 결정해야 한다.
- 이번 작업에서는 이미지 내용을 확인하지 않았다.

### classmanage-exam-graderV2

- PDF는 원본 입력 폴더와 자동 검토 패킷 폴더에 각각 1개씩 있다.
- ISSUES.md도 학생 정보가 있는 원본인지, 가짜 시험 자료인지 확인한 뒤 처리하도록 기록한다.
- PDF 내용을 열지 않았으므로 현재는 둘 다 삭제 대상으로 정할 수 없다.

### personal-record-trade

- PDF 26개는 `data/report/`와 `docs/research/` 아래에 있다.
- ISSUES.md는 교사 확인 뒤 저장소에서 추적을 해제하고, 필요하면 로컬 데이터 폴더로 옮기는 방안을 제안한다.
- 기업·증권사 보고서는 저작권·배포 허가가 중요하다. 개인 분석용으로 보유할 필요가 있더라도 공개 저장소에 둘 수 있는지는 별도로 결정해야 한다.
- 이 스킬은 현재 보관 상태지만 PDF는 계속 Git 추적 대상이다.

### personal-youtube-gemini-kakao-automation

- 저장소 트리에서 `v/` 아래 임시 VTT 파일 2개를 확인했다.
- 스킬 문서에서 이 임시 파일을 언제 만들고 언제 지우는지 설명하지 않아 정확한 재생성·보존 필요성은 확인할 수 없다.
- 영상 출처와 자막의 저작권·보존 필요성을 교사가 확인해야 한다.

### util-school-print

- `ParameterSetObject.pdf`는 스킬 루트에 있는 PDF 한 개다.
- ISSUES.md에는 한글 인쇄 설정에서 용지 크기·방향·프린터 이름 등의 매개변수를 확인한 기록이 있다.
- PDF가 해당 설정을 추출한 원본인지, 현재도 필요한 자료인지는 파일 내용을 열지 않아 확인하지 않았다.

## 교사 확인이 필요한 결정

1. **시험지·답안 이미지**: 임시 PNG와 PDF에 학생 이름·답안이 있는지 교사 PC에서 확인할지 결정.
2. **외부 보고서**: 증권사·기업 리포트 PDF를 공개 저장소에 둘 권리가 있는지 확인.
3. **영상 자막**: VTT가 공개 가능한 영상의 자막인지, 개인 연수·저작물에서 나온 것인지 확인.
4. **인쇄 설정 PDF**: 현재 도구가 실행될 때 필요한 참고 자료인지 확인.

## 삭제 전에 알아둘 점

- 이 보고서는 삭제 권고 목록이 아니다. 모든 파일은 현재 Git에서 추적 중이며, 이번 작업자는 아무 파일도 삭제하지 않았다.
- 파일을 현재 버전에서 제거해도 이전 Git 커밋에는 내용이 남을 수 있다. 개인정보가 확인되면 단순 삭제만으로 끝나는지 별도 검토가 필요하다.
- Git 기록 재작성, 강제 푸시, 브랜치 삭제는 하지 않았다. 기록 정리가 필요하면 교사가 별도 승인·절차를 정해야 한다.
