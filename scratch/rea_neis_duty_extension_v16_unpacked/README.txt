나이스 부서 복무 달력 v1.6

수정 내용
- 조회정보 초기화 버튼을 제거했습니다.
- 대상자 설정에서 기존 이름 입력과 함께 이름(직급/직위/직종) 형식을 지원합니다.
- 예: 홍길동은 같은 이름 전체, 홍길동(7급)은 7급인 홍길동만 표시합니다.
- 직급을 지정한 대상자는 달력과 상세창에도 홍길동(7급)처럼 표시합니다.
- 괄호 안 값이 나이스 응답의 직급·직위·직종 중 하나와 일치하면, 달력에는 사용자가 입력한 값을 그대로 표시합니다.
- 같은 달에 이름은 같고 직급·직위·직종이 다른 사람이 확인되면 자동으로 구분하여 표시합니다.
- 기본값은 승인완료만 표시하며, 제어판에서 상신(진행) 건을 함께 표시할 수 있습니다.
- 상신(진행) 건은 달력과 상세창에 (결재중)으로 표시합니다.
- 제어판 상단을 끌어 원하는 위치로 이동할 수 있으며, 이동 위치를 저장합니다.
- 위치 초기화 버튼으로 제어판을 기본 위치로 되돌릴 수 있습니다.
- 월간일정에서 데이터가 바뀌지 않았는데도 이름이 반복해서 깜빡이던 현상을 수정했습니다.

사용 방법
1. 확장 프로그램 설치 또는 새로고침 후 나이스에 접속합니다.
2. 최초 1회는 나이스의 일일근무상황조회 화면에서 조회를 한 번 실행합니다.
3. 월간일정 화면으로 이동하면 저장된 조회정보를 기준으로 부서 복무 달력을 사용할 수 있습니다.
4. 다른 시도교육청 나이스에서 사용할 경우에도 해당 사이트에서 일일근무상황조회를 한 번 실행해 조회정보를 저장해야 합니다.

대상자 설정 방법
- 이름만 입력: 홍길동
- 직급·직위·직종으로 구분: 홍길동(7급), 김철수(장학관)
- 한 줄에 한 명씩 입력하거나 쉼표로 구분합니다.
- 괄호 안에는 나이스 일일근무상황조회 화면의 '직급/직위/직종'에 표시되는 값을 입력합니다.
- 같은 이름과 같은 직급·직위·직종인 직원은 현재 API 정보만으로 구분할 수 없습니다.

설치 방법
1. 기존 확장 폴더에 이 폴더의 파일을 덮어씁니다.
2. chrome://extensions 또는 edge://extensions 에서 확장 프로그램 새로고침을 누릅니다.
3. 이전 버전이 별도 확장으로 켜져 있으면 끕니다.
4. 나이스 화면을 새로고침합니다.
