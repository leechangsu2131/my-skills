# 장바구니 구입 목록 자동 기록 (admin-buying-product)

온라인 서점(교보문고 등)의 장바구니 목록을 분석하여 학교/기관의 구입 목록 엑셀 양식에 맞게 자동으로 기록하는 스킬입니다.

## ⚠️ 핵심 주의 사항 (할루시네이션 방지 로직)

장바구니 화면 캡처 **이미지**에는 글씨가 작고 흐릿하여 AI가 책 제목이나 가격을 **잘못 인식(할루시네이션)할 위험이 매우 높습니다.** (예: 표지 색상만 보고 비슷한 베스트셀러로 착각하거나, 대상 엑셀 파일명을 보고 임의의 책을 지어내는 오류)
따라서 다음 로직을 반드시 준수합니다.

### 1. 입력 방식 우선순위
- **1순위 (권장): 서점 장바구니 엑셀 다운로드 파일**
  사용자가 이미지를 주었을 경우, "이미지 인식은 오류(할루시네이션)가 발생할 수 있으므로, 가급적 교보문고 장바구니에서 제공하는 **엑셀 다운로드(예: `교보문고_장바구니_상품리스트.xlsx`)** 파일을 첨부해 주시면 가장 정확합니다"라고 안내합니다.
- **2순위: 이미지 기반 추출 및 교차 검증**
  사용자가 엑셀 파일 다운로드가 불가능하여 이미지만으로 진행해야 하는 경우, 추출한 데이터를 엑셀에 바로 기록하지 말고 **반드시 사용자에게 먼저 목록을 텍스트로 출력하여 확인(컨펌)받아야 합니다.**

### 2. 데이터 처리 흐름

#### A. 서점 엑셀 파일을 입력받은 경우 (정확도 100%)
1. `openpyxl` 등을 사용하여 제공된 서점 엑셀 파일(예: `C:\Users\user\Downloads\교보문고_장바구니_상품리스트.xlsx`)을 읽습니다.
2. 헤더를 파악하여 다음 정보를 정확히 추출합니다: `상품명`, `인물/아티스트(저자)`, `출판사/제작사`, `수량`, `판매가`.
3. 대상 엑셀 파일(예: `시울림 동시집 구입목록.xlsx`)의 빈 행을 찾아 양식에 맞게 데이터를 기입하고 저장합니다.

```python
import openpyxl

# 교보문고 엑셀에서 데이터 추출 예시
kyobo_wb = openpyxl.load_workbook(r'교보문고_장바구니_상품리스트.xlsx')
kyobo_sheet = kyobo_wb.active
items = []
for row in kyobo_sheet.iter_rows(min_row=2, values_only=True):
    if not row[0]: continue
    title = row[4]       # 상품명
    author = row[11]     # 저자
    publisher = row[12]  # 출판사
    qty = int(row[10])   # 수량
    price = int(str(row[6]).replace(',', '')) # 판매가
    items.append((title, author, publisher, qty, price))

# 대상 엑셀에 기록 (이전 지침과 동일하게 순번, 10%할인가 등 양식 준수)
# ...
```

#### B. 장바구니 이미지만 입력받은 경우 (사용자 검증 필수)
1. 이미지에서 도서명, 저자, 출판사, 가격, 수량을 최대한 신중하게 읽어냅니다. (이름, 표지 색상으로 어림짐작 절대 금지)
2. **엑셀에 바로 쓰지 않고**, 추출된 목록을 사용자에게 텍스트로 보여주며 맞게 추출되었는지 물어봅니다.
   - 예: *"이미지에서 다음 9권의 책을 인식했습니다. 이 목록이 맞는지 확인해 주시면 엑셀에 기록하겠습니다."*
3. 사용자가 "맞다"고 확인(승인)한 경우에만 파이썬 스크립트를 작성하여 엑셀에 기록합니다.
4. 만약 사용자가 틀렸다고 하면, 다시 읽거나 서점 엑셀 파일을 첨부해 달라고 정중히 요청합니다.

### 3. 파일 잠금(Lock) 처리
대상 엑셀 파일이 이미 열려 있어 `PermissionError`가 발생하는 경우, 원본을 덮어쓰지 못하므로 `_최종본.xlsx` 등 새로운 이름으로 우회 저장하고 사용자에게 안내합니다.
