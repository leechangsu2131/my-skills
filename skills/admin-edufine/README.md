# 공문 기안 자동화 파이프라인 (V4 Hybrid + CDP)

에듀파인(Edufine) 기안 작성을 자동화하기 위한 스크립트입니다.
다량의 공문(ODT) 파일을 한 번에 파싱하고 연속으로 기안 폼을 작성하며 결과를 엑셀로 자동 정리해 줍니다. 
특히, 정부 사이트의 봇 탐지를 회피하기 위해 **원격 디버깅(Remote Debugging)** 기능을 활용하여 실제 사용자의 크롬에 연결합니다.

## 기능

1. **파싱 (`parse_gongmun.py`)**: ODT 파일에서 기안에 필요한 메타데이터 추출
2. **원격 크롬 제어 (`playwright_edufine.py`)**: 봇이 직접 브라우저를 열지 않고, `launch_chrome.bat`으로 미리 열어둔 브라우저(포트 9222)에 기생(Attach)하여 자동화
3. **통합 웹 제어 (`app.py` & `templates/index.html`)**: 터미널 명령어 없이 예쁜 웹 화면에서 폴더를 지정하고, 실시간 로그를 보며 [다음 공문 진행]을 마우스로 컨트롤
4. **엑셀 리포트 생성 (`edufine_report.py`)**: 작업 성공/실패 내역을 `.xlsx` 형식의 엑셀 파일로 자동 정리

## 설치 방법

```bash
# 필수 패키지 설치 (playwright, pandas, openpyxl, flask 등)
pip install -r requirements.txt

# Playwright용 브라우저 엔진 설치 (최초 1회)
playwright install chromium
```

## 사용 방법 (워크플로우)

1. **보안 로그인 (수동)**
   - 프로젝트 폴더 안의 **`launch_chrome.bat`** 파일을 더블클릭합니다.
   - 크롬 브라우저가 열리며 나이스(NEIS) 화면이 뜹니다. 공동인증서로 나이스에 로그인합니다.
   - 로그인 후 나이스 상단 메뉴에 있는 **[K-에듀파인]**을 클릭하여 에듀파인 창을 열어둡니다.
2. **웹 서버 구동**
   - 터미널에서 `python app.py`를 실행합니다.
3. **일괄 작업 지시**
   - 아무 브라우저에서 `http://localhost:5030` 에 접속합니다.
   - 파싱할 ODT 공문들이 모여있는 폴더 경로를 입력하고 **[일괄 실행]**을 클릭합니다.
   - 1번에서 열어둔 크롬 창이 스스로 움직이며 공문을 순서대로 작성합니다!

## 주의사항 및 작업 흐름
- **본문 작성 수동 개입**: 봇이 기안 폼 입력을 마치고 멈추면(웹 콘솔에 노란색 대기 메시지 표시), 사용자가 LLM 등에서 본문을 복사하여 에듀파인에 직접 붙여넣어야 합니다. 그 후 결재 상신(또는 임시저장)을 누르고 웹 UI의 **[다음 공문으로 진행]** 버튼을 클릭하세요.
- **포트 9222 충돌**: `launch_chrome.bat`을 실행하기 전에 다른 모든 크롬 창이 완전히 닫혀있어야 정상적으로 디버깅 모드가 활성화될 수 있습니다.
