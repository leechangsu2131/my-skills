# admin-edufine 스킬

경상북도 경주 화천초등학교 에듀파인 행정 업무를 실전 자동화(RPA)합니다.

---

## 🛠 주요 기능 목록

### [트랙 1] 학교회계 물품 구매 품의 봇
S2B(학교장터) 장바구니 품목이나 물품 리스트를 바탕으로, 에듀파인 학교회계 품의등록 화면의 품목 그리드에 일괄 행추가하고 수량·단가를 자동 입력합니다.
- **실행 모듈**: [`playwright_edufine.py`](playwright_edufine.py)
- **작동 경로**: `[학교회계]` 시스템 전환 $\rightarrow$ `사업관리` $\rightarrow$ `사업담당` $\rightarrow$ `품의등록` $\rightarrow$ 제목/개요 입력 $\rightarrow$ 품목내역 그리드 좌표 타격 및 행추가 반복

### [트랙 2] 전자결재 공문 기안 봇 (신규 완성)
수신한 공문(ODT / HWPX)을 분석하거나 기안할 내용을 바탕으로, 전자결재 기안기 화면을 열고 제목 및 규격 본문(`1. 관련... 2. ... 끝.`)을 자동 주입합니다.
- **실행 모듈**: [`playwright_gongmun_draft.py`](playwright_gongmun_draft.py)
- **작동 경로**: `[업무관리]` 시스템 확인 $\rightarrow$ `문서관리` $\rightarrow$ `기안` 메뉴 클릭 $\rightarrow$ 공용기안문 호출 $\rightarrow$ 기안문 작성 팝업 감지 $\rightarrow$ 제목 입력 $\rightarrow$ 웹한글 본문 영역에 클립보드 주입
- **이중 안전망 (Fallback)**: 자동 실행 시 클립보드에 본문이 우선 복사되며, 스튜디오 화면에 `[📋 본문 복사]` 버튼이 상시 노출되어 브라우저 렉 발생 시에도 0.1초 만에 `Ctrl+V`로 직접 상신 가능

### [트랙 3] 에듀파인 공문 검색 & 문서번호 연계 품의/기안 봇
기안할 내용이나 품의에 필요한 교부/선정 공문이 필요할 때, 키워드를 입력하면 에듀파인 `문서등록대장`에서 해당 공문을 자동 검색하여 **생산/접수문서번호 및 메타데이터를 추출**하고, 원하는 **품의등록 또는 기안문 탭을 즉시 호출**합니다.
- **실행 모듈**: [`playwright_gongmun_search.py`](playwright_gongmun_search.py)
- **작동 경로**: 포털 자동 진입 $\rightarrow$ 공지사항 팝업 메모리 파괴(`destroy`) $\rightarrow$ 넥사크로 직결 메뉴 호출(`LeftFrame.gfnOpenMenu('A00AAB0107001')`) $\rightarrow$ 기간 및 키워드 조회 $\rightarrow$ 문서번호(접수/시행/생산) 추출 $\rightarrow$ 필요 시 학교회계 품의등록(`A00FAA0104001001`) 즉시 호출
- **역할 분담**: 사용자가 "문서번호 따서 품의 탭 열어줘"라고 요청하면, 봇이 관련 공문 번호를 발굴하여 요약 제시하고 해당 품의 탭을 화면에 바로 준비해 주는 스마트 업무 비서 역할 수행

### [기능 4] 결재대기 / 공람대기 자동화 봇
업무포털(gbe.eduptl.kr) K-에듀파인 전자결재 현황 위젯에서 결재대기 / 공람대기 문서를 수집하고 결재 처리를 지원합니다.
- **실행 모듈**: [`edufine_auto_approve.py`](edufine_auto_approve.py)

### [기능 5] Edufine Flow V5 (통합 대시보드 웹 스튜디오)
브라우저(`http://localhost:5030`)에서 공문 드래그앤드롭, 실시간 파싱, 기안문 생성, 트랙1/2/3 원클릭 실행을 총괄 제어하는 웹 인터페이스입니다.
- **백엔드**: [`app.py`](app.py) (Flask)
- **프론트엔드**: [`templates/index.html`](templates/index.html)

### [기능 6] 생산문서 개인정보 노출 점검
요청된 연도의 생산문서 중 공개 문서를 찾아 제목, 본문, 붙임파일을 확인하고 개인정보 등 비공개 대상 정보가 확인된 문서를 사용자 요청 범위에 따라 비공개로 전환하도록 지원합니다. 완료 후 문서번호만 정리해 행정실 담당자에게 보낼 쪽지를 준비하거나, 사용자가 발송을 요청한 경우 쪽지 발송을 진행합니다.
- 점검 범위, 판정 기준, 변경 후 확인 및 쪽지 작성은 [`references/privacy-review.md`](references/privacy-review.md)를 따릅니다.
- 문서 내용이나 개인정보를 쪽지에 복사하거나 불필요하게 저장하지 않습니다.

## 🚀 빠른 실행 방법

### 1단계. Chrome 원격 디버깅 모드로 실행 (최초 1회)
평소 쓰시던 일상 크롬 프로필 그대로 보안 플러그인과 인증서 세션을 유지하며 실행합니다:
```bash
launch_chrome_default.bat
```
*(기존 열려있는 크롬 창을 모두 닫은 후 실행하여 포트 9222를 개방합니다)*

### 2단계. 스튜디오 웹 실행
```bash
run_studio.bat
```
또는 `edufine` 저장소 루트의 `스마트_공문기안_스튜디오_실행.bat` 실행.
브라우저에서 `http://localhost:5030` 접속 후 작업 진행.

## ⚠️ 핵심 보안 및 안전 정책

1. **공동인증서 비밀번호 하드코딩 금지**: 사용자가 직접 브라우저에서 로그인 수행.
2. **최종 결재/상신 버튼 자동 클릭 금지**: 제목과 본문, 품목 입력까지만 봇이 진행하며, 결재선 지정과 최종 상신 버튼은 사람이 직접 눈으로 확인하고 클릭.
3. **이중 안전망 보장**: 브라우저 원격 조작 중 예기치 못한 지연이나 팝업 오류가 생겨도, 클립보드에 완성된 기안 본문이 항시 준비되어 있어 수동 `Ctrl+V` 즉각 대응 가능.
4. **개인정보 점검은 최소 수집**: 점검 중 발견한 개인정보 원문을 채팅, 로그, 파일, 쪽지에 재현하지 말고 문서번호와 최소한의 판정 사유만 기록합니다. OCR/검색 결과만으로 확정하지 말고 원문 위치를 직접 확인합니다.
5. **문서 상태 변경 및 쪽지 발송**: 사용자 요청 범위 안에서만 실행합니다. 비공개 저장 후 해당 문서가 비공개 상태인지 다시 확인합니다. 수신자가 확실하지 않거나 비공개 설정 항목의 의미/근거가 불명확하면 임의 선택하지 말고 확인이 필요한 건으로 남깁니다. 쪽지는 지정된 담당자와 문서번호를 재확인하고 발송합니다.
