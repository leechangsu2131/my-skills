### 현재 앱 상태와 다음 작업

- 지비톡 쪽지관리함 창 ID 731736에서 seq11, 권윤옥 · 2026-09-30 08:12 쪽지를 마지막으로 선택했다. 마지막 검색어는 심폐소생술 교육 안내다.
- 다음 미확인 후보는 seq12, 2026-09-29다. 본문 고유 구절 `네오디움장구자석 2통`으로 검색하고, 선택된 화면의 머리글·날짜·본문을 원본과 대조한다.
- 현재 미확인 범위에는 8·9월 seq1–286 일부와 7월 seq367 이후가 함께 있다. 7월 자료는 건드리지 않는다. 원본과 보강본에서 sequence만으로 날짜를 추정하지 말고 각 행의 received_date를 확인한다.
- 키보드 우선으로 검색어를 입력하고 Return으로 검색한다. 이번 창에서는 검색칸을 클릭해도 접근성 `focused_element`가 `16 창 쪽지함 리스트`로 남았지만, 화면의 검색칸에 입력 커서가 보였고 입력한 검색어가 화면에 표시된 뒤 Return을 눌렀을 때 예상 결과가 나왔다. 이 동작을 현재 창에서만 관찰된 사례로 기록하며, 화면에 커서와 입력한 검색어가 확인되지 않으면 검색을 실행하지 않는다. 필요한 마우스 입력은 검색창 포커스와 결과 행 선택에만 사용한다.
- UIA 본문 편집 값이 이전 탭의 텍스트로 남는 경우가 batch10에서 관찰됐다. 새로 선택한 전체 본문이 화면에 보이고 원본과 육안 대조할 수 있을 때만 `manual-screen-body-match` 방식으로 기록한다. 화면이 잘리거나 본문이 모호하면 미확인으로 둔다. UIA 해시를 계산한 것처럼 기록하지 않는다.
- 검색 결과가 0건이어도 대상 쪽지가 없다고 판단하지 않는다. 짧고 고유한 구절로 바꿔 검색하고, 검색 후보가 여러 개면 날짜·발신자·본문 지문으로 고른다.
- 30건보다 작은 배치로 저장·대조하고 다음 구간으로 넘어간다. 키보드 연속 Down 이동과 앱 전체 목록 순회는 아직 검증되지 않았다.
