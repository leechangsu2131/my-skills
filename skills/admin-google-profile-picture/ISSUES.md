### ISSUE-005: Google 계정 사진 변경의 Playwright 흐름 확인 (2026-11-25 해결)
- **상태**: 🟢 해결 (2026-11-25)
- **증상**: 실제 계정에서 사진 선택 대화상자와 저장 흐름이 자동화에서 불분명했다.
- **원인**: 프로필 사진 설정이 iframe 안에서 열리고, 기기 업로드 버튼이 파일 선택 이벤트를 발생시키는 구조였다.
- **해결/조치**: Playwright persistent context에서 계정 사진 창을 찾아 파일 선택 이벤트에 지정 사진을 연결하고, 자르기 및 저장 단계를 진행했다. 저장 뒤 계정 프로필 사진을 다시 열어 지정 이미지가 표시됨을 확인했다. 로그인 완료 전에 context를 닫지 않도록 안내를 보완했다.
- **관련 파일**: `SKILL.md`

### ISSUE-002: Windows PowerShell에서 한글 별칭 검사 실패 (2026-11-25 해결)
- **상태**: 🟢 해결 (2026-11-25)
- **증상**: 프로필 실행 시 별칭 정규식에서 문자 범위 오류가 나 Chrome이 열리지 않았다.
- **원인**: Windows PowerShell이 UTF-8 BOM 없는 스크립트를 시스템 기본 인코딩으로 읽어 한글 정규식 범위를 손상시켰다.
- **해결/조치**: 정규식의 한글 범위를 ASCII 유니코드 이스케이프로 바꾸고, 스크립트를 UTF-8 BOM 형식으로 저장했다. 테스트 별칭으로 다시 실행해 프로필 폴더 생성과 Chrome 실행을 확인했다.
- **관련 파일**: `scripts/open_chrome_profile.ps1`

### ISSUE-001: Google 로그인 자동 입력이 비밀값을 노출할 수 있음 (2026-11-25 해결)
- **상태**: 🟢 해결 (2026-11-25)
- **증상**: 숨겨진 비밀번호 입력란에 입력을 시도하면 자동화 도구의 원본 오류에 입력 값이 포함될 수 있었다.
- **원인**: Google 로그인에 계정 비밀번호를 자동 입력하는 절차를 초안에 넣었다.
- **해결/조치**: 비밀번호 파일과 자동 입력 절차를 제거했다. 로그인과 보안 확인은 사용자가 Chrome에서 직접 한다. 별칭별 로컬 프로필을 여는 스크립트를 추가했다.
- **관련 파일**: `SKILL.md`, `scripts/open_chrome_profile.ps1`
