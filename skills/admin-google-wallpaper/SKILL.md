# 학생 Google 계정 Chrome 배경 관리

학생용 Google 계정마다 Chrome 프로필을 분리하고, 사용자가 고른 로컬 그림을 Chrome 새 탭 배경으로 등록한 뒤 지정한 사이트를 시작 페이지로 설정한다. Chrome 새 탭 배경과 태블릿 운영체제 배경화면은 서로 다른 설정이다. 사용자가 기기 자체 배경을 뜻한다고 밝히면 Android/ChromeOS 기기 관리 방법을 먼저 확인한다.

## 설정 파일

계정 정보는 저장소나 스킬 폴더에 두지 않는다. `%OneDriveCommercial%\96. 인증\google.env`, `%OneDrive%\96. 인증\google.env`, 또는 `~/OneDrive - gyo6.net/96. 인증/google.env` 순서로 파일을 찾는다. 환경변수 `GOOGLE_WALLPAPER_ENV`가 설정되어 있으면 그 경로를 먼저 사용한다. OneDrive 환경변수나 파일을 찾을 수 없으면 임의의 경로를 만들지 말고 사용자에게 위치를 묻는다.

키 이름과 예시는 [.env.example](.env.example)을 따른다. 계정은 `GOOGLE_WALLPAPER_ACCOUNT_01_EMAIL`과 `GOOGLE_WALLPAPER_ACCOUNT_01_PASSWORD`처럼 번호로 묶는다. 계정 ID가 바뀌면 해당 로컬 파일의 이메일 값만 바꿔 다음 실행부터 새 ID를 사용한다. 이 파일은 이 스킬 전용 `google.env`이며 저장소 공용 `.env` 로더로 대신 읽지 않는다.

환경 파일을 읽을 때는 필요한 계정 값만 메모리에서 사용한다. 아이디·비밀번호 원문을 채팅, 터미널 출력, 예외 메시지, 로그, 스크린샷, 브라우저 추적 기록에 남기지 않는다. 브라우저 입력은 화면에 보이고 활성화된 필드인지 확인한 뒤 진행한다. 입력 실패 시 자동화 라이브러리의 원본 예외를 그대로 출력하지 말고, 값이 들어갈 수 있는 오류 세부 정보는 버린 뒤 원인만 일반화해 보고한다. 디버그 추적·비디오·DOM 덤프를 켜지 않는다. 파일 전체를 출력하지 말고, 계정 목록을 사용자에게 보여 줄 때는 별칭이나 번호만 쓴다. 실제 파일이나 암호 값을 저장소에 복사하지 않는다.

## 작업 흐름

1. 요청에서 대상 계정, 사용할 그림, 시작 사이트를 확인한다. 여러 계정을 다룰 때는 한 번에 한 프로필씩 처리하고, 성공 여부를 계정 별칭으로만 기록한다.
2. 지정한 `DOWNLOADS_DIR`가 있으면 그 폴더를, 없으면 현재 사용자 다운로드 폴더를 찾는다. 그림 후보를 시각적으로 확인해 학생에게 적합한 로컬 이미지를 고른다. 이미지 후보가 여러 개거나 내용이 불분명하면 선택지를 보여 주고 고르게 한다. 웹에서 새 이미지를 받아야 하면 출처와 사용 조건을 확인하고 사용자가 요청한 경우에만 다운로드한다.
3. 전용 Chrome 프로필을 계정마다 별도로 만든다. 프로필은 로컬의 `%LOCALAPPDATA%\my-skills-data\admin-google-wallpaper\profiles\<계정별칭>` 아래에 둔다. OneDrive 동기화 폴더, 저장소, 공용 Chrome 프로필을 사용하지 않는다. 기존 프로필이 있으면 재사용하고 초기화하거나 삭제하지 않는다.
4. 브라우저는 Playwright로 제어할 수 있는 실제 Google Chrome을 우선 사용한다. 별도 `user_data_dir`를 지정해 프로필을 분리하고, 비디오·추적·콘솔의 입력 값 기록을 끈다. 실행 환경에서 Playwright를 쓸 수 없지만 데스크톱 제어가 가능하면 사용 가능한 컴퓨터 제어 도구를 활용한다. Aside/Ego 같은 관리형 브라우저는 전용 Chrome 프로필을 지정할 수 있을 때만 사용한다.
5. `google.env`에서 해당 계정의 이메일과 비밀번호를 읽어 로그인 화면에 필요한 경우에만 입력한다. Playwright를 쓸 때는 화면에 표시된 입력란을 확인하고 `visible` 대기 후 입력한다. 입력·탐색 단계는 비밀값을 포함할 수 있는 오류가 밖으로 나오지 않게 감싼다. Google이 CAPTCHA, 2단계 인증, 기기 확인 또는 보안 경고를 요구하면 우회하지 말고 사용자가 직접 완료하도록 기다린다. 로그인 성공 여부를 확인하고 계정이 요청한 대상인지 검증한다. 대상이 다르면 설정 변경 전에 멈춘다.
6. Chrome 새 탭의 맞춤설정 메뉴에서 선택한 그림을 배경으로 적용한다. 적용 상태를 화면에서 확인한다. Google 계정 동기화나 조직 정책 때문에 배경 설정이 막히면 우회하지 말고 원인과 관리 콘솔 정책 확인 필요성을 알린다.
7. Chrome 설정의 시작 시 페이지에서 지정 URL을 여는 옵션을 설정한다. URL이 제공되지 않았다면 값을 추측하지 말고 묻는다. 시작 시 페이지와 새 탭 페이지는 별도 설정임을 확인한다.
8. 실제 변경 직전, 대상 계정 별칭, 이미지 미리보기/파일명, 시작 URL을 간단히 제시하고 적용 확인을 받는다. 확인 뒤 한 계정씩 변경하고 새 탭 배경과 시작 페이지를 다시 확인한다. 완료 시 성공/실패한 별칭, 적용한 그림 파일명, 시작 URL만 보고한다.

## 브라우저 선택

Playwright는 계정별 지속 프로필을 지정하고 반복 작업을 재현하기 쉬워 기본 선택이다. Google 로그인은 자동화 제어를 제한할 수 있으므로 로그인·보안 확인을 자동으로 통과시키려 하지 않는다. Computer Use, Ego, Aside는 현재 실행 환경의 브라우저 기능을 활용해야 할 때 보조 수단으로 쓴다. 브라우저 도구가 로컬 Chrome 프로필을 만들거나 다시 열 수 없다면 무리하게 세션을 옮기지 말고 Chrome을 직접 연 뒤 화면 제어를 사용한다.

## 멈춰야 하는 경우

- `google.env`, 계정 키, 그림 폴더, 시작 URL을 찾지 못했거나 값이 모호한 경우
- 로그인 대상이 요청한 별칭과 다르거나 계정 전환 여부를 확인할 수 없는 경우
- Google 인증 단계 또는 학교 관리 정책이 추가 조치를 요구하는 경우
- 그림이나 시작 페이지를 적용하기 직전 사용자의 확인을 받지 못한 경우
