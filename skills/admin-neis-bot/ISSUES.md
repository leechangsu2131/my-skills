### ISSUE-005: 결재자지정(결재선) 추가가 모델·도구에 따라 실패 (2026-11-19)
- **상태**: 🟢 해결 (2026-11-19)
- **증상**: 기안문서상신 창에서 결재자를 넣지 못하거나, 넣어도 구분(검토/결재)이 틀림. 이름 입력란(`ipbUserNm`)에 이름만 타이핑하고 끝나거나, 결재자지정 버튼이 '오늘의 수업' 확장 팝업에 가려 좌표 클릭이 빗나감. 상신 버튼 연타로 확인창이 겹침.
- **원인**: (1) 결재선은 기안창이 아니라 **별도 결재자지정 창(`wam_woapm07_p04`)** 에서 추가·저장해야 반영됨. (2) 구분은 추가 *전에* p04의 `rdbCn` 라디오로 정해야 함(추가 후 변경 아님). (3) 기안창·확인창이 5~10초 늦게 떠서 재클릭하면 중복 동작.
- **해결/조치** (검증된 순서):
  1. 승인요청 클릭 후 **기다림** → 기안창 `wam_woapm07_p00` 등장 확인(앱 목록 또는 스크린샷). 안 뜨면 그때 한 번만 재클릭.
  2. `p00.lookup("btnSelectSancr").click()` (좌표 클릭 대신 JS — 확장 팝업에 가려도 됨).
  3. p04 열림 대기 → `dsMain`에서 `userNm`으로 행 번호 찾기. 동명이인은 `jbpsNm`·`userId`로 구분. '비고'에 "부재중"이면 사용자에게 먼저 알림.
  4. 사람마다: `rdbCn` 라디오 클릭(2 결재 / 7 검토 / 4 협조 / 5 공람) → `grdUserListFrom.selectRows([row]); btn1.click()` → `grdUserListTo.dataSet`에서 `atrzScNm`·`atrzSeqSn` 확인.
  5. `btn4`(저장) → 기안창 결재선 표에 반영됐는지 스크린샷 확인 → [상신] **한 번** → 부재중 경고(있으면) [확인] → "기안문서상신을 하겠습니까?(결재자 수 N)" 확인 → "상신을 완료하였습니다".
  - 매 단계 스크린샷으로 확인창 유무를 보고 진행. 버튼 연타 금지.
- **관련 파일**: `references/paps-submission-workflow.md`, `neis_absence_report.py`(같은 p04 방식)

### ISSUE-004: 같은 9222 브라우저에 NEIS 탭이 둘이면 엉뚱한 탭을 조작 (2026-11-19)
- **상태**: 🟢 해결 (2026-11-19)
- **증상**: 사용자가 NEIS 탭을 하나 더 열자 URL(`main.jsp`)로 탭을 고르던 스크립트가 새 탭을 잡음. 새 탭 초기화면을 보고 "MDI 탭이 다 닫혔다"고 오판·오보고.
- **해결/조치**: 작업 시작 시 `/json`에서 target id를 정해 환경변수(`NEIS_TAB`)로 고정. 사용자에게 작업 중 탭 추가를 피하거나 미리 알려 달라고 안내.

### ISSUE-003: 메뉴 프로그램 호출 시 "2개 이상의 메뉴가 선택 되었습니다" 선택창 누적 (2026-11-19)
- **상태**: 🟢 해결 (2026-11-19)
- **증상**: `openMdiMenu(id)` / `doOpenMenuToMdi`를 여러 번 호출하자 선택창(학급담임/체육/PAPS 경로)이 쌓임. X를 반복 클릭하다 다른 요소가 눌릴 위험.
- **원인**: 같은 메뉴가 여러 권한 트리에 있음. 호출이 늦게 반영돼 재호출하면 큐에 쌓임.
- **해결/조치**: 메뉴는 상단 업무 메뉴 → 왼쪽 트리 클릭으로 연다. 이미 쌓였으면 X 대신 각 창의 "체육 > …" 항목을 하나씩 골라 소진(화면만 열림).

### ISSUE-002: 마감·확인창·완료 알림이 늦게 떠 다음 클릭을 막음 (2026-11-19)
- **상태**: 🟢 해결 (2026-11-19)
- **증상**: PAPS 입력마감/측정마감에서 버튼 클릭 후 확인창이 5~10초 뒤 등장. 완료 알림도 늦게 떠서 다음 학년 조회·탭 전환 클릭이 무시됨. 체크박스 클릭이 재조회 중이면 반영 안 됨.
- **해결/조치**: 클릭 → 대기 → 스크린샷 확인 → 다음 동작. 다음 학년으로 넘어가기 전 늦게 뜬 알림을 반드시 닫고, 체크박스 선택 상태를 스크린샷으로 확인 후 마감 버튼.

### ISSUE-001: Playwright connect_over_cdp가 멈춤 (2026-11-19)
- **상태**: 🟢 해결 (2026-11-19)
- **증상**: 확장 프로그램 대상이 많은 프로필에서 `connect_over_cdp`가 120초 넘게 응답 없음.
- **해결/조치**: `/json`에서 페이지 `webSocketDebuggerUrl`에 websocket-client로 직접 연결(`suppress_origin=True`), `Runtime.evaluate`(awaitPromise)·`Input.dispatchMouseEvent`·`Page.captureScreenshot` 사용. 60초 넘는 작업은 페이지 안에서 비동기로 돌리고 `window.__변수`에 결과를 저장해 폴링.
