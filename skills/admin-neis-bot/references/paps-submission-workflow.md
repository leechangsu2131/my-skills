## 근거 공문
- 매년 8월경 도교육청 체육건강과 「학생건강체력평가 및 건강체력교실 내실 운영 안내」
- 2026 기준: **PAPS 나이스 결과 전송 11. 27.(금)까지**, 건강체력교실 운영 현황(시트2)은 12. 11.(금)까지 교육지원청에 공문 제출.
- 공문 위치: `51. 체육업무\건강체력교실\`, `51. 체육업무\paps\`

### 2026-11-19 실제 수행 기록 (검증된 흐름)
- 입력마감·측정마감: 학년별(4·5·6, 3학년은 "종목미선정(0/0)"이라 대상 아님)로 `학년 콤보 값 설정 + btnSearch` → 헤더 체크박스 클릭 → 마감 버튼 → 확인창 [확인] → 완료 알림 [확인].
  - **확인창·완료 알림이 5~10초 늦게 뜬다.** 버튼을 다시 누르지 말고 스크린샷으로 기다린다. 늦게 뜬 알림이 다음 클릭을 막으므로 다음 학년으로 가기 전에 반드시 닫는다.
  - 측정마감 후 그 학년에 "승인요청"(측정현황 D80 결재) 버튼이 생긴다. 필수 여부 미확인 — 이번엔 통계 결재만 올렸다.
- 통계생성: `dsAllMagam.msrmDdlnYn == "0"`(미마감 반 0)이어야 가능. 확인 → "통계 생성이 완료" 알림.
- 승인요청(btnDoc) → 기안문서상신 창(`wam_woapm07_p00`)이 늦게 열린다 → `btnSelectSancr` → 결재자지정 창(`wam_woapm07_p04`): `rdbCn` 라디오(2 결재/7 검토/4 협조/5 공람)를 먼저 고르고 `grdUserListFrom.selectRows([row]); btn1.click()`으로 추가 → `btn4`(저장) → 기안창 [상신] → (부재중 결재자 있으면 경고 확인) → "기안문서상신을 하겠습니까?" 확인 → "상신을 완료하였습니다".
  - 2026 결재선: 기안(체육 담당) → 검토(연구부장) → 결재(교감). 결재자 목록 '비고'에 "부재중"이 보이면 사용자에게 알리고 진행 여부를 묻는다.
- 상신 후 화면: 결재상태 "상신(진행)", 상단 "[결재 중]", **제출 버튼이 숨겨짐(btnSend.enabled=false)**. 결재 완료 후 [제출] → "통계를 교육청으로 전송하시겠습니까?" 확인 → 완료. 교육청 통계가 마감됐으면 제출 불가(dsSidoMagam.ddlnYn=="Y").

## 누락 유형별 처리
- **비만(BMI)만 누락**: 해당 학생 개인별 입력에서 **보건자료 불러오기**(건강기록부 신체발달의 키·몸무게) → 저장. 입력되지 않은 값만 채워진다(SA-PAP-0020).
- **전입생**: 입력누락에 전입생이 있으면 **측정결과입력 > 전입생자료관리(AMPAP40009, pap_elsmr05_m00)에서 전 학교 기록 불러오기**. 전 학교 종목·기록·등급도 이 화면에서 확인된다.
  - 전 학교와 측정 종목이 다르면(예: 순발력 제자리멀리뛰기 ↔ 50m달리기) 우리 학교 종목 칸이 빈다. 이때 사용자에게 **전 학교 종목의 기록·등급**(전입생자료관리)과 **두 종목의 학년·성별 평가기준표를 점수별로 나란히** 보여준다(평가기준조회, 아래 자동화 메모). 같은 점수 줄이 대응 구간이다.
  - 입력값은 사용자가 정한다. 실제로 재지 않은 기록을 에이전트가 정하거나 입력하지 않는다.
- **측정 불가 학생**(장기결석·장애 등): 측정불가 선택 + 사유 입력(SA-PAP-0014/0019) 또는 측정제외학생관리.

## 자동화 메모 (함정)
- 같은 메뉴가 학급담임·체육·PAPS 여러 권한 아래에 있어서 `openMdiMenu(id)` / `doOpenMenuToMdi`를 호출하면 **"2개 이상의 메뉴가 선택 되었습니다" 선택창**이 뜬다. 호출이 바로 반영되지 않는다고 여러 번 호출하면 선택창이 쌓인다.
  - 메뉴는 한 번에 하나만 호출하고, 매번 스크린샷으로 확인한 뒤 "체육 > …" 항목을 누른다.
  - 쌓인 선택창은 X를 반복 클릭하지 말고, 각 창의 "체육 > …" 항목을 하나씩 골라 소진한다(화면만 열리고 저장은 없음). 매번 스크린샷으로 확인.
  - 사람처럼 상단 "체육" 메뉴 → 왼쪽 트리에서 여는 편이 안전하다.
- 평가기준조회(AMPAP40033, pap_elspr01_m00): `cmbGrd`·`cmbSxdsCd` 설정 → `btnSearch.click()` → `grdEvlLine`의 `cell-click` 핸들러를 행 번호로 호출(41=50m 8행, 42=제자리멀리뛰기 9행) → `dsList`(evlClaCd 등급, claScr 점수, minNmvl~maxNmvl).
- Playwright `connect_over_cdp`는 확장 프로그램 대상이 많은 프로필에서 멈출 수 있다. 페이지 대상의 `webSocketDebuggerUrl`에 바로 붙어 `Runtime.evaluate`를 쓰는 편이 안정적이다(websocket-client, `suppress_origin=True`).
- 측정마감 화면의 학년 콤보는 UDC(`udcSwcAuth`) 안의 `cmbUdcAuth`. 값을 넣고 `btnSearch.click()`으로 학년별 조회.
- 사용자가 같은 9222 브라우저에서 NEIS 탭을 하나 더 열면 `main.jsp` 탭이 둘이 된다. URL로 탭을 고르면 사용자의 새 탭을 조작하게 되므로(2026-11-19 실제 발생: 새 탭 초기화면을 보고 "탭이 다 닫혔다"고 오판), 작업 시작 시 `/json`에서 target id를 정해 고정한다.
