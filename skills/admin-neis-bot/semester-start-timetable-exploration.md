## 내부값 패턴

`dsWeekByClsByTi`의 요일별 `*Info` 값은 다음 형태로 관찰됐다.

```text
01|개설과목코드|교사ID|4||
```

예:

- 국어: `01|20042|lee2131|4||`
- 사회: `01|20045|lee2131|4||`
- 과학(전담): `01|20054|choy2910|4||`
- 체육(전담): `01|20057|sch9901|4||`
- 토요휴업일: `01|00000|0000000000|2|9011|`

이 패턴은 이후 시간표 셀 자동 기입을 만들 때 중요하다. 단, 저장 자동화 전에는 반드시 UI 이벤트, 데이터셋 변경 플래그, 검증/충돌 처리 방식을 별도로 확인해야 한다.
