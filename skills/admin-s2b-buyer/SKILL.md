# S2B 학교장터 자동 구매 시스템

이 스킬은 **S2B 학교장터(s2b.kr)**에서 개인이용자로 로그인한 뒤, 구매 품목을 견적서(장바구니)에 담는 자동화입니다.

지원하는 흐름:

1. **Excel 견적서 처리** — `G2B/S2B번호`, `품명 및 규격`, `수량` 열이 있는 견적서 양식을 읽습니다.
2. **S2B번호 직접 담기** — S2B번호가 있으면 검색 없이 상세 페이지로 이동해 수량을 입력하고 견적서에 담습니다.
3. **품목명 검색 보완** — S2B번호가 없으면 품목명으로 검색하고 첫 결과를 선택합니다.
4. **결과 리포트 저장** — 처리 결과를 `result/s2b_구매결과_YYYYMMDD_HHMMSS.xlsx`로 저장합니다.

> 실제 계약/구매 확정까지는 자동화하지 않습니다. 성공 기준은 S2B 견적서(장바구니)에 품목을 담는 단계입니다.

## 필요 조건

- Python 3.8 이상
- `playwright`
- `openpyxl`
- `requests`, `beautifulsoup4`
- S2B 개인이용자 계정

## 사용 방법

### 1. 초기 설정

```bash
pip install -r requirements.txt
playwright install chromium
```

### 2. 환경 변수 세팅

`.env.example`을 `.env`로 복사 후 실제 값 입력:

```bash
cp .env.example .env
```

| 변수 | 설명 |
|------|------|
| `S2B_USER_ID` | S2B 개인이용자 아이디 |
| `S2B_USER_PW` | S2B 개인이용자 비밀번호 |

### 3. 웹 UI 실행

```bash
python app.py
```

브라우저에서 `http://localhost:5026`에 접속합니다.

웹 UI에서는 다음 순서로 사용합니다.

1. `엑셀 불러오기`로 견적서 양식 파일을 선택합니다.
2. 추출된 S2B번호, 품목명, 수량을 확인합니다.
3. 처음에는 `테스트 모드`로 검색/견적 담기 흐름을 확인합니다.
4. 실제 담기가 필요하면 `테스트 모드`를 끄고 `물품 검색` 후 `견적신청`을 실행합니다.

### 4. CLI 실행

```bash
# CSV 테스트
python s2b_buyer.py items_example.csv --dry-run

# 견적서 양식 Excel 실제 견적서 담기
python s2b_buyer.py "list/자투리공간 체육물품 구입내역(화천초).xlsx"

# 브라우저 창 없이 실행
python s2b_buyer.py "list/자투리공간 체육물품 구입내역(화천초).xlsx" --headless
```

## 입력 파일

### CSV

CSV는 `품목명`, `수량`, 선택적으로 `S2B번호` 열을 지원합니다.

```csv
품목명,수량,S2B번호
A4 복사용지 80g,10,
화이트보드 마커,20,202604067720487
```

### Excel 견적서 양식

아래 헤더를 가진 견적서 양식을 지원합니다.

- `NO`
- `G2B/S2B번호`
- `품명 및 규격`
- `수량`
- `단위`
- `단가`
- `금액`

`G2B/S2B번호` 셀에 G2B번호와 S2B번호가 함께 있어도 마지막 긴 숫자 값을 S2B번호로 추출합니다.

예: `22852308 / 201611085168882` -> `201611085168882`

## 주의 사항

- S2B는 공공 전자조달 시스템이므로, 과도한 자동 접근은 삼가주세요
- `--dry-run`으로 먼저 테스트를 권장합니다
- 로그인 실패 시 `login_failed.png` 스크린샷을 확인하세요
- 보안 키보드 등 추가 인증이 있는 경우 수동 로그인이 필요할 수 있습니다
- 결과 리포트는 `result/` 폴더에 저장됩니다
- 실제 계약/구매 확정 버튼은 자동화하지 않습니다
