안내사항

  • 1. 아이디 로그인
    • 기관회원/개인회원의 경우 범용공동인증서가 없거나, 등록하지 않은 경우 이용
  • 2. 공동인증서 등록
    • 공동인증서 등록/재등록을 선택하여 등록
    • 사업자용 범용공동인증서 등록
    • 개인 공동인증서 등록 불가
      ※ 아이디 로그인 후 MY desk > 회원정보에서도 공동인증서 등록가능
  • 3. 개인이용자 로그인 유지
    • 개인정보 보호를 위해 개인PC에서만 사용하시기바랍니다.
    • 브라우저의 쿠키를 삭제하거나, 로그아웃 시 로그인 유지는 해제됩니다.

로그인 실패 등의 접속불가 시 조치사항

  • 1. 인터넷 익스플로러
        가. 호환성 보기 사이트 추가
    • 상단메뉴 도구 → 호환성보기설정 → 이 웹사이트 추가란에 "s2b.kr" 입력후 추가 버튼 클릭 → 닫기
      ※http://www.s2b.kr, http://*. 형식은 불가
  •     나. 쿠키 및 캐시 삭제
    • 상단메뉴 도구 → 인터넷옵션 → (일반탭)검색기록의 "삭제"버튼 클릭 → (팝업창)"임시임터넷파일 및 웹사이트파일", "쿠키 및 웹사이트데이터"2가지 항목에 체크 → "삭제"버튼 클릭
  •     다. 팝업차단 해제
    • 상단메뉴 도구 → 인터넷옵션 → 개인정보탭 클릭 → "팝업차단사용"체크가 되어 있을 경우 체크 해제 → 확인버튼 클릭
      ※ S2B만 팝업해제를 원할 경우 "팝업차단사용" 옆 설정 버튼 클릭 → 허용
  • 2. 크롬
        가. 쿠키 및 캐시 삭제
    • Chrome 열기 → 오른쪽상단에서 클릭 → 도구 더보기를 클릭 → 인터넷 사용 기록 삭제를 클릭 → 상단에서 기간을 선택(전체기간 선택) → '쿠키 및 기타사이트 데이와'와 '캐시된 이미지 또는 파일' → 체크박스를 선택
  • 3. 엣지
        가. 쿠키 및 캐시 삭제
    • 엣지 열기 → 오른쪽상단에서 클릭 → 설정 클릭 → 개인정보, 검색 및 서비스 클릭 → 검색데이터 지우기에서 "지울항목 선택"버튼 클릭 → (팝업창)"쿠키 및 기타 사이트 데이터", "캐시된 이미지 및 파일" 선택 → 지금 지우기 버튼 클릭
  • 4. 공동인증서 로그인, 전자서명 프로그램 및 키보드 보안 프로그램 설치설치하기
