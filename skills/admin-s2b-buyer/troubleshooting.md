# S2B 자동 견적 담기 문제 해결 기록

## 2026-05-29 Excel 견적서 양식 지원 추가

### 요청

`list/자투리공간 체육물품 구입내역(화천초).xlsx` 같은 견적서 양식 Excel을 읽어 S2B 견적서(장바구니)에 담기까지 자동화.

### 개선 내용

- `s2b_excel.py`를 추가해 CSV와 Excel 입력을 공통 품목 구조로 변환하도록 했습니다.
- Excel 견적서의 `NO`, `G2B/S2B번호`, `품명 및 규격`, `수량`, `단위`, `단가`, `금액` 헤더를 자동 탐지합니다.
- `G2B/S2B번호` 셀에 `22852308 / 201611085168882`처럼 두 번호가 같이 있으면 마지막 긴 숫자열을 S2B번호로 사용합니다.
- S2B번호가 있는 품목은 검색 없이 상세 페이지 URL로 직접 이동합니다.
- S2B번호가 없는 품목은 기존처럼 품목명 검색 결과의 첫 번째 항목을 사용합니다.
- 웹 UI에 `엑셀 불러오기`, `S2B번호`, `수량` 열을 추가했습니다.
- CLI에서도 `.xlsx`, `.xlsm`, `.csv`를 모두 입력으로 받을 수 있게 했습니다.

## 확인된 문제와 조치

### 1. Excel의 G2B/S2B번호가 합쳐져 표시되는 문제

증상:

- Excel 셀 안에 G2B번호와 S2B번호가 줄바꿈 또는 `/`로 함께 들어 있습니다.
- UI에서 원본 셀 값을 그대로 넣으면 `22852308201611085168882`처럼 붙어 보일 수 있습니다.

조치:

- 파서에서 긴 숫자열을 모두 찾고, 마지막 값을 S2B번호로 추출하도록 했습니다.
- UI 입력칸에는 원본 코드보다 추출된 `s2b_id`를 우선 표시하도록 수정했습니다.

결과:

- 첫 번째 품목이 `201611085168882`로 정상 표시되고 실제 담기에도 이 번호가 사용됐습니다.

### 2. 모바일 화면에서 엑셀 불러오기 버튼 클릭이 막히는 문제

증상:

- 좁은 화면에서 기존 2열 레이아웃이 유지되며 파일 입력 영역 또는 헤더가 버튼 클릭을 가로막았습니다.

조치:

- `@media (max-width: 760px)` 반응형 규칙을 추가했습니다.
- 모바일에서는 좌측 로그인 카드와 품목 카드가 1열로 쌓이게 했습니다.
- 엑셀 업로드 영역도 1열로 접히게 했습니다.

결과:

- 390px 모바일 viewport에서 엑셀 업로드 후 8개 행 표시가 정상 확인됐습니다.

### 3. Flask 업로드 API 필요

증상:

- 기존 UI는 수동 검색어 입력만 지원해 Excel 파일을 바로 사용할 수 없었습니다.

조치:

- `/api/parse-excel` 엔드포인트를 추가했습니다.
- 업로드된 `.xlsx`, `.xlsm` 파일을 `parse_quote_workbook()`으로 읽어 JSON 품목 목록으로 반환합니다.

검증:

```text
POST /api/parse-excel
status: 200
count: 8
first item: 201611085168882, quantity 1
```

### 4. 기존 CLI가 CSV만 읽던 문제

증상:

- `s2b_buyer.py`가 `csv.DictReader`로만 입력을 처리했습니다.

조치:

- `load_purchase_items()`를 통해 확장자별로 CSV/Excel 파서를 선택하게 했습니다.
- 실행 인자명을 `csv_file`에서 `input_file`로 바꿨습니다.

검증 명령:

```bash
python s2b_buyer.py "list/자투리공간 체육물품 구입내역(화천초).xlsx"
```

결과:

```text
총 8개의 품목
S2B번호 직접 담기: 8건 / 품목명 검색: 0건
성공: 8건
실패: 0건
```

## 검증한 항목

- 샘플 Excel 파싱: 8개 품목 추출
- Python 컴파일: `s2b_excel.py`, `s2b_buyer.py`, `s2b_search.py`, `s2b_cart.py`, `s2b_report.py`, `s2b_login.py`, `app.py`
- 프론트엔드 JavaScript 문법 확인
- Flask `/api/parse-excel` 업로드 API 확인
- Playwright 화면 확인: desktop 1280x900, mobile 390x844
- 실계정 S2B 견적서 담기: 8건 성공

## 남은 주의점

- S2B 사이트 구조나 `fnSave()` 동작이 바뀌면 `s2b_cart.py`의 상세 페이지 처리와 팝업 대기 로직을 다시 확인해야 합니다.
- 보안 키보드, 추가 인증, 세션 만료가 발생하면 수동 개입이 필요할 수 있습니다.
- S2B번호가 없는 행은 품목명 검색 첫 결과를 선택하므로 실제 담기 전에 UI에서 선택 결과를 확인하는 것이 안전합니다.
- 이 자동화는 견적서 담기까지만 수행하며 실제 계약/구매 확정은 하지 않습니다.
