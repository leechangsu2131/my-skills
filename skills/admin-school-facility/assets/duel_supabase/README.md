# 퀴즈 듀얼 (Supabase) 설치 안내

두 학생이 서로의 QR을 찍어 만나면 같은 문제 5개를 풀고 점수를 겨루는 게임입니다.
정답·채점·승패는 모두 서버(SQL 함수)가 정하고, 화면은 보여 주기만 합니다.

## 파일
- `supabase/schema.sql` : 테이블, 보안 규칙(RLS), 서버 함수. SQL Editor에 통째로 붙여 실행
- `supabase/seed_questions.sql` : 예시 문제 12개 (학년에 맞게 고치세요)
- `web/duel.html` : 학생용 화면 (파일 하나). 위쪽의 `SUPABASE_URL`, `SUPABASE_ANON_KEY` 두 줄만 바꿉니다

## 설치 순서
1. https://supabase.com 에서 프로젝트를 만듭니다. 지역은 가까운 곳을 고릅니다.
2. **Authentication → Sign In / Providers**에서 *Allow anonymous sign-ins*를 켭니다. (학생은 이메일 없이 별명만 씁니다)
3. **SQL Editor**에서 `schema.sql` 전체를 실행하고, 이어서 `seed_questions.sql`을 실행합니다.
4. **Project Settings → API**에서 *Project URL*과 *anon public key*를 복사해 `duel.html` 위쪽에 넣습니다.
   - `anon` 키는 공개되어도 되는 키입니다(보안은 서버 규칙이 지킵니다). **`service_role` 키는 절대 넣지 마세요.**
5. `duel.html`을 GitHub Pages 등 정적 호스팅에 올립니다. (저장소 → Settings → Pages)
6. 휴대폰 두 대로 접속해 한 대의 QR을 다른 대로 찍어 봅니다.

## 문제 관리
Supabase **Table Editor → questions**에서 문제를 추가·수정합니다. `choices`는 보기 4개(JSON 배열), `answer`는 정답 번호(첫째=0 … 넷째=3), `active`를 끄면 출제에서 빠집니다. 정답 열은 학생 화면으로 전달되지 않습니다.

## 꼭 알아 둘 점
- **학교 와이파이에서 처음 접속이 막힐 수 있습니다.** 익명 로그인은 같은 IP에서 시간당 횟수 제한이 있습니다(기본 30회 안팎). 학교 와이파이는 학생들이 같은 IP로 보여서, 한 반이 한꺼번에 처음 접속하면 걸릴 수 있어요. 학생 기기는 한 번 로그인하면 계속 유지됩니다. 반별로 나눠 시작하거나, Authentication → Rate Limits에서 값을 확인·조정하세요(조정 가능 여부는 요금제와 버전에 따라 다릅니다).
- **무료 프로젝트는 7일 동안 쓰지 않으면 일시정지**됩니다. 방학 전후에 확인하거나 주기적으로 접속 신호를 보내 두세요. 무료 한도(동시 실시간 접속 200 등)는 바뀔 수 있으니 가격 페이지에서 확인하세요.
- 저장하는 정보는 **별명(12자)과 팀 이름(8자, 예: 5-2)** 뿐입니다. 실명·IP·위치는 저장하지 않지만, 외부 클라우드를 쓰는 것이므로 학교의 클라우드 서비스 사용 규정과 만 14세 미만 개인정보 기준을 확인하세요.
- 대결 중 채팅은 없습니다. 순위는 개인이 아니라 **팀(학급) 단위**만 보여 줍니다.
- 시험한 것: 서버 규칙(채점, 시간 제한, 정답 비공개, 권한)은 로컬 PostgreSQL에서 36가지로 확인했습니다. 실제 Supabase(실시간 알림, 익명 로그인)와 화면은 직접 접속해서 확인해 주세요.

## 규칙 요약
- 한 판 5라운드, 라운드당 20초. 정답 10점, 둘 다 맞히면 먼저 답한 쪽 +3점.
- 한 사람은 한 번에 하나의 대결만 할 수 있고, 10분 넘게 멈춘 대결은 자동으로 정리됩니다.
- 시간 안에 답하지 않으면 그 라운드는 0점으로 넘어갑니다.
