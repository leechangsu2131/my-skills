# 카카오톡 챗봇으로 대여·반납·예약 (설치 안내)

선생님들이 이미 쓰는 **스쿨투두 카톡 채널 하나**에서 시설 관리 시트까지 다룬다.
시트는 두 개(일정DB, 시설 관리)로 따로 두고, Cloudflare 중계기가 말머리를 보고 나눠 보낸다.

```
카톡 → 오픈빌더 스킬 → Cloudflare 중계기 ─┬─ 대여·반납·예약·빈곳·내 신청·시설… → 시설 관리 웹앱 (Code.gs + Chatbot.gs)
                                          └─ 그 밖의 말                       → 일정DB 웹앱 (school-todo-kakao)
```

> 코드는 가짜 시트로 시험했다(`scripts/test_chatbot.js` 47개, `scripts/test_router.mjs` 24개).
> 실제 카카오·Cloudflare·구글 연결은 설치한 뒤 직접 확인해야 한다.

## 설치 순서
1. **시설 관리 시트 → 확장 프로그램 → Apps Script**에 `Code.gs`, `Index.html`이 이미 있으면 `Code.gs`를 새 것으로 바꾸고, **파일 추가(+) → 스크립트 → `Chatbot`** 을 만들어 `Chatbot.gs` 내용을 붙여 넣는다.
2. 프로젝트 설정 → **스크립트 속성**에 `CHATBOT_SECRET` = 20자 이상의 영문·숫자 (새로 만든 값). `ACCESS_CODE`, `ADMIN_CODE`는 기존 그대로.
3. **배포 관리 → 연필 → 새 버전 → 배포** (웹앱 주소는 그대로 유지된다). 처음 배포라면 실행 사용자 **나**, 액세스 **모든 사용자**.
4. **Cloudflare 중계기**(스쿨투두에서 만든 워커) 코드를 `assets/kakao/cloudflare_router.js`로 바꾸고, 변수에 두 개 추가 후 배포:
   - `FACILITY_URL` = 시설 관리 웹앱 주소(…/exec)
   - `FACILITY_KEY` = 2번의 `CHATBOT_SECRET` 값
   기존 변수(`KAKAO_KEY`, `APPS_SCRIPT_URL`, `APPS_KEY`)와 오픈빌더 스킬 URL은 **바꾸지 않는다.** `FACILITY_URL`을 비우면 예전과 똑같이 동작하므로 되돌리기도 쉽다.
5. 카톡에서 `시설`이라고 보내 사용법이 나오면 연결된 것이다.

비밀값은 중앙 `.env`에 `ADMIN_SCHOOL_FACILITY__CHATBOT_SECRET`처럼 기록해 두고, 저장소·문서에는 적지 않는다.

## 선생님 연결 (한 사람당 한 번)
- **스스로**: 웹앱 "내 신청"에서 PIN을 정한 뒤, 카톡에 `시설등록 이름 PIN`. 이후 카톡에서는 PIN을 묻지 않는다.
- **관리자가**: 선생님이 카톡에 아무 시설 말이나 보내면 나오는 아이디를 받아 `챗봇연결` 탭에 `이름 / 챗봇아이디`로 적는다.
- 같은 채널이라 스쿨투두 `구성원` 탭의 챗봇아이디와 **같은 값**이다. 그 값을 그대로 옮겨 적어도 된다.
- 이름은 설정 탭 신청자 명단(H열)과 글자가 같아야 한다. 명단에서 빠지면 카톡 연결도 자동으로 막힌다.

## 카톡에서 하는 말
| 말 | 결과 |
|---|---|
| `시설` | 사용법 |
| `대여 빔프로젝터` | 오늘 하루 1개 대여(이름이 정확히 같은 물품이 하나면 바로, 여럿 맞으면 관리번호로 다시 묻는다) |
| `대여 B-0001 2개 3일` / `대여 노트북 내일부터 금요일까지` | 수량·기간 지정 (최대 30일) |
| `반납` / `반납 빔프로젝터` / `반납 R0003` | 빌리고 있는 것이 하나면 바로, 여럿이면 목록 |
| `대여취소 R0003` | 시작 전 대여 취소 |
| `예약 강당 내일 3교시 학년 행사` | 공간 예약(뒤의 말은 목적). 승인 필요 공간은 ⏳승인대기 |
| `예약취소 12` | `내 신청`에 나오는 번호로 취소 |
| `빈곳 내일 3교시` | 그 시간 비어 있는 예약 공간 |
| `내 신청` | 내 대여·앞으로의 예약 |

날짜: 오늘·내일·모레·글피, 월~일(오늘 포함 가장 가까운 날), 다음주화요일, 12/3, 12월3일, 2026-12-03.
교시: 설정 탭 B열 이름(`3교시`, `점심`, `방과후`) 또는 숫자만(`3`).

## 규칙과 한계
- 대여·예약 규칙(수량·기간 겹침, '양호' 상태만, 정규 수업 시간 막기, 한 시간에 한 곳, 승인 필요 공간)은 웹앱과 **같은 함수**를 쓴다. 규칙을 바꾸면 `node scripts/test_server.js`와 `node scripts/test_chatbot.js`를 둘 다 돌린다.
- 카카오 스킬은 몇 초 안에 답해야 한다. 시트가 크면 느려질 수 있다. 동시에 몰리면 "잠시 뒤 다시 보내 주세요"라고 답한다.
- `시설등록`에 적은 PIN은 카카오 서버를 거친다. 꺼림직하면 관리자 연결 방식을 쓴다.
- 대화 내용은 카카오 서버를 거치므로 예약 목적에 학생 이름을 적지 않게 안내한다.
- 중계기의 말머리 목록(`FACILITY_WORDS`)에 없는 말은 일정DB로 간다. 스쿨투두에 같은 말머리를 새로 만들면 겹치므로 둘 중 하나를 바꾼다.
