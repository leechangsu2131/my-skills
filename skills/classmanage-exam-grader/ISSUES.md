### ISSUE-001: 임시 그림 파일 42개가 공개 저장소에 올라가 있음 (2026-11-25)
- **상태**: 🟢 해결 (2026-11-26, 교사 지시 "빼자" — 브랜치 fix/untrack-tracked-outputs)
- **증상**: `python tools/build_catalog.py --check` 의 새 경고(T24)가 `tmp_answer_key_pages/`, `tmp_answer_region_debug/`, `tmp_blank_layout_debug/`, `tmp_blank_layout_debug_120/` 폴더와 `tmp_*.png` 파일 3개, 모두 42개 파일이 git 에 추적된다고 알림.

- **해결/조치**: 42개를 저장소에서 빼고 `.gitignore` 에 `skills/classmanage-exam-grader/tmp_*` 를 넣어 다시 올라오지 않게 함(스킬의 코드·문서는 그대로). 교사 PC 에 같은 이름 파일이 있으면 이 변경을 합칠 때 지워질 수 있으니, 필요하면 합치기 **전에** 다른 곳(`data_dir()`)에 복사해 둘 것. 예전 기록은 ISSUE-002.
