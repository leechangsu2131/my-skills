다음은 학생이 작성한 시험지 PDF입니다.
이 시험지에서 학생의 정보와 각 문제의 답안을 정확하게 추출해 주세요.

## 추출 규칙

1. 학생 이름과 번호가 있으면 반드시 추출합니다.
2. 각 문제의 번호와 학생이 작성한 답을 정확하게 읽습니다. 특히 손글씨 텍스트를 최대한 판독하고, 빈칸인 경우에만 빈 문자열("")을 넣으세요.
3. 객관식은 선택한 번호를, 단답형은 작성한 텍스트를, 서술형은 전체 내용을 추출합니다.
4. 읽기 어려운 글씨는 문맥을 고려하여 최선을 다해 판독하되, 확신이 낮으면 confidence를 "low"로 표시합니다.
5. 아무것도 작성하지 않은 문제는 answer를 빈 문자열("")로 합니다.
6. 시험 제목이 보이면 exam_title에 넣습니다.

## 출력 형식

반드시 아래 JSON 형식으로만 출력하세요. JSON 외의 텍스트는 포함하지 마세요.

```json
{
  "student_name": "학생 이름",
  "student_number": 1,
  "exam_title": "시험 제목 또는 null",
  "answers": [
    {
      "q_num": 1,
      "type": "multiple_choice",
      "answer": "3",
      "confidence": "high"
    },
    {
      "q_num": 2,
      "type": "short_answer",
      "answer": "24",
      "confidence": "high"
    },
    {
      "q_num": 3,
      "type": "descriptive",
      "answer": "삼각형의 넓이는 밑변 곱하기 높이 나누기 2이므로...",
      "confidence": "medium"
    }
  ]
}
```

type 값은 다음 중 하나:
- "multiple_choice": 객관식 (번호 선택)
- "short_answer": 단답형 (짧은 텍스트/숫자)
- "descriptive": 서술형 (긴 텍스트)
- "unknown": 유형 판별 불가

confidence 값은 다음 중 하나:
- "high": 명확하게 판독 가능
- "medium": 대체로 판독 가능하나 일부 불확실
- "low": 판독이 어려움

JSON만 출력하세요.
