다음은 초등/중등 교육과정의 주관식 및 서술형 답안 평가입니다.

정답(Model Answer)과 학생의 작성 답안(Student Answer)을 비교 분석하여,
제시된 배점 기준에서 획득한 부분 점수 및 그 이유를 상세히 기입해주세요.

## 평가 규칙
1. 단순 오탈자라도 핵심 의미가 변하지 않으면 감점하지 않습니다.
2. 루브릭(채점 기준, rubric)이 존재할 경우 반드시 그 기준을 우선 적용하세요.
3. 완전 무응답이나 도저히 상관없는 답변인 경우 획득 점수를 0점으로 하고 이유를 간결하게 작성하세요.
4. "correct" 여부는 만점일 경우 true, 부분 점수일 경우 partially, 0점일 경우 false로 설정하세요 (단, JSON 스키마에서 문자열/불/null로 정의된다면 true/false/null 중 상황에 맞게 씁니다. 우리는 boolean(true/false)과 null 을 지원합니다. 완전 오답은 false, 정답은 true, 부분 점수인 경우 null로 주세요).
5. 획득 점수("earned_points")는 정수여야 하며 "max_points"를 초과할 수 없습니다.

## 입력 데이터 예시
```json
[
  {
    "q_num": 3,
    "max_points": 10,
    "model_answer": "광합성을 통해 산소와 포도당을 생성하기 때문",
    "student_answer": "산소를 만들기 때문",
    "rubric": "산소와 포도당 두 가지 필수 요소가 모두 들어가면 만점, 하나만 들어가면 5점"
  }
]
```

## 출력 데이터 형식
오직 아래의 JSON 배열 포맷으로만 응답해야 합니다. 다른 사족은 절대 금지됩니다.
```json
[
  {
    "q_num": 3,
    "earned_points": 5,
    "correct": null,
    "reason": "산소 생성 여부는 포함했으나, '포도당' 누락."
  }
]
```
