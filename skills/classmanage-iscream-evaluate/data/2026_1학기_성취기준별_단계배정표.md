# 2026학년도 3학년 1학기 성취기준별 학생 단계 배정표 (v3)

영어·과학·체육(전담교사 담당)을 제외한 도덕·국어·수학·사회·음악·미술·창체에 대해
단계(매우잘함/잘함/노력요함)를 배정한 표입니다.

## 추정 방식 (v3 개선)
- **(추정)** 표시가 없는 값: 실제 점수 또는 관찰 기반 실측 결과
- **(추정)** 표시가 있는 값: 아래 과목별 근거에 따라 다르게 추정함
  (일괄 "전체 경향" 복사 방식을 사용하지 않음)

| 과목/영역 | 추정 시 사용 근거 |
| --- | --- |
| **도덕 2단원(성실)** | 수업태도 + 수학 수준(학습 성실도) + 국어 수준(언어이해) 평균 |
| **도덕 3단원(효)** | 수업태도 + 사회 수준(공동체 이해) + 국어 수준 평균 |
| **사회 01-01** | 실측(01-02) 그대로 사용 |
| **사회 02-02** | 실측 우선, 없으면 사회 01-02 적용 |
| **음악 1단원** | 실측 우선, 없으면 수업태도+미술표현 수준 평균 |
| **음악 2단원** | 실측(6/12 춤 관찰) 우선, 없으면 음악 1단원 적용 |
| **미술 4단원** | 미술 2단원 수준 그대로 적용(같은 교과, 직전 단원) |
| **창체 자율(학교폭력예방교육)** | 수업태도 + 국어 수준(언어감수성) 평균 |
| **창체 동아리(독서동아리)** | 수업태도 + 국어 수준(독서와 직결) 가중평균 |
| **창체 진로(자기이해)** | 수업태도 + 사회 수준 + 국어 수준 평균 |
| **수학 1~3 (김주안)** | 사회·국어·태도 결합 수준으로 추정 |
| **수학 1~3 (최윤채)** | 수학 4단원(같은 교과, 실측) 적용 |
| **국어 1단원 (최윤채)** | 국어 4단원(같은 교과, 실측) 적용 |
