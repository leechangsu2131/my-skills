## 📌 백로그

### ISSUE-002: 게시판 셀렉터 자동 감지 (2026-11-13)
- **상태**: 📌 백로그
- **증상**: 새 게시판을 연결할 때마다 probe 스크립트로 HTML을 살펴보고 목록 요소의 선택자(CSS 셀렉터)를 직접 확인해야 함.
- **원인**: 크롤러가 게시판 종류별 선택자를 자동으로 찾아보는 기능이 아직 없음.
- **해결/조치**: URL만 입력해도 아래 순서로 목록 구조를 찾아보도록 개선한다.
  - `table.board-list`
  - `ul.board-list`
  - `div.board-list`
  감지하지 못하면 어떤 구조를 찾지 못했는지 사용자에게 분명히 알린다.
- **수락 기준**:
  - [ ] 위 세 선택자를 차례로 시도한다.
  - [ ] 감지 실패 시 명확한 오류 메시지를 보여 준다.
- **관련 파일**: `scripts/probe_school.py`, `scripts/crawl_notices.py`

### ISSUE-003: 여러 학교 지원 (2026-11-13)
- **상태**: 📌 백로그
- **증상**: 다른 학교 게시판을 추가할 때 크롤러 코드의 `BOARD_CONFIGS`를 직접 수정해야 함.
- **원인**: 학교별 주소·게시판 정보가 코드 안에 들어 있고 외부 설정 파일을 읽는 기능이 없음.
- **해결/조치**: `config/schools.yml`에 학교별 URL·bbsId·게시판 이름을 적고, 크롤러가 이 파일을 읽어 여러 학교를 처리하도록 바꾼다.
- **수락 기준**:
  - [ ] `config/schools.yml`에 학교별 URL·bbsId·이름을 관리한다.
  - [ ] 크롤러가 설정 파일을 읽어 게시판별로 처리한다.
- **관련 파일**: `scripts/crawl_notices.py`, `config/schools.yml`(추가 예정)

### ISSUE-004: 새 게시글 감지 알림 (선택) (2026-11-13)
- **상태**: 📌 백로그
- **증상**: 새 게시글이 올라와도 크롤링 결과를 직접 열어 보지 않으면 새 글 등록 사실을 알 수 없음.
- **원인**: 이전 `notices.json`과 새 결과를 비교해 알림을 보내는 기능이 아직 없음.
- **해결/조치**: 이전 결과와 새 결과를 비교해 새 항목만 추리고, 필요성을 확인한 뒤 Supabase Edge Function 또는 GitHub Actions에서 FCM 푸시를 보내는 방안을 검토한다.
- **참고**: 업로드된 프로토타입 `school-notice-notifier` 모듈을 살펴볼 수 있음.
- **수락 기준**:
  - [ ] 이전 `notices.json`과 새 결과를 비교해 신규 항목을 추출한다.
  - [ ] Supabase Functions 또는 GitHub Actions에서 FCM API를 호출한다.
- **관련 파일**: `scripts/crawl_notices.py`, `.github/workflows/crawl_notices.yml`, `school-notice-notifier`(프로토타입)

- **수락 기준**:
  - [ ] 전화번호·이메일 모양의 가림 시험을 만든다.
