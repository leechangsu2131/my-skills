## 📌 백로그

### ISSUE-001: `_looks_like_price` 가 '원'이 든 지역·제목을 가격으로 읽음 (2026-11-25)
- **상태**: 📌 백로그
- **증상**: `수원시 · 3시간 전`, `원피스 팝니다` 가 가격으로 판단됨 → 가격이 아닌 줄을 기준으로 가짜 상품이 만들어지거나 진짜 가격 앞 줄(지역)이 제목 후보에서 밀릴 수 있음(추정, 실제 화면에서 확인 필요)
- **원인**: `indicators` 에 `원` 한 글자가 있어 `in` 검사로 걸림
- **해결/조치**: 미정(예: `숫자+원`, `만원` 꼴일 때만 가격). 교사 PC 에서 폰으로 확인 필요. 시험은 xfail
- **관련 파일**: `collector/daangn_app.py` `_looks_like_price`, `tests/test_pure_functions.py`

### ISSUE-002: `parse_price` 가 '천' 단위와 '만+천' 표기를 못 읽음, 점이 여러 개면 멈춤 (2026-11-25)
- **상태**: 📌 백로그
- **증상**: `3천원` → 3, `10만5천원` → 100000(5천 누락), `1.2.3만원` → `ValueError: could not convert string to float: '1.2.3'`
- **원인**: 정규식이 `만` 앞 숫자만 읽고 `천` 을 처리하지 않으며, `[\d.]+` 를 검사 없이 `float()` 에 넣음
- **해결/조치**: 미정. 실제 당근 화면에 이런 표기가 나오는지는 확인 필요. 시험은 xfail
- **관련 파일**: `collector/models.py` `parse_price`

### ISSUE-003: 빈 목록과 값이 있는 목록의 열 이름이 다름 (2026-11-25)
- **상태**: 📌 백로그
- **증상**: `products_to_dataframe([])` 의 열은 한글 머리글(`수집일시`…), 값이 있으면 영어 열 이름(`collected_at`…)이라 빈 결과를 CSV 로 저장하면 머리글이 달라짐
- **원인**: 빈 경우만 `Product.sheet_header()` 를 씀
- **해결/조치**: 미정. 시험은 xfail
- **관련 파일**: `collector/extractor.py` `products_to_dataframe`

### ISSUE-004: 수집 결과 저장 위치가 스킬 폴더 기준 상대 경로 (2026-11-25)
- **상태**: 📌 백로그
- **증상**: `save_to_json`·`save_to_csv`·`DaangnDB` 기본값이 `data/` (실행한 폴더 기준)라 저장소 폴더 안에 수집한 매물 자료(개인 거래 정보 포함 가능)가 생길 수 있음. README 규칙은 `data_dir()` 아래에만 저장
- **원인**: `data_dir()` 를 쓰지 않는 기본값
- **해결/조치**: 미정(`config.json` 의 `output.json_dir` 값 확인 필요). 시험은 모두 임시 폴더를 지정해서 저장소에는 아무것도 만들지 않음
- **관련 파일**: `collector/extractor.py`, `storage/sqlite_db.py`, `config.json`
