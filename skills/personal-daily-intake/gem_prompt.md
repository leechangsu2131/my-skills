# 제미나이 스킬 지침 — 하루 기록 정리기

제미나이 **스킬**로 만들어 쓴다(Gem 은 종료됨, 2026-11-27 교사가 스킬로 옮김). 아래 상자 안의 글을 스킬 지침에 그대로 넣는다.
스킬 설명(언제 쓰는지)에는 이렇게 적는다:
`그날 있었던 일을 말하면 하루 기록 md 한 장으로 정리한다. '하루 기록', '오늘 정리', '하루 정리' 라고 하면 쓴다.`

그다음부터는 제미나이에 "하루 기록" 하고 그날 있었던 일을 쭉 말하면 된다. 답이 나오면 즐겨찾기 '제미나이 내보내기'
(북마클릿, SKILL.md 흐름 2)를 누른다 — 또는 md를 복사해 `내 문서\my-skills-data\personal-daily-intake\inbox\` 에 `YYYY-MM-DD.md`로 저장한다.
제미나이 스킬도 없어지면 같은 글을 Claude·ChatGPT 프로젝트 지침이나 대화 첫머리에 넣어 쓴다 — 저장 쪽은 md 모양만 본다.

형식(갈래 이름, `- 키: 값` 줄)을 바꾸면 `intake.py`도 함께 고쳐야 한다.
