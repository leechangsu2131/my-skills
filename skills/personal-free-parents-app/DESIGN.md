# 한명만 (One Parent Watch) — DESIGN.md v2.0

> 이 문서는 디자인 결정의 **이유**까지 기록한다.
> "어떻게 생겼는가"보다 "왜 이렇게 생겼는가"가 더 중요하다.

---

## 1. 콘셉트 — 한낮의 그늘 (Midday Shade)

이 앱의 핵심 경험은 두 가지 상태의 대비다.

> **감독하는 한 명**은 햇볕 속에 있다. 따뜻하고 명확하고 책임이 있다.
> **쉬는 부모들**은 그늘 속에 있다. 시원하고 고요하고 자유롭다.

이 은유가 색, 레이아웃, 타이포그래피, 애니메이션의 모든 결정을 지배한다.
디자인의 어떤 요소도 이 은유를 배반하지 않는다.

## 2. 색 시스템 (Color Tokens)

### 원칙
- **색이 상태를 말한다.** 글자를 읽기 전에 색만으로 "지금 감독 중인지, 쉬는 중인지"를 알아야 한다.
- **차갑지 않다.** 흰색 배경 대신 따뜻한 양피지(Parchment)를 쓴다. 이 앱은 놀이터, 오후 햇살, 벤치의 세계다.
- **그린은 금지 색이 아니다 — 단, 짙어야 한다.** 흔한 세이지그린(#6B9E7A)은 쓰지 않는다. 숲의 그늘처럼 깊어야 한다.

```
── 햇볕 영역 (Warm / Sun Zone) ──────────────────────────────

parchment   #F6EFD8   메인 배경. 따뜻한 양피지. 순백이 아닌 오후의 종이색.
amber       #C07A22   주 액션 컬러. 오후 햇살. 버튼, 강조, 현재 감독자 표시.
amberGlow   #EDD49A   햇살 번짐. 감독 화면 상단 존 배경 그라디언트 끝값.
amberPale   #FAF4E4   거의 흰색에 가까운 따뜻함. 강조 카드 배경.
sunZone     #F2E5C0   감독화면 상단 존 전용. amber와 parchment의 중간.

── 그늘 영역 (Cool / Shade Zone) ────────────────────────────

forest      #192B1B   짙은 숲. 감독화면 하단 존. 쉬는 부모들의 공간.
canopy      #3A6630   수관 녹색. forest보다 밝은 포인트. "다음" 뱃지.
sage        #7CAF6E   잎사귀 연녹. 그늘 존 아이콘, 구분선.
mist        #B4D4A8   안개 연녹. 그늘 존 텍스트 전용. 어두운 배경 위 가독성.

── 중립 (Neutral) ────────────────────────────────────────────

warmGray    #E8DFC8   드라이그라스. 카드 배경, 비활성 서피스.
bark        #5C4B28   나무껍질 갈색. 서브 텍스트, 레이블. gray 대신 쓴다.
ink         #18180E   따뜻한 검정. 메인 텍스트. 순흑(#000)이 아닌 숲의 밤색.
smoke       #8A8472   캡션, 힌트, 비활성 텍스트.

── 유틸리티 (Utility) ───────────────────────────────────────

error       #B03020   긴급 버튼, 경고. 붉은 점토색. 순빨강 대비 덜 자극적.
white       #FFFDF3   가장 밝은 서피스. 카드 위, 바텀시트 배경.
```

### 색 조합 규칙
```
배경 위 텍스트
  parchment + ink        ✅
  parchment + bark       ✅ (서브)
  forest    + mist       ✅
  forest    + sage       ✅ (아이콘/구분선)
  amber     + white      ✅ (버튼 내부)

절대 쓰지 않는 조합
  parchment + smoke      ❌ 대비 부족
  forest    + bark       ❌ 대비 부족
  amber     + amberGlow  ❌ 구분 불가
```

## 3. 타이포그래피

**폰트**: Noto Sans KR (Google Fonts)
- 이유: 영문/숫자/한글이 모두 같은 계열로 처리된다. 다른 폰트를 섞지 않는다.
- 굵기는 400(Regular), 700(Bold), 900(Black) 세 가지만 쓴다.

### 타입 스케일

```
역할            크기    굵기    색         용도
─────────────────────────────────────────────────────────────
Display Timer   82px    900     ink        감독화면 타이머. 이 앱의 심장.
Wordmark        20px    900     forest     "한명만" 앱 이름
H1              24px    900     ink        화면 제목 (그룹 생성, 온보딩)
H2              22px    900     ink        바텀시트 놀이터명
H3              18px    700     ink        카드 제목
Body Large      15px    700     ink        리스트 항목, 강조 본문
Body            14px    400     ink        일반 본문
Body Small      13px    400     smoke      보조 설명
Caption         11px    600     smoke/bark 레이블, 뱃지 내 텍스트
Timer Colon     60px    900     amber      타이머 콜론(:). 크기를 본체보다 작게.
```

### 타이포그래피 규칙
- `letter-spacing`: H1 이상은 `-0.5px` 이상 음수 자간. 굵은 한글은 붙어야 힘이 생긴다.
- `font-variant-numeric: tabular-nums`: 타이머 숫자 전용. 자릿수가 바뀌어도 레이아웃이 흔들리지 않는다.
- 줄바꿈이 필요한 제목은 `line-height: 1.2`. 본문은 `line-height: 1.6`.

```
텍스트:   white (#FFFDF3), 16px, 700
```

```
함께하는 부모 bg #EDD49A / text #5C3D08 / dot #C07A22  (amber 계열)
새내기 부모   bg #E4DFD3 / text #5C4B28 / dot #8A8472  (smoke 계열)
```

### 7-3. MiniCard (홈 하단 가로 스크롤 카드)

```
너비:       150px min
배경:       white
테두리:     1.5px warmGray → (hover) amber
radius:     16px
내용:       이름 / 상태 도트+텍스트 / 인원수·거리
```

### 7-4. 감독 타이머 영역 (Sun Zone)

감독화면의 서명 컴포넌트. 다른 화면에는 등장하지 않는다.

## 8. 애니메이션

애니메이션은 4가지만 쓴다. 더 추가하지 않는다.

```
ping      1.8s cubic-bezier(0,.2,.8,1) infinite
          — 활성 놀이터 마커 외부 원. "지금 뭔가 일어나고 있다"는 신호.

sunRay    3s ease-in-out infinite
          — 감독 화면 햇살 방사. opacity .12↔.22, scale 1↔1.06.
          — 매우 느리고 조용해야 한다. 호흡처럼.

breathe   4s ease-in-out infinite
          — 감독 화면 Sun Zone 전체. scale 1↔1.02.
          — 살아있는 느낌. 너무 빠르면 불안하다.

slideUp   .32s cubic-bezier(.22,1,.36,1)
          — 바텀시트 등장. spring 곡선으로 자연스럽게.

fadeIn    .25s ease
          — 화면 전환 기본.
```

**금지 애니메이션**:
- 무한 로딩 스피너 (작업 완료 후 즉시 제거)
- 화면 전환 슬라이드 (좌우 이동 — 앱의 계층 구조가 단순해서 불필요)
- 탭 클릭 시 리플 효과 (너무 일반적)

## 10. 화면별 디자인 결정 노트

### 홈 (지도 화면)
- 지도가 화면의 70% 이상을 차지한다. 앱의 진입점은 지도다.
- 상단 헤더는 최소화. 워드마크 + 검색 + 프로필만.
- 하단 드로어는 "핸들 탭 → 확장"으로 두 단계. 기본 상태는 가로 스크롤 미니카드.
- 플로팅 네비게이션 바를 쓰지 않는다. 지도 위에 겹치는 요소를 최소화.

### 바텀시트 (놀이터 상세)
- 지도를 완전히 가리지 않는다. 상단 28%는 지도(축소)가 보인다.
- "미니 썬/쉐이드 카드"로 전체 감독 화면의 축소판을 미리 보여준다.
  사용자가 합류 전에 현재 상태를 파악할 수 있다.
- 긴급 버튼은 지도 영역(상단)에 고정. 바텀시트가 올라와도 항상 보인다.

### 감독 화면 (서명 화면)
- 이 화면이 전체 앱의 정체성이다. 다른 모든 화면은 여기로 오기 위한 흐름.
- 상태 칩("☀️ 지금 감독 중" / "🌿 지금 쉬는 중")을 탭하면 토글된다.
  → 데모 목적이며, 실제 앱에서는 타이머 도달 시 자동 교대.
- 타이머는 화면에서 가장 크다. 82px 900 weight.
  이유: 놀이터에서 햇빛 아래 잠깐 화면을 볼 때 한눈에 읽혀야 한다.
- 파도 SVG 구분선은 CSS border가 아니라 SVG path로 그린다.
  수평선이 아닌 유기적 곡선이어야 "그늘"의 느낌이 산다.

### 그룹 생성 (4단계)
- 각 단계는 하나의 질문만 한다.
- 진행 표시줄은 숫자 없이 색 채움만. "1/4"보다 시각적 진행이 덜 부담스럽다.
- 마지막 단계(동의) 체크박스 없이는 버튼이 활성화되지 않는다.
  법적 설계 원칙(19-1번) 강제 구현.

### 온보딩
- 기능 설명보다 감성 전달 먼저. 슬라이드 3개는 "왜 이 앱인가"다.
- 전화번호 인증 → 소속 선택. 2단계 이상의 개인정보를 요구하지 않는다.
- 소속 선택 카드는 아이콘이 크다(24px). 선택된 항목에 amber 테두리.

## 11. 접근성 기준

```
명도 대비 (WCAG AA 기준 4.5:1 이상)
  ink (#18180E) on parchment (#F6EFD8)   → 13.8:1  ✅
  mist (#B4D4A8) on forest (#192B1B)     → 7.2:1   ✅
  amber (#C07A22) on white (#FFFDF3)     → 4.7:1   ✅
  white (#FFFDF3) on amber (#C07A22)     → 4.7:1   ✅
  smoke (#8A8472) on parchment           → 3.4:1   ⚠️ 캡션 전용만 허용

터치 타깃
  최소 48×48px. 긴급 버튼은 54px.
  지도 마커는 탭 영역 44px 이상 확보.

모션 감소
  prefers-reduced-motion 시 ping, sunRay, breathe 비활성.
  slideUp, fadeIn은 유지 (정보 전달에 필요).
```

```
       "마이페이지"             — "내 정보"
       "아이를 맡긴다"          — 법적 원칙(19-1번)에 따라 금지
```

## 13. 아이콘 사용 원칙

이모지를 아이콘으로 쓴다. 별도 아이콘 라이브러리를 쓰지 않는다 (MVP 원칙).

```
🛝  놀이터 마커, 빈 상태
☀️  감독 중 상태
🌿  쉬는 중 상태
🚨  긴급 버튼
🏢  아파트 소속 마커
🏫  어린이집 소속 마커
🚄  신경주역 (지도 내)
📍  거리/위치 표시

←   뒤로 가기

```

Beta 이상에서 아이콘 라이브러리(lucide-react 등) 도입 검토.
단, 이모지와 벡터 아이콘을 혼용하지 않는다.
