# PKM 속성 관리 도구 — 사용 설명서

## 실행 방법

```
python pkm_manager.py
```

Python 3.8 이상 필요. 추가 설치 없음 (표준 라이브러리만 사용).

---

## 주요 기능

### 1. Vault 불러오기
- 상단 **[폴더 선택]** → Google Drive 안의 Obsidian Vault 폴더 선택
- **[파일 불러오기]** 클릭 → 전체 .md 파일 목록 표시

### 2. 파일 선택
| 방법 | 설명 |
|------|------|
| 클릭 | 단일 선택 |
| Ctrl+클릭 | 여러 개 선택 |
| Shift+클릭 | 범위 선택 |
| [전체 선택] | 필터된 파일 전체 선택 |
| 검색창 입력 | 파일명으로 실시간 필터 |
| domain/engine 필터 | 이미 속성 붙은 것만 필터 |

### 3. 속성 추가 (핵심 기능)
1. 파일 선택
2. 오른쪽 패널에서 속성 값 선택
   - `domain`: 수업/학급/투자/자기/관계/DIY/생산성/횡단
   - `engine`: concept/pattern/principle/experiment
   - `type`: 수업안/감상문/거시예측/시장일지/자서전/리소스
   - `topic`: 직접 입력
3. **[✅ 속성 추가/수정]** 클릭

> **"기존 값 덮어쓰기" 체크 안 하면** → 이미 값 있는 것은 그대로 두고, 빈 것만 채움  
> **체크하면** → 모두 덮어씀

### 4. 자동 추천 ✨
- 파일 1개 선택 후 **[인덱스 매핑 자동 추천]** 클릭
- v6 인덱스 기반으로 domain/engine 자동 제안
- 인덱스에 있는 노트 80개에 대해 자동 매핑 적용

### 5. 속성 제거
- 제거할 속성 콤보박스에서 선택 후
- **[🗑 속성 제거]** 클릭

### 6. 되돌리기 ⏪
- **모든 변경 전 자동으로 백업** 생성 (같은 폴더 내 `_PKM_BACKUP/`)
- **[되돌리기]** → 가장 최근 백업으로 복원
- 백업 파일은 절대 자동 삭제되지 않음

### 7. PARA 소배치 이관 🚚
- 오른쪽 아래 **[PARA 소배치 이관]** 섹션에서 source 폴더와 batch size를 선택
- 기본 권장 시작점: `3 Resources(관심사, area를 위한)/코딩 소프트웨어 스마트작업`
- **[🔎 배치 검토]**를 누르면 5~10개 노트를 자동 검토하고 `reports/pkm-batches/`에 보고서를 생성
- 상태는 `ready / needs_review / link_sensitive / conflict`로 표시됨

### 8. 2단계 이관 흐름
1. **배치 검토**
   - 현재 경로, 현재 YAML, 추천 YAML, 추천 목적지, 보류 사유를 보고서로 확인
2. **1단계 YAML 적용**
   - 원래 PARA 폴더에 그대로 둔 채 추천 YAML만 붙임
   - 변경 전 `_PKM_BACKUP/` 백업 자동 생성
3. **2단계 이동**
   - `ready` 상태의 노트만 PKM 목적지로 이동
   - 목적지 규칙
     - `concept`, `experiment`, `type=리소스` → `10_NOTE/{domain}`
     - `pattern` → `20_THINKING/{domain}`
     - `principle` → `30_SYSTEM/{domain}`
     - 애매한 노트 → `Inbox`

### 9. 충돌 / 링크 민감 처리
- 대상 폴더에 같은 파일명이 이미 있으면 `conflict`로 분류되고 자동 이동하지 않음
- 다른 노트가 `폴더/파일명` 형식의 wikilink나 markdown 상대경로로 참조하면 `link_sensitive`로 분류됨
- 이런 파일은 **1단계 YAML 적용까지만** 하고, 이동은 수동 검토 후 진행하는 것을 권장

---

## 절대 삭제 없음 원칙

이 프로그램은 **속성 편집 단계에서 원본을 삭제하지 않습니다**.
- 기본 편집은 속성 추가/수정만 함
- 변경 전 항상 `.bak` 백업 생성
- 잘못 수정해도 되돌리기로 복구 가능
- 2단계 이동은 원본 백업이 만들어진 뒤에만 수행되며, 대상 파일 생성 성공 후 원래 위치에서 제거됨

## 팁

- **감상문 248개 일괄 처리**: 검색창에 아무것도 입력 안 한 채 전체 선택 → type: 감상문 설정 → 추가
- **인덱스 노트 자동 매핑**: 전체 선택 후 [속성 추가] → 인덱스에 있는 것은 자동으로 domain/engine 설정됨 (수동 입력값이 우선)
- **더블클릭**: 파일 내용 미리보기
- **첫 이관 배치 추천**: `코딩 소프트웨어 스마트작업` 폴더에서 8개 정도로 시작하면 리소스/생산성 규칙을 검증하기 좋음
