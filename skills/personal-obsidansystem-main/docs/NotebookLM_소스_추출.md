# NotebookLM 소스를 md 파일로 받아 볼트·Claude에 쓰기

출처: 오빠두엑셀, 「노트북LM 소스를 파일로 저장해 클로드와 챗GPT에 활용하기」(2026-11-20)
https://www.oppadu.com/notes/9f973u9u6b/

> 북마클릿 코드는 남이 만든 것이고 원문이 계속 고쳐질 수 있으므로 여기에 복사하지 않는다. **위 글에서 최신 코드를 받아 쓴다.**
> NotebookLM 내부 요청 방식을 그대로 쓰는 도구라, NotebookLM이 바뀌면 갑자기 안 될 수 있다.

## 무엇을 하나
북마클릿 두 개를 크롬 북마크에 추가해 쓴다.

| 북마클릿 | 하는 일 |
|---|---|
| 유튜브 링크 일괄 복사 | 유튜브 검색 결과·재생목록·채널 [동영상] 탭의 일반 영상 링크를 한 번에 클립보드로 복사(쇼츠 제외) |
| 노트북 소스 추출 | 열려 있는 NotebookLM 노트북의 모든 소스 본문과 소스 가이드(요약·핵심 주제)를 **md 파일 하나**로 저장 |

추출 옵션: 담을 내용(본문 + 소스 가이드 / 본문만 / 가이드만), "정리해서 받기"(웹은 주소만 있는 줄·반복 줄 제거, 유튜브는 문단 나누기, 글은 인용 번호 제거).
파일 이름은 `<노트북 제목>_전사_YYYYMMDD.md`이다.

## 설치
1. 크롬에서 `Ctrl + Shift + O` → 빈 곳 오른쪽 클릭 → [새 북마크 추가]
2. 이름을 정하고, URL 칸에 원문 글의 `javascript:...` 코드를 붙여 넣는다(두 개 각각).
3. 북마크바가 안 보이면 `Ctrl + Shift + B`.

## 이 볼트에서 쓰는 방법

### 1. 조사 자료를 볼트 인박스로 (추천)
1. 유튜브에서 주제를 검색하고, 필터에서 [인기도]·[동영상]을 고른다(최근 자료면 업로드 날짜 [이번 주]/[이번 달]).
2. 스크롤로 영상을 더 불러온 뒤 [유튜브 링크 일괄 복사]를 누른다.
3. NotebookLM 새 노트북 → 소스 추가 → 웹사이트/YouTube URL에 붙여 넣는다. 실패한 소스는 [더보기] → [실패한 소스 모두 삭제]. 필요하면 NotebookLM 검색(Fast Research)으로 소스를 더 가져온다.
4. [노트북 소스 추출] → [파일로 저장]으로 md 파일을 받는다.
5. 받은 md를 볼트 `00_Inbox`에 넣고 Claude에게 "인박스 정리해줘"라고 한다. 운용지침에 맞게 분류·속성 제안을 받은 뒤 반영한다.

> 소스 수십 개를 합친 파일은 수십만 자가 될 수 있다(예시: 38개, 약 67만 자). 볼트에는 이 원본을 `90_ARCHIVE` 같은 자료 폴더에 두고, 핵심만 뽑은 노트를 따로 만드는 편이 낫다. Claude에게 원본을 통째로 읽히지 말고 "소스 가이드만" 옵션 파일로 먼저 요약을 보게 한다.

### 2. NotebookLM 결과를 Claude 작업 재료로
- NotebookLM에서 모은 소스를 md로 받아 Claude에게 첨부하면, NotebookLM이 가진 원문을 Claude도 그대로 볼 수 있다(수업 자료, 발표 대본, 모션 그래픽 등 제작 작업).
- 원문 글은 이 파일로 Claude에게 GSAP 모션 그래픽(HTML 하나)을 만들게 하는 예시를 보여 준다.

### 3. 볼트 묶음과 함께 쓰기
- `orchestrator.py merge`로 만든 볼트 묶음을 NotebookLM에 올려 둔 노트북에서 [노트북 소스 추출]을 "소스 가이드만"으로 돌리면, NotebookLM이 묶음마다 만든 요약·핵심 주제를 파일 하나로 받을 수 있다. 볼트 전체 지도(MOC)를 다시 짤 때 Claude에게 이 요약 파일만 주면, 볼트 전체를 읽지 않고도 구조를 제안받을 수 있다.
