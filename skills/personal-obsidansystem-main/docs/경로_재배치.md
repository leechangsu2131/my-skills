# path 기반 재배치 사용법

`path`는 AI에게 현재 저장 위치를 알려주는 보조 메타데이터이면서, 나중에는 실제 이동 규칙으로도 쓸 수 있습니다.

예시:

```yaml
---
path: "2 AREA(책임, 장기과제, 기한 없음) / 교육 학급운영 / 수업 / 공통"
---
```

AI가 이 `path` 값을 수정해 놓으면, 프로그램이 그 위치에 맞춰 실제 파일을 옮길 수 있습니다.

## GUI

1. `python pkm_manager.py`
2. Vault를 불러옵니다.
3. 재배치할 파일들을 선택합니다.
4. 오른쪽 아래 `path 재배치` 영역에서 `선택 파일을 path 기준으로 재배치` 버튼을 누릅니다.

동작 규칙:

- `path`가 없으면 스킵
- 현재 위치와 같으면 스킵
- 대상 파일이 이미 있으면 충돌로 중단
- 이동 전 원본 `.bak` 백업 생성
- 이동 후 `path`를 실제 위치 기준으로 다시 정규화

## CLI

전체 처리:

```powershell
python rehome_notes_by_path.py "<볼트 경로>" --all --dry-run
python rehome_notes_by_path.py "<볼트 경로>" --all
```

특정 파일만 처리:

```powershell
python rehome_notes_by_path.py "<볼트 경로>" --note "10_NOTE/수업/교육연극.md"
```

## 주의

- `path`는 폴더 경로 기준입니다. 파일명까지 넣어도 마지막 `.md`는 무시하고 폴더만 사용합니다.
- `Vault 루트`는 루트 폴더로 이동합니다.
- `..` 같은 상대 경로 탈출은 허용하지 않습니다.
- `knowledge`, `daily`, `Clippings`, `reports`, `_PKM_BACKUP`, `.obsidian` 같은 시스템 폴더는 `--all` 대상에서 제외됩니다.
