다모다란 엑셀 설명에서 가져올 제품 원칙

영상의 핵심은 엑셀 사용법보다 “사용자가 가치평가를 소유하게 만드는 방식”입니다.

Damodaran FCFF Simple Ginsu → Product design principles
Tool philosophy
모델이 말하는 것이 아니라, 내 가정이 말하게 만들기

다모다란의 설명은 “복잡한 엑셀 모델을 믿어라”가 아닙니다. 오히려 모든 숫자는 손으로도 따라갈 수 있어야 하고, 스프레드시트는 사용자의 스토리를 숫자로 바꾸는 도구여야 한다는 쪽에 가깝습니다.

우리 도구에 적용
노란색: 사용자가 바꾸는 입력성장률, 마진, WACC, sales-to-capital 같은 판단값.
초록색: 계산 결과FCFF, terminal value, equity value처럼 입력에서 흘러나온 값.
회색: 출처 데이터공식 IR, 시장 데이터, 자동수집값, 충돌 여부.
FCFF Simple Ginsu 구조
1. Input sheet회사, 산업, 실적, 재무상태, 주가, 세율, WACC 입력
2. Stories to Numbers왜 그런 성장률과 마진을 쓰는지 서술
3. Valuation output매출, EBIT, 세금, 재투자, FCFF, terminal value
4. Diagnostics성장, 마진, 재투자, ROIC, 가격 대비 가치 점검
5. Ginsu sheetsR&D, lease, cost of capital, failure rate, industry averages

영상에서 얻은 UX 원칙
1. 먼저 회사를 고른다추상 모델이 아니라 삼성전기처럼 실제 회사에서 시작.
2. 최소 자료만 준비연간 1개와 최신 분기 1개면 출발 가능.
3. 스토리를 먼저 쓴다왜 성장하고 왜 마진이 오를지 설명하게 함.
4. 진단이 입력을 되돌려줌가치가 너무 높거나 낮으면 어느 입력이 원인인지 알려줌.
제품 문장으로 바꾸면: “이 모델은 정답을 주는 기계가 아니라, 내 투자 스토리가 어떤 숫자를 요구하는지 보여주는 투명한 작업대입니다.”
