다음 설계 선택: 삼성전기 분석 시스템을 어떻게 붙일까

DART→LLM 파이프라인을 받아들이되, 어디에 중심을 둘지 정해야 합니다. 추천은 B안입니다.

Three integration approaches
A안

Google Sheets 중심

DART와 LLM이 숫자를 뽑아 시트에 넣고, 시트가 계산의 중심이 됩니다.

장점: 빠르게 시작 가능, Damodaran 엑셀과 연결 쉬움.

한계: 초보자에게 출처와 계산 흐름이 다시 숨겨질 수 있음. 앱 화면과 시트가 따로 놀 수 있음.

B안 추천

앱 내부 감사 데이터층 중심

DART 원문, LLM 추출, 계산값, 수동 수정, 출처를 앱 내부에 먼저 저장합니다. 시트는 선택적 내보내기입니다.

장점: “왜 이 숫자인가”를 화면에서 설명 가능. 여러 가치평가 모형이 같은 검증 데이터를 공유.

한계: 처음 설계가 조금 더 필요함. 데이터 구조를 잘 잡아야 함.

C안

모형 먼저, 데이터는 수동

Reverse DCF, P/B, ROIC, CAP 같은 분석 화면부터 만들고 데이터는 사용자가 직접 입력합니다.

장점: 가치평가 UI를 가장 빨리 검증 가능.

한계: 삼성전기 실제 분석을 반복할수록 입력 피로와 오류가 커짐.

추천 구조
공식 데이터에서 출발해 여러 가치평가 렌즈로 이어지는 구조

삼성전기 분석은 먼저 데이터 신뢰도를 확인하고, 그다음 FCFF, Value Attribution, ROIC, 상대가치, CAP를 차례로 지나가게 합니다. 각 렌즈는 결론보다 먼저 공식, 입력값, 출처를 보여줍니다.

1. DART 원문

연간 및 최신 분기 보고서 행 보관

2. 시장 데이터

주가, 시총, 주식수, EV 기준일 표시

3. 추출/검산

LLM 후보 매핑 + 공식 재계산

4. 공통 입력

FCF, NOPAT, 순부채, 자본, ROIC

5. 렌즈별 분석

DCF, P/B, EV/Sales, CAP, 민감도

6. 설명 화면

가정, 공식, 출처, 다음 질문

첫 구현 범위
삼성전기만 먼저처음부터 범용 주식 플랫폼이 아니라 009150 한 종목으로 흐름을 검증합니다.
연간 + 최신 분기연간 실적과 최근 분기 실적을 나란히 보여 현재 속도를 반영합니다.
수동 수정 허용자동 추출값이 이상하면 사용자가 고치고, 수정 사유를 기록합니다.
분석 순서
1. 데이터 무결성출처와 검산이 통과했는지 먼저 확인합니다.
2. FCFF / Reverse DCF현재 가격이 요구하는 FCF 수준을 봅니다.
3. Value Attribution 이후현재 수익력, 미래 기대, ROIC, 상대가치, CAP로 넓혀갑니다.
