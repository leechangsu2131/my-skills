# Claude Desktop 매매 자동화 프롬프트 모음

## ─────────────────────────────────────────
## 📸 스크린샷 → 매매일지 추가 (핵심)
## ─────────────────────────────────────────

### 기본 프롬프트 (이미지 붙여넣고 이것만 입력)

```
이 체결 스크린샷을 파싱해서 매매일지에 추가해줘.

파싱 후 아래 형식 JSON으로 만들어서 터미널에서 실행해줘:
python ~/투자/portfolio_gsheet/2_add_trade.py --json '<JSON>'

JSON 필드:
- date: 체결일 (YYYY-MM-DD)
- ticker: 종목코드 or 티커
- name: 종목명
- type: 매수 or 매도
- qty: 체결수량
- price: 체결단가 (원화 환산)
- amount: 체결금액
- reason: (있으면) 매매이유
- memo: (있으면) 기타
```

---

### 복수 체결 (여러 건 한 번에)

```
이 체결내역 스크린샷에서 모든 거래를 추출해서
각각 python 2_add_trade.py --json '...' 명령어로 순서대로 실행해줘.
달러 종목은 현재 환율 [환율 입력]원으로 원화 환산해줘.
```

---

### 현재가 업데이트 (잔고 화면 스크린샷)

```
이 잔고 스크린샷에서 종목별 현재가를 추출해서
python 2_add_trade.py --prices '{"티커1":가격1,"티커2":가격2,...}' 로 실행해줘.
```

포트폴리오 시트에서 목표비중 대비 ±5% 이상 이탈한 종목을 찾아서

### 파일 위치
```
~/투자/portfolio_gsheet/
├── service_account.json   ← Google 서비스 계정 키 (비공개!)
├── sheet_id.txt           ← 스프레드시트 ID (자동 생성)
├── 1_setup_gsheet.py      ← 최초 1회만 실행
├── 2_add_trade.py         ← 매매 추가/현재가 업데이트
└── 3_claude_desktop_prompts.md  ← 이 파일
```

### Google Service Account 발급 순서
1. https://console.cloud.google.com → 새 프로젝트
2. "API 및 서비스" → Google Sheets API, Google Drive API 활성화
3. "사용자 인증 정보" → 서비스 계정 만들기
4. 키 → JSON 다운로드 → service_account.json 으로 저장
5. 서비스 계정 이메일을 스프레드시트 편집자로 공유

### Claude Desktop MCP 설정 (filesystem)
```json
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem",
               "/Users/[이름]/투자"]
    }
  }
}
```
