# LectureCapture v0.2.6 — IDE/Claude 전달 메모

## 목적

개인 학습용 로컬 강의 영상에서 슬라이드를 추출하고, 자막·음성 전사를 구간별로 연결해 Obsidian용 Markdown 노트를 생성한다.

## 기준 버전과 우선 원칙

- 기준은 v0.2.6이다. 슬라이드 감지·전사 내보내기·참고 자료 첨부와 요약 사이드카 연결 기능이 포함되어 있다.
- 입력은 사용 권한이 있는 **로컬 영상 파일**이 기본이다. YouTube 다운로드는 `download-authorized` 별도 명령으로 분리되어 있고, 접근 제한·DRM·로그인 요구를 우회하지 않는다.
- 영상, 이미지, 음성을 외부 클라우드로 자동 전송하지 않는다.
- AI 요약은 구현되어 있지 않다. 노트에 요약 작성란과 `내 생각` 영역만 만든다.
- 원본 화면 보존이 우선이다. 슬라이드를 AI가 다시 그리지 않는다.
- 중복 후보는 삭제하지 않고 표시만 한다.

## 슬라이드 감지의 핵심 규칙 (수정 시 주의)

- 비교는 320×180 흑백 정규화 이미지에서 한다. 픽셀 변화 기준은 `--pixel-delta`(기본 30)이다.
- 새 상태는 다음 중 하나일 때 시작한다. 현재 상태 첫 프레임 대비 변한 픽셀 비율이 `--change-threshold`(기본 1.5%)를 넘거나, 기준의 내용이 사라진 비율이 `--removal-threshold`(기본 0.25%)를 넘는 경우이다.
- 두 번째 기준이 필요한 이유: 글자 길이가 비슷한 슬라이드끼리는 총 변화가 약 1.3%뿐이라 첫 번째 기준만으로는 합쳐진다. 글머리표가 *추가*되는 애니메이션은 내용이 사라지지 않으므로 이 기준에 걸리지 않는다.
- `--min-stable`(기본 2.5초)보다 짧은 상태는 버린다. 디졸브 중간 화면을 거르는 역할도 한다.
- 대표 프레임은 상태의 **마지막 정지 프레임**이다(선명도 최대 방식 아님).
- 중복 후보는 대표 이미지의 변한 픽셀 비율이 0.3% 이하일 때 표시한다. 8×8 dHash는 같은 템플릿의 다른 슬라이드를 구분하지 못해 사용하지 않는다.
- 임계값이나 비교 로직을 바꾸면 `tests/test_text_slides.py`가 계속 통과해야 한다. 이 테스트가 흰 배경 텍스트 슬라이드, 디졸브, 노이즈, 60장 반복을 검증한다.

## 전사 관련

- 우선순위: 사용자가 준 SRT/VTT, 없으면 faster-whisper. 자막이 있어도 직접 전사하려면 `--transcribe`, 전사를 생략하려면 `--no-transcribe`.
- GPU는 `int8_float16`, CPU 대체는 `int8`, VAD 필터 사용, 기본 모델 `large-v3`, 기본 언어 `ko`.
- 용어 힌트는 두 가지다. `--hotwords`는 매 30초 구간에 다시 적용된다. `--initial-prompt`는 이전 문맥에 섞여 최근 약 223토큰만 남으므로 긴 강의에서는 효과가 약해질 수 있다(faster-whisper 1.2.1 소스 기준). 긴 강의에는 `--hotwords`를 권한다.
- 설치된 faster-whisper가 `hotwords`를 지원하지 않으면 경고 후 무시한다. 두 옵션 모두 강제 사전이나 후처리 교정이 아니라 인식 문맥을 주는 옵션이다.
- `--export-transcript`: `transcript.txt`(각 구간 시작 시각 포함)와 `transcript.srt`(번호는 출력된 블록 기준으로 연속)를 저장한다. 두 파일은 BOM이 있는 UTF-8이다.

## 실행 예시

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[transcribe,test]"

lecturecapture run "C:\Videos\lecture.mp4" `
  --course "학급 경영 연수" `
  --hotwords "초등 교육, 기초학력, 형성평가, 교육과정" `
  --export-transcript `
  --diagnose
```

## 검증 결과

- `pytest`: 39개 테스트 통과.
- 합성 영상 기준 확인 항목: 하드컷 3/3장, 4초·1초 디졸브 3/3장, 10분 영상 60장 중 60장(중복 후보 57개), 센서 노이즈와 JPEG 압축을 넣은 영상, 글머리표 애니메이션의 완성 화면 선택, 진단 CSV, 노트 생성, TXT/SRT 내보내기.
- faster-whisper 옵션 전달은 가짜 모델로 인터페이스만 테스트했다.

## 검증하지 못한 것

- 실제 강의 영상에서의 슬라이드 분할 품질(강사 움직임, 마우스 포인터, 사진·영상이 섞인 슬라이드, 어두운 배경).
- 실제 `large-v3` 모델의 한국어 전사 정확도와 GPU(`int8_float16`) 동작.
- `--hotwords`의 실제 효과, 그리고 `hotwords`를 지원하는 faster-whisper의 정확한 최소 버전(1.2.1에서 지원 확인).
- 이 항목들은 실제 연수 영상 여러 종류로 확인하기 전에는 사용자가 결과를 검토해야 한다.

## 다음 작업 후보

1. 실제 한국어 연수 영상 3개(전체 화면 슬라이드, 강사 얼굴 포함, 애니메이션 많음)로 `--diagnose` 결과를 보고 기본 임계값을 보정한다. 슬라이드 누락률, 중복률, 시간 연결 오류를 기록한다.
2. `--hotwords` 사용 여부에 따른 전사 품질과 전문 용어 오류를 비교한다.
3. 전사 교정 흐름을 만든다(구간별 텍스트 수정 후 SRT와 노트 재생성).
4. 슬라이드 연결이 안정적임을 확인한 뒤, 슬라이드 이미지와 해당 발언을 함께 넣는 요약 기능을 설계한다. 기본값은 로컬 처리로 하고, 외부 API는 명시적 사용자 동의가 있을 때만 쓴다.
5. 검토 상태와 제외 여부를 저장하고 보고서·노트에서 제외하는 기능을 추가한다.
