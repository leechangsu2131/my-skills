# 강의 미디어 URL 수집

사용자가 수강 권한을 가진 `krcls.kr` 강의의 미디어 URL을 기존 Chrome 세션에서 확인해 로컬 CSV와 Markdown 목록으로 저장한다. `personal-video-note`와 나란히 쓰는 보조 스킬이며 영상 파일은 다운로드하지 않는다.

## 동작 방식과 경계

- 사용자가 직접 로그인한 Chrome에서 이미 원격 디버깅 포트 9222를 활성화했고, 대상 강의 목록을 열어 둔 경우에만 로컬 CDP에 연결한다. Chrome을 새로 띄우거나 기존 세션을 종료하지 않는다. 로그인 정보, 쿠키, 스토리지, 네트워크 요청은 읽지 않는다.
- `scripts/collect_lesson_media_urls.py`는 강의 목록의 보이는 제목·차시·진도를 읽고, 요청한 차시의 재생 버튼을 누른다. CDP 프레임 트리에서 `.mp4`, `.webm`, `.m3u8`, `.mpd`로 끝나는 프레임 주소를 찾고, 플레이어의 영상 요소를 일시정지한 뒤 플레이어 모달을 닫는다. 주소를 찾기 위해 네트워크 감청이나 사이트 API를 사용하지 않는다.
- 이 방식은 해당 사이트에서 확인된 플레이어 구조에 맞춘 것이다. 미디어 확장자로 끝나는 프레임 주소를 찾지 못하면 URL을 추측하지 말고 중단한다. 현재 열려 있는 플레이어가 그 차시의 미디어인지 확인되지 않아도 중단한다.
- 사용자가 요청한 강좌와 차시 범위만 연다. 범위가 넓거나 불명확하면 강좌 목록에서 차시·제목·진도를 먼저 확인해 대상 목록을 보여주고 범위를 확정한다.
- 결과 CSV에는 확인한 URL 원문을 기록한다. 사용자는 이 작업에서 URL 자체를 민감정보로 보지 않는다고 명시했다. URL을 임의로 자르거나 쿼리 문자열을 제거하지 않으며, 사용자가 요청하면 채팅에도 원문을 표시할 수 있다. 결과는 사용자가 지정한 로컬 폴더에 저장한다.
- 플레이어를 연 뒤 진도가 바뀌면 그 차시까지 저장하고 즉시 멈춘다. 변화를 사용자에게 알린 뒤 사용자가 계속하라고 명시한 경우에만 `--continue-after-progress-change`를 사용한다. 진도나 출석을 되돌리거나 다른 동작으로 보정하지 않는다.

## 실행 절차

1. 기존 로그인 Chrome의 CDP 포트 9222에 `krcls.kr` 강의 목록 페이지가 열려 있는지 확인한다. 대상 탭이 없거나 포트에 연결되지 않으면 사용자에게 Chrome에서 직접 목록 페이지를 열도록 안내한다. 연결 실패를 우회하려고 새 브라우저나 프로필을 만들지 않는다.
2. 정확한 강좌 제목과 요청한 차시 범위를 확인한다. 강좌 제목은 목록에 보이는 텍스트와 정확히 일치해야 한다.
3. 첫 실행은 요청 범위에서 진도 0%인 차시 하나를 시험한다. 플레이어를 일시정지하고 모달을 닫은 다음 진도를 다시 확인한다. 진도가 바뀌었거나 확인할 수 없으면 나머지 차시는 열지 않는다.
4. 진도가 유지되면 사용자가 요청한 나머지 범위를 처리한다. 진도 0%가 아닌 차시도 사용자가 그 차시를 명시적으로 요청한 경우 수집할 수 있으며, 실행 전·후 진도를 기록한다.
5. 스크립트를 실행한다. 사용자가 현재 작업 폴더에 결과를 원하면 `--output-dir ".\output"`을 사용한다. 그 외에는 사용자가 지정한 로컬 폴더를 사용한다.

```powershell
py -3 .\personal-video-url\scripts\collect_lesson_media_urls.py `
  --course "강좌 목록에 보이는 정확한 제목" `
  --output-dir ".\output" `
  --start 1 `
  --end 3 `
  --port 9222 `
  --host krcls.kr
```

6. 진도 변화가 발생한 뒤 사용자가 계속하라고 명시한 경우에만 명령에 `--continue-after-progress-change`를 추가한다.
7. 실행 후 `lesson_media_urls.csv`와 `lesson_media_urls.md`를 확인한다. CSV에 차시와 URL 원문이 있고, Markdown에 차시·제목·상태·진도 전후가 있는지 검증한다.

## 실패 시

- 포트 9222 연결이 안 되거나 대상 강좌 제목을 찾지 못하면 중단하고 오류 원인을 알린다.
- 차시 행이나 재생 버튼을 찾지 못하거나 미디어 프레임 주소가 나타나지 않으면 해당 차시 URL을 추측하지 않는다. 실패한 항목을 확인된 값으로 기록하지 않는다.
- 재생 모달을 닫을 수 없으면 다른 차시를 열지 않고 사용자에게 수동 정리를 안내한다.
- 실행이 진도 변화를 감지하면 자동으로 후속 차시를 열지 않는다. 사용자가 변화를 확인하고 계속 요청한 경우에만 재개한다.

URL을 모았다는 사실만으로 다운로드 권한이 추가되지는 않는다. 영상은 사이트가 공식적으로 제공하는 다운로드 기능으로만 저장하고, 로컬 영상이 있으면 `personal-video-note` 스킬을 사용한다.
