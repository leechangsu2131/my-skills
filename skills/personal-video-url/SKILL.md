# 강의 재생 페이지 주소 수집

사용자가 수강 권한을 가진 강의 사이트의 기본 동영상 플레이어에서 명시적으로 요청한 강의별 **미디어 주소**를 모아 로컬 목록으로 저장한다. `personal-video-note`와 나란히 쓰는 보조 스킬이다. 영상 파일은 다운로드하지 않는다.

## 범위와 원칙

- 사용자가 지정한 사이트와 강의 범위만 다룬다. 이 사례의 사이트는 `krcls.kr` 및 그 하위 도메인으로 제한한다.
- 로그인은 사용자가 직접 완료한 브라우저 세션을 사용한다. 비밀번호, 쿠키, 세션 저장소를 읽거나 파일에 기록하지 않는다. 로그인이나 접근 제한을 우회하지 않는다.
- 사용자가 미디어 주소를 명시적으로 요청한 경우에만 기본 플레이어의 브라우저 우클릭 메뉴 `동영상 주소 복사` 또는 화면에 노출된 주소를 기록한다. 이는 강의 페이지 URL과 구분되는 미디어 리소스 주소다.
- 네트워크 요청 감청, 사이트 API, 페이지 스크립트·소스코드 분석, DRM·로그인·접근 제한 우회로 주소를 찾지 않는다. 사용자 세션의 기본 영상 플레이어가 주소를 제공하지 않으면 추측하지 말고 중단한다.
- 주소에 세션 키나 서명 토큰이 포함되면 결과 파일에만 로컬로 저장하고 채팅에 출력하지 않는다. URL 목록은 계정 접근이 필요한 개인 자료로 취급한다.
- 강의 시작은 출석이나 진도에 영향을 줄 수 있다. 사용자가 요청한 범위에서만 재생 페이지를 연다. 사이트가 진도 변경, 평가 제출, 수강 완료를 요구하거나 자동으로 처리하려는 것을 발견하면 멈추고 사용자에게 알린다. 학습 종료·완료 버튼은 누르지 않는다.
- URL에 토큰·세션 키 등 비밀값이 포함되어 있으면 그 값을 저장하거나 공유하지 않는다. 안전하게 제거해도 페이지 식별이 유지되는지 확인할 수 없으면 해당 주소를 기록하지 말고 사용자에게 알린다.

## 수집 절차

1. 사용자가 지정한 코스와 차시 범위를 확인한다. 범위가 주어지지 않으면 로그인된 브라우저에서 수강 목록을 확인하고, 여러 차시를 순회하기 전에 대상 목록을 사용자에게 보여준다.
2. 먼저 브라우저 탭 목록에서 사용자가 이미 열어 둔 대상 사이트 탭이 있는지 확인한다. 가능하면 그 탭을 사용한다. Playwright로 기존 Chrome 세션에 붙어야 할 때는 사용자가 이미 원격 디버깅을 켜 둔 경우에만 로컬 CDP(`http://127.0.0.1:9222`)에 연결한다. Windows 환경 변수의 로컬 프록시 예외가 빠져 연결이 실패하면 `no_proxy`와 `NO_PROXY`에 `localhost,127.0.0.1`을 지정해 한 번 시도한다. 브라우저 연결은 실패해도 해당 도메인의 페이지 타깃이 CDP `/json`에 확인되면, 그 타깃의 `webSocketDebuggerUrl`에만 연결해 화면에 표시된 DOM 텍스트를 읽을 수 있다. 이 대체 연결은 보이는 페이지 내용 확인에만 쓰고 쿠키·스토리지·네트워크 요청·미디어 주소에는 접근하지 않는다. 기존 Chrome을 종료하거나 프로필을 바꾸거나 새 디버깅 브라우저를 임의로 띄우지 않는다. 대상 탭이 없으면 사용자가 직접 Chrome에서 강의 목록 페이지를 열도록 요청한다. 인증 정보를 복사하거나 새 로그인 자동화를 만들지 않는다.
3. 수강 목록의 차시 번호·제목·현재 진도를 먼저 기록한다. 재생 페이지를 실제로 열어야 할 때는 요청 범위에서 진도 0%인 차시 하나만 시험으로 연다. 자동 재생되면 즉시 일시정지하고 모달을 닫은 뒤 목록의 진도를 다시 확인한다. 진도가 변했거나 변화를 확인할 수 없으면 나머지 차시는 열지 말고 사용자에게 보고한다. 진행이 안전하게 확인된 경우에만 계속한다.
4. 기본 플레이어에서 `동영상 주소 복사`를 사용해 미디어 URL을 얻는다. 해당 브라우저 UI를 조작할 수 없는 경우, 사용자가 활성화한 로컬 Chrome CDP에 연결해 현재 열린 플레이어 프레임의 주소만 읽는다. 플레이어를 열기 전과 닫은 뒤 진도를 확인한다. 자동 재생되면 즉시 일시정지하고 주소를 확인한 뒤 플레이어를 닫는다. 진도 변화나 출석 기록이 감지되면 사용자에게 알리고, 사용자가 이미 영향을 안내받고도 나머지 URL 수집을 지시한 경우에만 계속한다.
5. 각 항목에 차시 번호, 제목, 미디어 URL, 수집 시각, 확인 상태를 기록한다. 미확인·차단·오류 항목은 빈 값으로 남기고 사유를 적는다. 1차 URL이 미디어 리소스인지 브라우저 플레이어에서 확인한다.
6. 결과 폴더에 `lesson_media_urls.csv`와 읽기 쉬운 `lesson_media_urls.md`를 만든다. 주소가 세션 만료나 사이트 변경으로 작동하지 않을 수 있음을 표시한다. 결과 파일은 사용자가 지정한 로컬 학습 자료 폴더에만 저장한다.
7. 실제 저장 결과를 열어 차시와 URL이 서로 맞는지 확인하고, 수집을 위해 연 탭·모달만 닫는다. 진도나 출석 상태가 바뀌었는지 확인할 수 있으면 변경 여부를 사용자에게 보고한다. 진도 변화는 자동으로 되돌리거나 다른 시청 동작으로 보정하지 않는다.

## 브라우저 접근 실패

- 브라우저 제어기가 사이트를 차단하거나 `ERR_BLOCKED_BY_CLIENT`, 인증 장벽, 보안 경고를 표시하면 해당 경로를 재시도·우회하지 않는다. 단, 기존에 사용자가 설정해 둔 Chrome CDP 연결은 별도 브라우저를 새로 띄우는 우회책이 아니라 기존 세션을 사용하는 정상 접속 방식이므로, 위 절차대로 대상 탭이 이미 있는지 확인할 수 있다. Playwright 브라우저 연결 자체의 시간 초과일 때만 이미 열린 해당 페이지 타깃의 DevTools 연결을 제한적으로 사용한다. 이때도 보안 경고, 접근 제한 또는 사이트 차단이 나타나면 멈춘다.
- 사용자가 본인 브라우저에서 공식 사이트를 직접 열고 로그인한 뒤 그 탭을 연결할 수 있도록 안내한다. 사용자가 탭을 열어 준 뒤에만 목록 확인을 이어간다.
- 접근이 막힌 상태에서는 URL 목록 파일을 만들지 않는다. 수집하지 못한 주소를 추측하거나 목록의 확인된 값처럼 기록하지 않는다.
- CDP에 연결했으면 Playwright 연결만 정리하고 사용자의 Chrome이나 기존 탭을 종료하지 않는다. 작업 중 새로 연 탭이 있으면 그 탭만 닫는다.

## 결과 열 예시

| 차시 | 강의 제목 | 미디어 URL | 수집 상태 |
|---|---|---|---|
| 1차시 | 오리엔테이션 | 로컬 CSV에 저장 | 확인 |

URL을 모았다는 사실만으로 다운로드 권한이 추가되지는 않는다. 영상은 사이트가 공식적으로 제공하는 다운로드 기능으로만 저장하고, 저장된 로컬 영상이 있으면 `personal-video-note` 스킬을 사용한다.
