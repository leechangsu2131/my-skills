# 유튜브 자막 → 카톡 알림 자동화

저장해둔 유튜브 재생목록에 새 영상이 생기면, 매일 정해진 시각에 자막을 가져와 저장소에 `.txt`로 쌓고 카카오톡 "나와의 채팅"으로 알려주는 프로그램이다. 깃허브 액션(무료 사용량 안)에서 돌린다.

## 구성물

| 파일 | 역할 |
|---|---|
| `scripts/main.py` | 재생목록 조회 → 자막 추출 → 파일 저장 → 카톡 전송. 로컬에서는 같은 폴더의 `.env`를 자동으로 읽는다 |
| `assets/daily.yml` | 깃허브 액션 워크플로. 저장소의 `.github/workflows/daily.yml`로 둔다 |
| `assets/gitignore.txt` | 저장소의 `.gitignore`로 둔다 (`.env` 등 제외) |
| `references/kakao-setup.md` | 카카오 앱 설정, 토큰 발급, 오류 코드, 친구에게 보내기 제약 |

사용자에게 줄 때는 `main.py`는 저장소 최상위, `daily.yml`은 `.github/workflows/daily.yml`, `gitignore.txt`는 `.gitignore`라는 이름으로 두도록 안내한다.

## 진행 순서

1. **확인할 것 (한 번에 하나만 묻는다)**: 재생목록이 공개/일부공개인지. 비공개면 공개로 바꾸는 것을 먼저 권한다. 비공개를 유지해야 하면 쿠키 방식이 필요하고, 이는 만료·계정 제재 위험이 있다고 알린다.
2. **저장소**: 반드시 **새 비공개(private) 저장소**를 쓰게 한다. 자막은 남의 콘텐츠이고 `state.json`에 재생목록 내용이 남는다. 개인 블로그용 공개 저장소(`xxx.github.io` 등)에는 올리지 않도록 권한다. 비공개여도 하루 1~2분짜리 작업이라 무료 사용량 안에 들어간다.
3. **카카오 설정**: `references/kakao-setup.md`를 읽고 단계별로 안내한다.
4. **파일 배치와 Secrets 등록**:
   - `PLAYLIST_URL`, `KAKAO_REST_API_KEY`, `KAKAO_CLIENT_SECRET`, `KAKAO_REFRESH_TOKEN`
   - `GH_PAT`: 리프레시 토큰 자동 갱신용. Fine-grained 토큰으로 해당 저장소의 Secrets 읽기/쓰기 권한만 준다.
5. **로컬 테스트**: `.env`를 만들고 `pip install yt-dlp requests` 후 `python main.py`.
6. **깃허브 테스트**: Actions 탭 → Run workflow로 수동 실행. 카톡이 오는지 확인한다.

## 동작 규칙

- 한 번에 최대 `MAX_PER_RUN`(기본 5)개의 새 영상만 처리하므로, 처음에 영상이 많아도 며칠에 걸쳐 따라잡는다.
- 처리한 영상 ID는 `state.json`에 기록한다. 로컬 테스트로 생긴 `state.json`을 저장소에 올리지 않으면 같은 영상 알림이 중복으로 올 수 있다고 알려준다.
- 자막 우선순위는 한국어, 없으면 영어. 둘 다 없으면 "자막 없음" 알림을 보내고 처리 완료로 기록한다.
- 요청 실패(차단, 네트워크)는 처리 완료로 기록하지 않아 다음 실행 때 재시도하고, 실패 알림을 카톡으로 보낸다.
- cron은 UTC 기준이다. 한국 오전 7시는 `0 22 * * *`. 깃허브 스케줄은 몇 분~수십 분 늦을 수 있다.
- 카톡 텍스트 메시지는 글자 수 제한이 있어(약 200자) 전문이 아니라 제목·앞부분·링크만 보낸다. 전문은 `transcripts/`에 저장한다.

## 자주 생기는 문제

- **깃허브 서버에서만 자막이 안 받아진다**: 클라우드 IP가 유튜브에 차단되는 경우가 있다. 대안은 (1) 쿠키 파일을 Secrets에 넣고 `yt-dlp --cookies` 사용, (2) 집 PC나 라즈베리파이에서 작업 스케줄러/cron으로 실행, (3) 자막 API 사용. 이 위험은 처음부터 사용자에게 알린다.
- **공개 저장소는 60일간 활동이 없으면 스케줄이 자동 중지**된다. 이 자동화는 자막이 생길 때 커밋하지만, 새 영상이 오래 없으면 멈출 수 있다.
- **60일 뒤 알림이 멈춘다**: 리프레시 토큰 만료. `GH_PAT`이 없으면 갱신된 토큰이 Secrets에 저장되지 않는다.
- **링크가 열리지 않는다**: 카카오 앱의 웹 도메인에 `https://www.youtube.com`이 등록되지 않은 경우.

## 보안 규칙 (반드시 지킨다)

- 사용자에게 `.env`를 깃허브에 올리라고 하지 않는다. 깃허브는 파일 단위 비공개가 없다. 깃허브에서는 Secrets, 로컬에서는 `.env`(`.gitignore`에 포함)로 나눈다.
- 사용자가 클라이언트 시크릿, 인가 코드, 액세스·리프레시 토큰을 대화에 붙여넣으면, 그 값을 답변에 다시 적지 않고 **재발급과 교체를 권한다.** 앞으로는 터미널 출력을 공유할 때 해당 값을 가려달라고 안내한다.
- 사용자의 깃허브 계정에 직접 올릴 수 없다. 파일을 만들어주고 웹에서 올리는 방법을 안내한다.

## 친구에게 보내기를 요청받으면

기본은 "나에게 보내기"다. 친구에게 보내려면 상대가 내 카카오 앱에 로그인해 동의해야 하고, 권한 없이는 앱 팀 멤버로 등록한 사람에게만 가능하다. 전체 권한은 비즈니스 정보 심사와 동작 화면 제출이 필요해 개인 자동화로는 통과가 어렵다. 자세한 내용은 `references/kakao-setup.md`를 읽는다. 여러 사람과 같이 받고 싶다면 디스코드 웹훅 사용을 권한다. 디스코드로 바꿀 때는 `kakao_send` 호출부를 웹훅 POST(`{"content": ...}`, 메시지당 2,000자 제한, 길면 파일 첨부)로 바꾼다.
