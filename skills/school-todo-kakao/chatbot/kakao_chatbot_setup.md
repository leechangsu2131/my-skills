# 카카오톡 챗봇 v2 — 담당자별 완료 기록 설정 순서

담당자가 카톡 채널에 "완료 탄소중립"이라고 보내면 **그 사람 몫으로** 완료가 기록되고,
선생님은 "현황"으로 누가 했고 누가 안 했는지 봅니다. 아침 메시지(깃허브 + cron-job.org)와는 별개입니다.

> 카카오 화면 이름과 메뉴 위치는 제 기억 기준이라 실제와 조금 다를 수 있습니다.
> 코드는 구글 시트를 흉내 낸 가짜 환경에서 38개 동작을 시험했지만, 실제 카카오와의 연결은 아직 시험하지 못했습니다.

## 시트 구조 (이미 만들어 두었습니다)
| 탭 | 내용 |
|---|---|
| 일정DB | 기존 열 + **담당**(H열). 이름을 쉼표로 여러 명(`김철수, 이영희`), 그룹 이름(`3학년교사`), `전체` 중 쓸 수 있고 섞어도 됩니다. 비우면 공유 일정(행사)이거나 선생님 본인의 할 일입니다. |
| 구성원 | 이름 / 그룹 / 챗봇아이디 / 역할(관리자·일반) / 이메일. 사람 추가는 한 줄입니다. |
| 완료기록 | 시각 / 키 / 이름 / 내용. 누가 무엇을 끝냈는지 챗봇이 한 줄씩 적습니다. |

담당자가 모두 완료하면 일정DB의 상태 칸에 ✔가 자동으로 들어가서 아침 메시지에서 빠집니다.

## 설치 순서
1. 일정DB 시트 → **확장 프로그램 → Apps Script**에서 기존 코드를 지우고 `kakao_chatbot.gs`를 붙여 넣고 저장합니다.
   (이전 버전을 이미 설치했다면 그 위에 덮어쓰고, **배포 관리 → 연필 → 새 버전 → 배포**를 합니다.)
2. 프로젝트 설정 → **스크립트 속성**: `SECRET` = 20자 이상의 영문·숫자 / `ALLOWED_IDS` = 선생님 챗봇 아이디(처음 한 번 관리자 등록용).
3. **배포 → 새 배포 → 웹 앱**, 실행 사용자 **나**, 액세스 **모든 사용자** → 웹 앱 URL 복사 (브라우저로 열면 "켜져 있어요").
4. 카카오톡 채널 만들기 → 오픈빌더에서 챗봇 만들고 채널 연결.
5. 오픈빌더 **스킬**: URL = `웹앱URL?key=SECRET값`. **폴백 블록**의 봇 응답에서 이 스킬을 선택 → 저장 → **배포**.

## 사람 등록 (담당자 한 명마다 한 번)
1. 담당자가 선생님 채널을 추가하고 챗봇에 **내아이디**라고 보냅니다.
2. 나오는 긴 글자를 선생님께 전달합니다.
3. 선생님이 **구성원 탭**에서 그 사람 줄의 `챗봇아이디` 칸에 붙여 넣습니다. (이후에는 이름으로 연결됩니다.)
   관리자로 쓸 선생님의 다른 계정은 `역할`을 `관리자`로 적습니다.

## 챗봇에게 하는 말
| 누가 | 말 | 결과 |
|---|---|---|
| 담당자 | `완료 탄소중립` / `탄소중립 완료` | 내 몫 완료 기록 + `(2/3)` 진행도 |
| 담당자 | `나 완료했어` / `완료` | 남은 일이 하나일 때만 처리, 여러 개면 목록 |
| 담당자 | `되돌리기 탄소중립` | 내 완료 기록 삭제 |
| 담당자 | `할일` / `오늘` | 내 남은 일 / 오늘 일정 |
| 관리자 | `현황` 또는 `현황 탄소` | 담당 지정된 일정의 ✔ 한 사람 / ⏳ 안 한 사람 |
| 관리자 | `완료 탄소중립 이영희` | 이영희 몫을 대신 처리 (`되돌리기 탄소중립 이영희`도 가능) |

일반 담당자는 **자기 몫만** 처리할 수 있고, 담당이 아닌 일정이나 다른 사람 몫은 거부됩니다.
같은 일정에 담당자가 여러 명이어도 한 사람의 완료가 다른 사람에게 영향을 주지 않습니다.

## 주의
- `담당`에 적은 이름은 `구성원` 탭의 이름과 **글자가 정확히 같아야** 합니다. 다르면 `현황`에 "못 찾았어요" 경고가 나옵니다.
- 완료기록은 일정의 `키`로 연결됩니다. 일정DB의 `키`를 고치면 그 일정의 기록이 끊깁니다.
- 일정DB를 정렬할 때는 H열(`담당`)까지 범위에 포함하세요. A~G만 정렬하면 담당이 다른 행과 어긋납니다.
- 아침 카톡(파이썬)은 아직 담당자별로 나눠 보내지 않고 선생님께만 갑니다. 안 한 사람에게 알리는 이메일은 다음 단계입니다.
- 웹 앱 주소의 `key=` 값은 비밀번호입니다. 남에게 보여 주지 마세요. 대화 내용은 카카오 서버를 거치므로 일정에 학생 이름 같은 개인정보는 적지 마세요.

## 문제가 생기면
- **답이 없거나 오류**: 오픈빌더 응답 제한(몇 초)이나 구글 앱스 스크립트 웹 앱 주소를 카카오가 못 받는 경우일 수 있습니다. 어느 단계에서 어떤 화면이었는지 알려 주세요.
- **"접근할 수 없어요"**: 스킬 URL 끝의 `?key=` 값이 `SECRET`과 다릅니다.
- **"아직 등록되지 않은 사용자"**: 구성원 탭의 `챗봇아이디`가 비었거나 다릅니다(앞뒤 공백 확인).
