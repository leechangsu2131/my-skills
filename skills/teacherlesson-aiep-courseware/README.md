# AIEP 수업꾸러미 플랫폼 어댑터

이 스킬은 공통 수업 패키지 제작 체계의 AIEP 전용 어댑터입니다. 여러 학습 사이트에 공통으로 쓸 수업 설계·자료 양식은 [학습 플랫폼 수업꾸러미 제작 스킬](../teacherlesson-courseware-builder/SKILL.md)을 참고합니다.

## 사용 방법

아래처럼 수업 조건과 만들고 싶은 결과물을 알려 주세요.

> 초등 5학년 과학, 태양계와 별 2차시 수업을 준비해 줘. 차시별 지도안, 학생용 활동지, 평가 문항을 만들고 AIEP 꾸러미 입력용으로 정리해 줘.

요청에 따라 로컬 자료 패키지만 만들거나, Ego Lite 브라우저로 사이트 입력까지 진행할 수 있습니다. 사이트 최종 등록은 명시적으로 요청한 경우에만 진행합니다.

## 구성

- `SKILL.md`: 자료 개발 및 사이트 입력 절차
- `templates/course-package.md`: 수업 패키지 표준 양식
- `references/site-capabilities.md`: 매뉴얼/현재 화면에서 확인한 저작 기능
- `records/2026-11-10-initial-setup.md`: 초기 조사에서 생긴 이슈와 해결 과정
- `records/2026-11-11-learning-platform-check.md`: 파일 배치, 학습자 미리보기, 자동 드래그 문제 해결 기록

수업 산출물은 기본적으로 `output/<날짜>-<수업명>/`에 차시안, 학습자료, 출처와 사이트 입력안을 모아 둡니다.

## 안내 페이지

브라우저에서 [사용안내.html](사용안내.html)을 열면 단계별 사용법, 요청 예시와 AIEP 입력 흐름을 확인할 수 있습니다.
