# 초기 조사 및 이슈 해결 기록

- 날짜: 2026-11-10 (Asia/Seoul)
- 목표: 수업 콘텐츠를 개발하고 표준 폴더로 정리한 뒤 경북 AIEP 저작 도구 기능에 맞춰 꾸러미로 구성하는 스킬을 준비한다.
- 조사 범위: 사용자 제공 매뉴얼 v1.2와 지정된 새 꾸러미 편집 화면. 사이트에 콘텐츠를 만들거나 등록하지 않았다.

## 확인한 내용

- 매뉴얼은 꾸러미명/공개 범위/순차학습, 성취기준 배치, LCMS 콘텐츠, 콘텐츠 속성, 파일/링크 및 저작권 설정, 공유 꾸러미, 목차/학습자 화면 미리보기를 설명한다.
- 지정 사이트는 로그인된 상태에서 새 꾸러미 편집 화면을 보여 주었다. 과목을 먼저 선택해야 하는 안내, 성취기준 패널, 단원 캔버스, 미리보기·임시저장·등록하기 버튼을 확인했다.
- 상세 업로드 제한과 현재 LCMS 콘텐츠 목록은 확인하지 않았다. 스킬은 이 정보를 추측하지 않고 작업 시 화면에서 확인하도록 정했다.

## 이슈와 해결 과정

| 이슈 | 원인/영향 | 해결 | 남은 점 |
|---|---|---|---|
| PDF 텍스트 추출 시 한글이 깨져 보임 | PowerShell 출력 코드 페이지와 Python stdout 인코딩이 달라 한글 출력이 손상됨 | `PyMuPDF`(`fitz`)로 텍스트를 UTF-8 파일에 저장한 뒤 UTF-8로 다시 읽음. 18쪽 전체 텍스트에서 기능별 설명을 확인함 | 텍스트 기반 확인이므로 복잡한 시각 배치 자체는 분석 대상이 아님 |
| 초기 PDF 추출 명령 오류 | 인라인 Python f-string과 PowerShell 따옴표가 충돌했고 `pypdf`가 설치되어 있지 않음 | f-string을 피하고 이미 설치된 `fitz`를 사용하도록 전환 | 추가 패키지 설치 없이 해결 |
| 화면 기본 공개 범위가 전체공개로 표시됨 | 신규 편집 화면의 선택값이 공개 정책의 사용자 의도와 다를 수 있음 | 제작 표준에 공개 범위 확인 항목을 만들고 전체 공개를 자동 선택하지 않도록 규칙화 | 최종 공개 범위는 건별로 확인 |
| 일부 기능의 실제 운영 제약 미확인 | 매뉴얼에 파일 형식/용량 또는 현재 LCMS 검색 결과가 구체적으로 나오지 않음 | `site-capabilities.md`에 미확인 사항으로 분리하고, 실제 작업 때 사이트 안내를 확인하도록 지침 추가 | 파일 업로드 전 허용 규격 확인 필요 |

## 결과

초기 스킬 규칙, 표준 패키지 양식, 사이트 기능 레퍼런스, 스킬 카탈로그 항목을 추가했다. 실제 수업 자료나 사이트 꾸러미는 이 작업에서 생성/게시하지 않았다.
