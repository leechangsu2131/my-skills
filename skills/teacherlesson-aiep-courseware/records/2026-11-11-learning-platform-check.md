# AIEP 학습자료 배치 및 미리보기 확인

- 날짜: 2026-11-11 (Asia/Seoul)
- 범위: 사용자가 제공한 성장발표 자료로 작성 화면을 확인하고, 공개 범위 선택과 학습자 미리보기 흐름을 확인했다.
- 개인정보: 실제 학생 이름·사진·작품은 올리지 않았다.

## 확인 사항

- 파일/링크 패널에서 DOCX를 업로드하고 제목·설명·과목·비구매 여부·저작권 유형을 지정할 수 있었다.
- 업로드된 문서는 파일함에만 추가된다. 차시의 콘텐츠 칸에 별도로 배치해야 꾸러미가 등록 가능 상태가 됐다.
- 학습자 미리보기는 DOCX를 PDF 뷰어로 표시했고, 원본 PDF 열기 링크도 제공했다.
- 안내자료와 활동지를 순서대로 배치하고 전체공개로 등록한 뒤, 전체 수업꾸러미 목록에 나타나는 것을 확인했다.
- 학습 화면 미리보기에는 학습 자료 열람 흐름이 보였으며, 학생 주관식 답 입력/제출 화면은 확인되지 않았다.

## 이슈와 해결

| 이슈 | 원인/영향 | 해결 과정 | 재사용 지침 |
|---|---|---|---|
| 파일이 차시 칸에 자동 연결되지 않음 | 파일함 업로드와 캔버스 배치가 별도 단계임 | 파일 목록에서 해당 자료를 첫/다음 콘텐츠 칸으로 드래그했다 | 업로드 후 파일함 목록과 캔버스 배치를 각각 확인한다 |
| 자동화 드래그가 텍스트 선택으로 동작 | 포인터 드래그가 사이트 드래그 센서 대신 기본 선택 동작에 잡힘 | 첫 시도는 사용자가 드래그해 화면 제어를 넘겨받았고, 이후 브라우저 드래그 기본 동작을 막은 상태의 포인터 경로로 자료를 배치했다 | 먼저 실제 화면을 확인한다. 반복 실패 시 브라우저를 사용자에게 넘긴다. 사이트 DOM/상태를 직접 수정해 게시하지 않는다 |
| 학생 제출 기능 여부 불명확 | 학습자 미리보기는 문서 열람 화면 중심임 | PDF 뷰어와 목차를 확인했으나 답변 입력/제출은 보이지 않았다 | AIEP를 답안 수집함으로 설명하지 않는다. 수집 요구가 있으면 별도 플랫폼 기능을 확인한다 |

## 공개 게시 확인

- 전체공개 선택 후 등록 완료 메시지를 확인했다.
- `전체 수업꾸러미` 기본 목록에 새 자료가 표시됐다.
- 학생 공개 자료에는 일반 안내와 빈 활동지만 연결하고 개인 학생 산출물은 포함하지 않았다.
