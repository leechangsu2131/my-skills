# AIEP 저작 도구 기능 및 확인 상태

## 대상 사이트

- 경북 AIEP 수업꾸러미 저작 도구: <https://aiep-courseware.gbe.kr/course/new?snb=objective>
- 근거 문서: 사용자가 제공한 「AIEP-수업꾸러미 저작도구 사용자 매뉴얼 v1.2」(18쪽)
- 화면 확인일: 2026-11-10. 로그인된 계정으로 `/course/new?snb=objective` 편집 화면을 열어 확인했다. 계정 식별정보는 이 기록에 포함하지 않는다.

## 매뉴얼에 기재된 기능

| 영역 | 기능 | 제작 시 활용 |
|---|---|---|
| 기본 설정 | 꾸러미명, 전체 공개/소속 학교 공개/비공개, 순차학습 | 제목과 공개 범위, 학습 진행 방식 결정 |
| 성취기준 | 학년/교과/과목별 검색, 성취기준 보기 및 캔버스 배치 | 공식 성취기준과 학습 목표 연결 |
| 콘텐츠 | LCMS 영상, 문서, 인터랙티브 자료 등 검색/미리보기/캔버스 배치 | 보유 콘텐츠를 검토하고 단원별로 배치 |
| 콘텐츠 속성 | 제목, 설명, 연결 성취기준, 학습 유형, 보충자료 | 자료의 학습 맥락과 추가 지원 작성 |
| 파일/링크 | 파일 또는 URL 직접 추가, 저작권 설정 후 배치 | 자체 제작 자료 및 적절한 외부 자료 활용 |
| 공유 꾸러미 | 공유 자료 미리보기, 가져와 편집/재구성 | 적합한 공유 자료를 검토 후 맞춤화 |
| 미리보기/등록 | 목차 및 통합학습플레이어 미리보기, 등록 | 학습자 관점 최종 검토 후 게시 |

## 2026-11-10 화면에서 확인한 상태

- 로그인 후 새 꾸러미 편집 화면이 열렸다.
- 성취기준 패널에 학년, 교과군, 과목 선택과 성취기준 검색 입력란이 보였다. 과목 선택 전에는 과목을 먼저 선택하라는 안내가 표시됐다.
- 꾸러미명 입력란, 공개 여부 선택(화면 기본값은 전체공개), 순차학습 토글이 보였다. 기본값을 권장 설정으로 간주하지 말고 매 작업마다 사용자의 의도를 확인한다.
- 캔버스에 성취기준/콘텐츠 배치 영역과 단원 행이 보였다. 안내는 좌측 패널 요소를 드래그 앤 드롭하도록 설명한다.
- 화면 하단에 미리보기, 임시저장, 등록하기 버튼이 보였다.
- 이 조사에서는 폼을 수정하거나 임시저장/등록하지 않았다. LCMS 검색 결과, 개별 업로드 규격, 용량 제한, 지원 파일 형식은 확인하지 않았다.

## 2026-11-11 추가 화면 확인

- 로그인된 작성 화면의 파일 업로드 입력은 `.docx`, `.pptx`, `.pdf`, 여러 동영상 형식과 오디오 형식을 허용 목록에 표시했다. 업로드 메타데이터에는 제목, 설명, 과목, 구매 여부, 저작권 유형 설정이 있었다. 실제 용량 제한은 별도로 확인하지 않았다.
- 업로드한 문서는 파일/링크 패널 목록에 나타난 뒤, 차시 콘텐츠 칸에 따로 배치해야 학습꾸러미에 연결됐다. DOCX는 학습자 미리보기에서 PDF 뷰어로 열렸다.
- 학습자 미리보기에서 문서 열람·원본 PDF 열기는 확인했다. 자유 서술 답변 입력 또는 학생별 과제 제출 기능은 이 화면에서 확인하지 못했다.
- 자료를 캔버스에 옮길 때 사람의 드래그는 정상 동작했다. 자동화 포인터가 텍스트 선택/네이티브 드래그로 빠지는 경우에는 화면 상태를 다시 확인하고, 불안정하면 사용자에게 브라우저 제어를 넘겨 드래그를 요청한다.

## 제작 시 해석 원칙

1. 사이트 항목은 바뀔 수 있으므로 실제 입력하는 날에 화면 안내를 우선 확인한다.
2. 사이트에 특정 학년/과목의 성취기준이 없거나 일치 여부가 불명확하면 임의 선택하지 말고 사용자 검토 대상으로 남긴다.
3. LCMS 자료의 실제 제공 여부는 사이트에서 검색/미리보기로 확인하기 전까지 보장하지 않는다.
4. 파일 형식, 최대 용량, 링크 정책 등 확인되지 않은 제한은 단정하지 않는다.
5. 전체 공개가 화면 기본값으로 표시되더라도 기본 공개 범위로 두지 않는다. 수업 자료의 민감도와 사용자의 배포 의도에 맞춰 선택한다.
