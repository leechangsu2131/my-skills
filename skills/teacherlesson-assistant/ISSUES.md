## 다음 단계 (우선순위 순)

1. **하이클래스 알림장 자동 게시** — `admin-hitalk-sender`의 Chrome 9222 연결 방식을 알림장 쓰기 화면에 맞게 고쳐 `/api/notice/post` 추가. 게시 전 미리보기·확인 필수
2. **나이스 시간표 변경 반영** — `teacherlesson-from-neis` 확장의 주간학습안내(보결·교체)를 읽어 교시 탭에 "변경됨" 표시, 진도표와 다르면 알려 주기
3. **사이트 자동 로그인** — 지금은 아이디/비번 클립보드 복사. 출판사별 로그인 화면 선택자를 정해 CDP로 채우기(전용 프로필 로그인 유지로 충분하면 생략)
4. **차시별 사이트 바로 열기** — 출판사 사이트의 단원·차시 주소 규칙을 찾아 `flows`에 `site_url` 저장 → 해당 차시 화면으로 바로 이동 (`teacherlesson-social-helper` 방식 참고)
5. **녹음 받아쓰기** — 로컬 Whisper 등으로 녹음을 텍스트로 바꾸고 [mm:ss] 메모와 맞춰 수업 분석(발화 비율, 단계별 시간, 발문 수)
6. **홈페이지 연계** — HomePage의 수업 관리 화면과 연결. 학생 이름·녹음은 홈페이지(공개 저장소)로 보내지 않고 요약 지표만
7. **굿데이티처 같은 대시보드 요소** — 타이머, 발표자 뽑기, 소음 측정 등 교실 편의 도구를 오른쪽 창 위젯으로
8. **학생 반응 분석(카메라)** — 장기 과제. 학생 영상은 동의·학교 지침 확인이 먼저이고, 저장 없이 실시간 지표만 내는 방식부터 검토
