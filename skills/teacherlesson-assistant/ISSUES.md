- **차시 자료 바로 열기(음악) 확인**: 음악 '차시 블록 0개' 원인 = 두클래스 로그인 풀림(교과서 주소는 맞음: 음악 3 최미영, 1년 치). 로그아웃 상태에서도 차시 틀이 보여 '로그인됨'으로 잘못 판단하던 것을 고침(로그인 링크가 보이면 로그인 안 됨)(2026-11-22). 교사 두클래스 로그인 후 실제 실행 성공(2026-11-22): 차시 35개 읽고 「[7~9차시] 함께 연주하는 겨울 노래」 찾음. 로그인 판단을 '차시 제목(resource-title)이 있나'로 바꾸고(접힌 단원도 textContent 로), 로그인 허브 주소(SSO)를 거쳐 자동 로그인되면 Enter 를 묻지 않음
