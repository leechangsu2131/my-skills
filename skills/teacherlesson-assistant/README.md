# 수업 비서 — 사람용 안내

Claude 작업 절차는 [SKILL.md](SKILL.md), 문제·할 일은 [ISSUES.md](ISSUES.md), 해결 과정과 운영 정보는 [WORKLOG.md](WORKLOG.md).

## 실행

- 바탕화면 `수업 준비 비서` → `실행_수업비서.bat`을 켠다. 수업 비서는 왼쪽 모니터의 약 1/3, 교과 사이트는 오른쪽 모니터 전체에 열린다. 오른쪽 모니터가 없으면 왼쪽 화면의 나머지 영역을 쓴다. 12시간에 한 번 `build_units.py`(단원 개관)도 돌린다.
- 시간표·완료·연장·미루기·따라잡기는 Supabase를 읽고 쓴다. 중앙 `.env`에 `SUPABASE_URL`(또는 `NEXT_PUBLIC_SUPABASE_URL`)과 `SUPABASE_SERVICE_ROLE_KEY`가 있어야 한다. 진도 서버(5000번)는 이전 Google Sheets 기능을 사용할 때만 필요하다.
- "수업 사이트 열기"는 수업 도우미 공용 Chrome 프로필(config `chrome_profile`, 기본 `%LOCALAPPDATA%\MusicClassHelper\chrome_profile`, 원격 디버깅 포트 `debug_port` 9233)로 오른쪽 모니터 전체에 창을 연다. Chrome 이 이미 실행 중이어도 새 창을 다시 배치한다. 열 수 있는 주소는 config 의 과목 사이트·바로가기·하이클래스·AI 사이트·NotebookLM 노트북 주소뿐이다. 한 번 로그인하면 그 프로필에 로그인이 유지된다.
- 9222 포트는 다른 자동화(에듀파인)가 쓰고 있을 수 있어 9233을 쓴다.
- 서버는 Host 가 127.0.0.1/localhost 인 요청만 받는다(다른 사이트·DNS 리바인딩 차단). 클립보드로 복사한 비밀번호는 30초 뒤 지운다.
- 최초 설정은 `python -m pip install -r requirements.txt`. 서비스 키는 로컬 Python 서버에서만 읽고 브라우저로 보내지 않는다.
- 수업 흐름 자동 준비: 화면의 `☀ 오늘 준비`와 `🌙 내일 준비` 단추, 아침 bat은 각각 오늘·내일 흐름을 준비한다. 손으로는 `python prepare_lessons.py --date today|tomorrow [--redo]`(`--redo`는 자동 흐름만 다시 만들고 사람이 고친 것은 그대로).

## 학교 PC 점검 (`점검_PC.bat`)

처음 쓰는 PC(학교 PC 등)에서 수업 비서를 켜기 전에 한 번 돌려 빠진 것을 찾는다. `점검_PC.bat`을 더블클릭하거나 이 폴더에서 `python check_setup.py`. 설치 순서(Python·부품·Node·Gemini CLI·Chrome 로그인·OneDrive)는 [docs/INSTALL_SCHOOL_PC.md](docs/INSTALL_SCHOOL_PC.md) 에 차례대로 적어 두었다.

- 읽기만 한다: 설치·폴더 만들기·서버/크롬 켜기를 하지 않는다. 중앙 `.env`는 키 **이름**만 보고 값은 출력하지 않는다.
- 항목마다 ✅ 괜찮음 / ⚠ 일부 기능만 안 됨·확인 필요 / ❌ 꼭 고쳐야 함, 그리고 고치는 방법 한 줄을 보여 준다. ❌ 가 있으면 종료 코드 1.
- 보는 것: Python 버전·패키지(`requirements.txt` + selenium), **Python 실행기**(`실행_수업비서.bat` 이 쓰는 `py -3.13` 과 `python` 을 둘 다 돌려 보고, 없거나 서로 다른 버전이면 ⚠ — 패키지가 한쪽에만 깔렸을 수 있다), Node.js·Gemini CLI, 크롬 실행 파일·`chrome_profile` 폴더, 중앙 `.env` 위치와 키 이름(Supabase 주소·서비스 키, Gemini 키), 데이터 폴더와 `flows/units/notebooklm`, OneDrive 폴더, 5180(수업 비서)·9233(수업용 크롬) 포트.
- 진도 저장소(config 의 `schedule_backend`)가 `supabase` 가 아니면 Supabase 키가 없어도 ❌ 가 아니라 ⚠ 로 안내한다. config 의 `port`·`debug_port` 가 숫자가 아니거나 1~65535 밖이면 멈추지 않고 ❌ 로 알린다(그 값으로는 서버가 켜지지 않는다).
- 포트가 닫혀 있는 것은 서버·크롬을 켜기 전이면 정상이다. 5180 이 열려 있으면 실제로 `http://127.0.0.1:5180/` 에 물어 수업 비서가 답하는지 확인하고, 다른 프로그램이면 ⚠ 로 알린다(컴퓨터에 설정된 프록시는 쓰지 않는다). 지도서 폴더(`D:\지도서`)는 집 PC 에만 있으면 되므로 없어도 ✅ 로 안내한다.
- 시험: `python -m pytest tests -v` (가짜 환경으로 항목별 성공·실패 판단을 확인).

## 교사용 사용 설명서 (한 장)

화면은 위에서 아래로 쓰는 순서와 같이 놓여 있어요. 그림 없이 순서대로 따라 하면 됩니다.

**0. 켜기** — `실행_수업비서.bat` 을 더블클릭합니다. 화면 왼쪽에 수업 비서가 열려요. 처음 쓰는 PC 라면 먼저 `점검_PC.bat` 을 한 번 돌려 ❌ 가 없는지 봅니다.

**1. 날짜와 교시 고르기 (맨 위)**
- `‹` `›` 로 하루씩, 달력으로 날짜를 골라요. `오늘` 을 누르면 오늘로 돌아와요.
- 그 아래 교시 탭(1교시, 2교시…)을 눌러 수업을 골라요. 지금 교시는 노란 테두리예요. 📋 는 수업 흐름이 준비됐다는 뜻, ✓ 는 이 수업 기록이 저장됐다는 뜻이에요.
- 시간표에서 불러온 수업이 아니면 진도 조정은 못 해요.

**2. ☀ 오늘 준비 · 🌙 내일 준비 (맨 위 오른쪽)**
- 아침에는 **☀ 오늘 준비**, 방과 후에는 **🌙 내일 준비**를 눌러 해당 날짜의 흐름 없는 차시를 지도서로 자동 준비해요. 차시마다 30초~2분 걸릴 수 있어요.
- 아침에 `실행_수업비서.bat` 을 켜면 오늘 수업도 자동으로 준비돼요.
- 자동으로 만든 흐름이 마음에 안 들면 **✏ 흐름 고치기** 로 직접 고쳐요. 고친 흐름은 다음 자동 준비가 덮어쓰지 않아요.

**3. 지금 할 일 (수업 중 맨 위 큰 카드)**
- 지금 단계, 💬 핵심 발문, 활동, 💡 팁이 크게 보여요. 큰 숫자는 이 단계의 남은 시간이에요(1분 이하 주황, 지나면 빨강).
- `다음 단계 ▶`(또는 → 키)로 넘기고 `◀`(← 키)로 되돌려요.
- 시간이 모자라면 `−1분` `+1분`(또는 `−` `+` 키)로 이 단계 시간만 이번 수업에서 바꿔요. 흐름 파일은 그대로예요. 시간이 모자라면 ✂ 로 줄여도 되는 단계를 알려 줘요. 교시 끝까지 시간이 모자라면 `⏩ 뒤 단계 N분 줄이기` 단추가 나타나요. 누르면 지금 단계 뒤쪽 단계들의 분을 모자란 만큼 한 번에 줄여요(단계 분에 비례, ✂ 줄여도 됨은 더·⭐ 핵심은 덜, 한 단계는 1분 밑으로 안 내려감). 잘못 줄이면 단계마다 `+1분`으로 되돌려요.
- 흐름이 없으면 🌙 로 준비하라고 안내해요.

**4. 수업 전에 보면 좋은 것 (카드 아래, 접었다 펴요)**
- ⚠ 이번 수업에서 주의할 점: 출판사별 주의점과 지난 수업의 고칠점.
- 📘 수업 흐름 전체, 📗 단원 개관: 단계를 눌러 바로 이동할 수 있어요.
- 🤖 AI와 수업 준비: 자료를 모아 폴더를 열고 질문을 복사한 뒤 고른 AI 사이트를 열어요. 학생 이름이 든 메모는 넣지 마세요.
- `🖥 수업 사이트 열기`, `📂 차시 자료`, `📄 지도서` 단추는 수업 제목 줄에 있어요. 아이디·비번 복사 단추는 비밀번호를 클립보드로만 넘기고 30초 뒤 지워요.

**5. 메모 남기기 (🎙 수업 기록)**
- `● 수업 시작` 을 누르면 녹음이 시작되고 10초마다 저장돼요.
- 수업 중에는 `👍 좋았음` `🔧 고칠점` `🙋 학생 발표` `★` 를 눌러 그 순간을 남겨요. 이유를 입력칸에 먼저 적고 누르면 함께 기록돼요. `🎤 음성 메모` 는 말로 남겨요(소리가 구글 서버로 가요).
- 이 기록은 다음에 같은 과목 수업을 열 때 "주의할 점"에 나와요.
- 📢 알림장·숙제: 글을 쓰고 `복사하고 하이클래스 열기` 를 누르면 복사되고 하이클래스가 열려요. 올리는 것은 직접 해요.

**6. 진도 조정 (📅 진도 조정) — 계획과 실제가 다를 때**
- `✅ 이 차시 완료`: 이 차시를 마쳤다고 표시해요.
- `➕ 한 차시 더 필요`: 한 시간 더 쓰고 뒤 진도를 하나씩 밀어요.
- `⏭ 이후 진도 미루기`: 며칠 미룰지 물어봐요(처음 값 7일).
- `📍 실제로 할 차시 고르기`: 오늘 실제로 할 차시를 검색해서 눌러요. 앞 차시는 '이미 함'이 되고, 고른 차시가 오늘 칸에 나와요. 회색 '✓ 함' 차시를 누르면 거기로 되돌려요.
- `🏫 과목·차시 바꾸기`: 이 교시에 다른 과목을 할 때 그 과목의 안 한 차시를 골라요. 원래 과목의 차시는 다음 같은 과목 시간으로 밀려요.
- 누르면 **확인 창**이 뜨고, 확인해야 Supabase 진도에 바로 반영돼요. 되돌리고 싶으면 다시 `📍` 로 원하는 차시를 골라요.

**막히면**: 화면이 비었으면 `점검_PC.bat` 결과를 보고, 진도가 안 바뀌면 중앙 `.env` 의 Supabase 설정부터 확인해요.

## 수업 메모 동기화 (`memo_sync.py`)

수업 메모를 Supabase(`lesson_memos` 표)에 올리고, 다른 PC 에서 받아 `sessions/` 파일에 합치는 부품이다. **아직 수업 비서 서버·아침 bat 에는 연결하지 않았다**(연결은 교사 PC 에서, TASKS T49). 필요한 표는 `sql/lesson_memos.sql`(Supabase 에서 실행), 키는 진도와 같은 중앙 `.env`(`SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`)에서 읽고 화면·출력에는 내보내지 않는다.

| 하고 싶은 일 | 방법 |
|---|---|
| 올리기 | 코드에서 `from memo_sync import push_session; push_session(session)`. 실패해도 예외 없이 결과만 돌려주고, 못 올린 것은 데이터 폴더 `memo_queue/` 에 쌓아 두었다가 다음에 먼저 다시 올린다 |
| 내려받기 | `python memo_sync.py pull --days 30` (또는 `--since 2026-11-01`, `--all`). 아침 bat 용: `pull --if-older 24` — 마지막 내려받기가 24시간 안이면 건너뜀 |
| 못 올린 것만 다시 올리기 | `python memo_sync.py flush` |
| 시험 | `python -m pytest tests/test_memo_sync.py` (가짜 서버라 진짜 DB 에 가지 않음) |

- 같은 메모는 고유값(`memo_key`)으로 한 번만 들어간다. 받아 온 메모에는 서버의 `memo_key` 를 그대로 저장해, 다시 받아도 늘어나지 않고 이 PC 에서 다시 올려도 새 메모가 되지 않는다.
- 🙋 학생 발표 메모(`student`)는 올리지도 받지도 않는다. 📝·🔧·🎤 같은 자유 글 메모는 **그대로 올라가므로, 학생 이름이 적혀 있으면 서버에도 올라간다**(교사 결정 대기, T49).
- 단계 기록(`step`·`sys`·`adj`)은 다른 PC 에서 수업 단계를 이어 가려고 올린다. 올리고 싶지 않은 종류는 중앙 `.env` 에 `TEACHERLESSON_ASSISTANT__MEMO_SKIP_KINDS=step,sys,adj` 처럼 적는다(쉼표나 띄어쓰기로 구분). 안 적으면 학생 메모만 빠지고 나머지는 올라간다. 받는 쪽에는 영향이 없다.
- 명령줄 출력은 UTF-8 이다. 직접 실행해서 한국어가 깨져 보이면 먼저 `chcp 65001` 을 실행한다(`실행_수업비서.bat`·`점검_PC.bat` 은 이미 한다).

## 화면 기능 (v0.1)

수업 중에는 상단의 **🎯 수업 진행**을 눌러 집중 화면으로 바꾼다. 왼쪽에서 단계를 고르고, 가운데 발문·활동·팁을 보며, 오른쪽에서 시간·다음 단계·준비물과 녹음·빠른 메모를 쓴다. 아래 고정 버튼과 방향키·발표 리모컨으로 단계를 이동한다. **↩ 준비 화면**으로 날짜·진도·자료 메뉴에 돌아간다.

| 영역 | 내용 |
|---|---|
| 위쪽 | 날짜 이동(달력·요일·'오늘'), ☀ 오늘 준비·🌙 내일 준비(해당 날짜의 흐름 없는 차시를 Gemini 로 자동 준비, 아침 bat 에서도 오늘 것 자동), 시계, 교시 탭(지금 교시 노란 테두리, 📋 흐름 준비됨, ✓ 기록 저장됨), 📞 내선번호(부서·교실 검색, 내선만 표시) |
| 수업 제목 | 과목·출판사·단원·차시, 수업 사이트 열기, 📂 차시 자료 바로 열기(`sites/` 도우미, config `subjects.<과목>.helper`), 아이디/비번 복사, 지도서 PDF(Supabase 차시 경로) |
| **지금 할 일** | 수업 중 맨 위 큰 카드: 현재 단계·💬 핵심 발문·활동·💡 팁, 단계 남은 시간(1분 이하 주황 / 초과 빨강 `+mm:ss`), 교시 종료까지 남은 분, 다음 단계 미리보기. `다음 단계 ▶` 단추·← → 키·발표 리모컨(PageUp/PageDown)으로 넘김. `−1분`/`+1분` 단추·`+` `−` 키로 이 단계 시간만 이번 수업에서 조정(흐름 파일은 그대로). 시간표 대비 `계획보다 N분 늦음 · 교시 끝까지 N분 모자라요` 안내. 시작 전에는 시간표 시각으로 "지금쯤 어느 단계" 추천. 새로고침해도 단계·시간 유지. 큰 숫자 옆 `−1분`/`+1분`(또는 `+` `−` 키)으로 그 단계 시간을 이번 수업에만 조정하고, `⏱ 계획보다 N분 늦음 · 교시 끝까지 N분 모자라요` 안내와 함께 시간이 모자라면 `✂ 줄여도 되는 단계`(단계 `flag: cut`)를 알려 준다. 흐름(`flows/*.json`)이 없으면 🌙 준비 안내 |
| 🤖 AI와 수업 준비 | 단원 개관·차시 지도서 PDF(+NotebookLM 차시 노트)를 `ask/<날짜>/<교시>_<과목>/`에 모아 폴더 열기 + 질문 복사 + 고른 AI 사이트 열기. NotebookLM 은 과목 노트북을 열고 질문만 복사 |
| 주의할 점 | 출판사별 주의점(`publisher_notes.json`) + 같은 과목 지난 수업 메모·고칠점 |
| 📗 단원 개관 | `units/*.json`의 단원 흐름(지금 차시 ◀)·목표·유의점·평가, 단원 개관 PDF (접기/펴기) |
| 수업 흐름 전체 (접이식) | `flows/*.json`의 목표·준비물·전체 단계(활동, 💬발문, 💡팁). 단계를 눌러 바로 이동 가능. 단계 이동 시 시각 기록(`sessions` 메모의 `step`, `idx` 포함). **✏ 흐름 고치기/직접 만들기**로 화면에서 편집(목표·준비물·단계 이름·분·활동·발문·팁·중요도 ⭐꼭 해야 함/✂ 줄여도 됨)·저장(`POST /api/flow`, 고친 흐름은 자동 준비가 덮어쓰지 않음) |
| 수업 기록 | 녹음(10초마다 서버에 이어 저장), 👍좋았음 🔧고칠점 🙋학생 발표 ★표시 🎤음성 메모, 직접 입력 메모. 모두 녹음 기준 [mm:ss] |

## 저장 위치 (깃에 올리지 않음)

`내 문서\my-skills-data\teacherlesson-assistant\`

- `config.json` — 교시 시각, 내선번호, 바로가기, 과목별 출판사·사이트·`secret_prefix`, `schedule_backend`, `ai_sites`. 처음 실행 때 `config.example.json`을 복사해 만든다. 그 밖에 `left_ratio`(수업 비서 창 너비 비율, 기본 0.32), `helper_python`(📂 차시 자료 도우미를 돌릴 Python, 안 적으면 `C:\Python313\python.exe`, 없으면 서버와 같은 것), `google_account_hint`(지도서 받기에서 고를 구글 계정)를 쓴다. 연락처는 비공개 데이터 폴더의 `phones`에 역할 이름과 내선만 입력한다. 외부 전화번호·개인 휴대전화는 저장소 예시나 코드에 넣지 않는다.
- `units/<과목>__<대단원>.json`·`.pdf` — 단원 개관 (`build_units.py`가 만든다)
- `flows/<record_key>.json` 또는 `flows/<과목>__<차시제목>.json` — 수업 흐름 (선택). Supabase 차시의 record_key 는 `lesson-0075` 같은 차시 번호(`lesson_lessons.legacy_lesson_id`)
- `sessions/<날짜>/<교시>교시_<과목>_<차시ID>.json` — 차시별 메모·알림장·시작/마침 시각. 예전 ID 없는 파일도 읽고, 다른 차시 기록은 현재 차시에 잘못 붙이지 않는다.
- `sessions/<날짜>/<교시>교시_<과목>_<시각>.webm` — 녹음
- `sessions/<날짜>/export/<같은 이름>.mp3` — 클로바노트용으로 바꾼 파일(🎧 단추를 누르면 만들어지고, 원본이 더 붙기 전까지 다시 쓴다)
- `ask/<날짜>/<교시>_<과목>/` — 웹 AI에 끌어다 놓을 PDF와 질문.txt
- `notebooklm/<과목>/` — NotebookLM 소스(`<대단원>.md`, `_그림.pdf`), `notes/` 차시별 노트, `목록.txt`
- `reports/week-<월요일>.md` — 주간 정리 글 (`python weekly_report.py [--date YYYY-MM-DD]`). 과목·출판사별 고칠점·좋았음, 출판사 주의점 후보, 학생별 발표 메모. **학생 이름이 있으니 밖에 보내지 않는다**
- `stt_words.json` — 받아쓰기 사전(선택). `"자주 쓰는 말"`(받아쓰기 힌트, 200자까지)·`"고쳐 쓰기"`(틀린 말→맞는 말, 낱말 경계·긴 것부터, 뒤의 조사는 그대로 둠). 파일을 못 읽거나 모양이 틀리면 받아쓸 때 ⚠ 로 알려 준다. 학생 이름이 들어갈 수 있어 저장소에는 `stt_words.example.json`(가짜 낱말)만 있다. 화면 편집 칸은 아직 없고 파일을 직접 고친다
- `publisher_notes.json` — `{"출판사|과목": [{"text","date"}], "출판사|*": [...]}`

아이디·비밀번호는 중앙 .env(`OneDrive\96. 인증\.env`)에 `<secret_prefix>_ID`, `<secret_prefix>_PW`로 적는다(예: `ISCREAM_ID`). 서버는 값을 화면에 보내지 않고 클립보드로만 넘긴다.

## NotebookLM 소스 (학기에 한 번)

공용 도구는 [`util-notebooklm`](../util-notebooklm/SKILL.md)(글자 뽑기·그림 PDF·md 자르기·노트북 목록·Gemini 찾기). 여기 있는 것은 진도표 차시에 맞추는 수업용 부분이다.

1. `py -3.13 notebook_sources.py [과목…] [--all] [--open]` — 진도표의 단원마다 `notebooklm/<과목>/<대단원>.md` 를 만든다(LLM 없음, 전 과목 30초 안팎).
   - 지도서 글자만 뽑고 차시마다 `## [수학 6단원] 4차시 제목 (지도서 p.25~28)` 표시를 심는다. 쪽마다 `〔p.N〕`.
   - 국어 단원 한 권은 쪽 머리의 `3~4차시 / 14차시`, 매체 단원은 `이 차시는 '다가가기' 학습` 표시로 차시를 나눈다.
   - 글자가 거의 없는 쪽과 음악·미술(`notebooklm_image_subjects`) 단원 전체는 `<대단원>_그림.pdf`(흑백, 쪽마다 차시 표시)로 따로 만든다.
   - 지도서 PDF가 이 PC에 없는 차시는 제목만 넣고 "PDF 없음"으로 알려 준다(지금 음악).
2. 과목마다 노트북을 하나 만들고 그 과목 폴더의 `.md`·`_그림.pdf` 를 소스로 올린다(공개 API가 없어 직접). 한도: 소스당 50만 단어/200MB.
3. 노트북 주소를 `C:\Python313\python.exe ..\util-notebooklm\nlm.py nb add 수업-수학 <주소>` 로 등록한다(또는 `config.json` 의 `subjects.<과목>.notebooklm`) → 🤖 줄의 **NotebookLM** 단추가 그 노트북을 열고 `[과목 N단원] N차시` 를 짚는 질문을 복사한다(파일은 모으지 않음).
4. 답을 오빠두엑셀 북마클릿 등으로 md 로 받았다면 `python split_notes.py 받은.md` → `notebooklm/<과목>/notes/<N단원>_<N>차시.md` 로 잘린다. 그 차시에 다른 AI 단추를 누르면 이 노트도 `ask/` 폴더에 함께 들어간다.
