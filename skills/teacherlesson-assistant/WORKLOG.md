# 작업 기록 (운영 정보)

> 문제·해결 기록은 [ISSUES.md](ISSUES.md)에 한곳으로 모았다(2026-11-25 정리). 이 파일에는 날짜별 요약과 링크, 그리고 운영 정보(수업 흐름이 만들어지는 순서)만 둔다.

## 수업 흐름이 만들어지는 순서 (운영 정보)

1. `notebook_sources.py`가 지도서 PDF에서 글자를 뽑아 `notebooklm/<과목>/<단원>.md`에 차시별 구간을 만든다.
2. `prepare_lessons.py`는 해당 차시 구간을 우선 가져와 Gemini CLI로 수업흐름 JSON을 만든다. 구간이 없으면 Supabase 차시의 PDF 경로에서 쪽을 발췌한다.
3. 결과는 `flows/<lesson_id>.json`에 저장하고 수업 비서가 읽는다.

NotebookLM 단추는 과목 노트북을 열고 질문을 준비하는 별도 기능이다. 자동 수업 준비 단추는 NotebookLM에 직접 질문하지 않고, NotebookLM에 올릴 때 쓰는 같은 `.md` 소스를 Gemini에 전달한다.

## 2026-11-25 — 사회 수업 준비: 원본 지도서 경로 복구

- 오늘 준비 상태에서 사회 3·4교시(`lesson-0553`, `lesson-0554`)가 `지도서 PDF 없음`으로 실패했다. Supabase 경로는 `pdf_splits` 아래 분할 PDF였고, 이 PC에는 그 파일뿐 아니라 연결된 단원 폴더도 없었다. `D:\지도서\사회 3-2`에는 `[사회]3-2_지도서_2단원.pdf` 원본이 있었다.
- 기존 `resolve_pdf_path()`는 상위 단원 폴더가 실제 존재하고 분할 파일명에 기대한 번호 패턴이 있을 때만 복구했다. 실제 저장 구조와 맞지 않았다. 경로 안 단원 폴더명에서 `2단원`을 읽고 그 폴더 및 한 단계 위 학년 폴더에서 고유한 `*지도서*2단원*.pdf`를 찾도록 보강했다. 여러 후보가 있거나 단원 번호를 못 찾으면 잘못 연결하지 않도록 원래 경로를 유지한다.
- 진도표 쪽수(75~80, 81~89)에 맞춰 두 차시 PDF를 각각 추출했고, 첫 페이지 제목·본문이 ‘옛날 사람들이 교통수단을 이용했던 모습’과 ‘오늘날 사람들이 교통수단을 이용하는 모습’에 맞는 것을 확인했다.
- 오늘 준비를 다시 실행해 `lesson-0553`은 4단계, `lesson-0554`는 5단계 흐름을 저장했다. 전체 작업 로그는 새로 준비 2, 실패 0이다. 추출한 페이지의 인쇄 쪽수를 확인해 흐름 출처를 `p.190-195`, `p.196-204`로 바로잡았다(Gemini가 두 번째 차시를 `p.1-4`로 잘못 반환했음). 테스트 모음은 실행하지 않았다.
- 경로 복구 범위와 실제 사례는 `ISSUES.md` ISSUE-026에 추가했다.

## 2026-11-25 — 듀얼 모니터 배치 바로잡기와 녹음 불러오기 확인

- 처음 요청을 같은 모니터의 좌우 분할로 잘못 해석했다. 현재 PC의 두 모니터 좌표를 확인해 수업 비서는 왼쪽 화면 약 1/3(614×1040), 교과 사이트는 오른쪽 화면 전체로 배치하도록 `monitor_rects()`와 `open_window()`를 바꿨다. 오른쪽 화면이 없는 경우는 왼쪽 화면의 나머지 영역을 쓴다. 바탕화면 바로가기는 저장소의 `실행_수업비서.bat`으로 연결돼 있다.
- `/api/recordings`에서 빠진 `Path` 참조와 재생 주소 파싱 오류를 고쳤다. 11/25 사회 녹음 2건이 목록에 뜨고, webm 파일 부분 요청이 HTTP 206으로 응답하는 것을 확인했다. 화면에서 목록은 `🎧 저장된 녹음 2건 보기`, 각 항목은 브라우저 재생과 원본 저장을 제공한다.
- 창을 맨 앞으로 올리는 `SetWindowPos`가 위치·크기 인수를 0으로 덮어쓰는 것도 발견해 플래그를 수정했다. 비서 창은 (0,0) 614×1040, 아이스크림 사이트 새 창은 (1920,0) 1920×1080인 것을 확인했다. 바탕화면 바로가기는 이 저장소의 실행 bat을 가리킨다. 코드 구문 검사와 `git diff --check`는 통과했다. 자동 시험은 실행하지 않았다([ISSUE-033](ISSUES.md), [ISSUE-038](ISSUES.md)).
