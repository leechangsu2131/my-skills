# 학교 PC 처음 설치 안내서

학교 PC 에서 **수업 비서를 처음 켜기 전에 한 번만** 하는 일입니다. 위에서부터 차례로 하고, 단계마다 **"확인"** 을 보고 넘어가세요.
다 하면 마지막에 `점검_PC.bat` 이 빠진 것을 한 번 더 찾아 줍니다.

- 걸리는 시간: 처음이면 약 30~40분(추정). 대부분 프로그램 내려받기·설치 시간이에요.
- 이 안내서는 **설치와 로그인**만 다룹니다. 학생 정보·비밀번호·키 값은 여기에 적지도, 이 저장소에 올리지도 않아요.
- 집·교사 PC 에는 이미 다 되어 있어서, 이 안내서는 **학교 PC(또는 새 PC)** 용이에요.

## 한눈에 보기

| 순서 | 할 일 | 안 하면 |
|---|---|---|
| 1 | OneDrive 에 학교 계정(gyo6.net) 로그인 | 비밀 설정 파일(`.env`)과 공유 데이터를 못 읽음 |
| 2 | Python 3.13 설치 | 수업 비서가 안 켜짐 |
| 3 | 수업 비서 폴더 준비 | 켤 파일이 없음 |
| 4 | 파이썬 부품 설치 | 수업 비서가 안 켜짐 |
| 5 | Node.js + Gemini CLI 설치 | 🌙 자동 수업 준비만 안 됨 |
| 6 | Chrome 설치 + 수업 사이트 로그인 | 📂 수업 사이트 열기만 안 됨 |
| 7 | `점검_PC.bat` 으로 확인 | (빠진 것을 모른 채 시작하게 됨) |
| 8 | `실행_수업비서.bat` 으로 켜기 | |

---

## 1. OneDrive 에 학교 계정 로그인

- 작업표시줄의 OneDrive 아이콘에서 학교 계정(`gyo6.net`)으로 로그인하고 **동기화를 켭니다.**
- **확인**: 탐색기 왼쪽에 `OneDrive - gyo6.net` 폴더가 보이고, 그 안에 `96. 인증` 폴더가 있다. (`96. 인증` 안의 `.env` 가 비밀 설정 파일이에요. 열어서 값을 보거나 복사하지 않아도 됩니다.)
- 아직 동기화 중이면 `96. 인증` 이 조금 늦게 나타날 수 있어요. 몇 분 기다리세요.

## 2. Python 3.13 설치

1. <https://www.python.org/downloads/> 에서 Python **3.13** 을 내려받아 설치합니다.
2. 설치 첫 화면 아래의 **"Add python.exe to PATH"(Add to PATH)를 꼭 체크**합니다. `py launcher` 항목도 켜 둔 채로 두세요(기본값).
3. 설치가 끝나면 **열려 있던 명령 창을 모두 닫고 새로 엽니다.**

- **확인**: 시작 메뉴에서 `cmd` 를 열고 아래 두 줄이 모두 `Python 3.…` 를 보여 준다.
  ```
  python --version
  py -3.13 --version
  ```
  - 수업 비서는 단원 개관은 `py -3.13`, 서버·수업 준비는 `python` 으로 켭니다. **둘 다 되는 것이 가장 좋아요.**
  - `py` 만 안 되면 단원 개관 자동 갱신 대신 `python` 으로 대신하니 켜는 데는 지장이 없어요. `python` 이 안 되면 서버가 안 켜지니 PATH 체크를 다시 확인하세요.
  - Python 3.10 보다 낮으면 ❌, 3.10~3.12 는 ⚠(권장 3.13)로 나와요.

## 3. 수업 비서 폴더 준비

수업 비서 파일은 저장소의 `skills/teacherlesson-assistant` 폴더에 있습니다(`실행_수업비서.bat`, `점검_PC.bat`, `check_setup.py`, `requirements.txt` 등이 들어 있어요).
이 폴더가 학교 PC 에 있어야 합니다.

- **확인**: 그 폴더 안에서 `실행_수업비서.bat` 과 `점검_PC.bat` 이 보인다.
- **확인 필요**: 학교 PC 에 이 폴더를 받는 방법(저장소 복사·USB 등)은 저장소에 적혀 있지 않아요. 교사에게 물어보세요. 저장소 주소는 <https://github.com/leechangsu2131/my-skills> 입니다(저장소 복사에 쓰는 Git 이 학교 PC 에 있는지도 확인 필요).
- 이미 폴더가 있다면 이 단계는 건너뜁니다.

## 4. 파이썬 부품 설치

수업 비서 폴더에서 명령 창을 열고(폴더 주소창에 `cmd` 라고 쓰고 Enter) 아래 두 줄을 차례로 실행합니다.

```
py -3.13 -m pip install -r requirements.txt
py -3.13 -m pip install selenium
```

(`py` 가 안 되는 PC 면 `py -3.13` 자리에 `python` 을 쓰세요.)

- `requirements.txt` 에는 `requests`, `truststore`, `PyMuPDF` 가 들어 있어요.
- `selenium` 은 📂 차시 자료 바로 열기·지도서 받기에만 필요해서 따로 설치합니다.
- **확인**: 7단계 `점검_PC.bat` 결과에서 `패키지 requests`, `패키지 truststore`, `패키지 PyMuPDF`, `패키지 selenium` 이 모두 ✅ 로 나온다. (`requests`·`truststore`·`PyMuPDF` 가 없으면 ❌, `selenium` 이 없으면 ⚠.)
- 설치가 인터넷 차단으로 안 되면 **확인 필요** — 교사에게 알려 주세요.

## 5. Node.js 와 Gemini CLI 설치 (🌙 자동 수업 준비용)

이 단계는 **자동 수업 준비(🌙)와 지도서 찾기를 쓸 때만** 필요해요. 안 해도 수업 비서는 켜집니다.

1. <https://nodejs.org> 에서 **LTS** 를 설치합니다. 설치 후 명령 창을 닫고 새로 엽니다.
2. 새 명령 창에서:
   ```
   npm i -g @google/gemini-cli
   ```
3. **로그인 방법 두 가지 중 하나**
   - 중앙 `.env` 에 Gemini 키가 이미 있으면(1단계 OneDrive 로 같이 옴) **로그인이 필요 없어요.**
   - 키가 없으면 이 PC 의 **구글 로그인**을 씁니다. 명령 창에서 `gemini` 를 한 번 실행해 나오는 안내에 따라 구글 계정으로 로그인합니다. (화면 안내 순서는 **확인 필요** — Gemini CLI 버전마다 다를 수 있어요.)

- **확인**: `점검_PC.bat` 에서 `Node.js`, `Gemini CLI` 가 ✅. 안 하면 ⚠ 로 "🌙 수업 준비가 안 돼요" 라고 나옵니다. `키 이름 Gemini 키` 가 ⚠ 인 것은 위 "구글 로그인"을 쓴다는 뜻이라 정상이에요.

## 6. Chrome 설치 + 수업 사이트 로그인

1. <https://www.google.com/chrome> 에서 Google Chrome 을 설치합니다(보통 위치에 설치해야 수업 비서가 찾아요).
2. 수업 비서를 켠 뒤(8단계) 화면의 **"수업 사이트 열기"** 를 처음 누르면, 수업 비서 전용 Chrome 창이 열리고 전용 프로필 폴더(`%LOCALAPPDATA%\MusicClassHelper\chrome_profile`)가 **그때 만들어져요.**
3. 그 창에서 **출판사 사이트와 구글에 한 번씩 로그인**합니다. 한 번 로그인하면 다음부터 이어서 써요.
4. 아이디·비밀번호로 로그인하는 사이트(예: 도덕)는 값을 **중앙 `.env`** 에 `<접두사>_ID`, `<접두사>_PW` 모양으로 적어 둡니다(예: `TSHERPA_ID`, `TSHERPA_PW`). **값을 이 저장소나 `config.json` 에 적지 마세요.** 중앙 `.env` 는 OneDrive 로 같이 옵니다.

- **확인**: `점검_PC.bat` 에서 `크롬 실행 파일` 이 ✅. `크롬 프로필 폴더(chrome_profile)` 는 처음엔 ⚠ "아직 없음" 이 정상이고, 수업 사이트를 한 번 열면 ✅ 가 돼요.
- 수업용 Chrome 은 원격 디버깅 포트 `9233` 을 써요(`9222` 는 다른 자동화가 쓸 수 있어서 피함).

## 7. 점검하기 — `점검_PC.bat`

수업 비서 폴더의 **`점검_PC.bat` 을 더블클릭**합니다(또는 그 폴더에서 `python check_setup.py`).
읽기만 하고 아무것도 설치·수정하지 않으며, 비밀 설정 파일의 **값은 보여 주지 않고 키 이름이 있는지만** 봅니다.

항목마다 표시가 나와요.

| 표시 | 뜻 |
|---|---|
| ✅ | 괜찮아요 |
| ⚠ | 그 기능을 쓸 때만 필요해요. 급하지 않으면 넘어가도 돼요 |
| ❌ | 꼭 고쳐야 해요. 수업 비서가 제대로 안 돌아요 |

항목 옆의 **"→ 고치기:"** 한 줄을 그대로 따라 하면 됩니다. 고친 뒤 다시 `점검_PC.bat` 을 실행하세요. **❌ 가 하나도 없으면 시작해도 돼요.**

### 처음 PC 에서 자주 보는 ⚠ 와 ❌

| 표시된 항목 | 처음에 그렇게 나오는 까닭 | 할 일 |
|---|---|---|
| ❌ Python 버전 | 3.10 보다 낮음 | 2단계 다시 |
| ❌ 패키지 requests·truststore·PyMuPDF | 4단계를 안 함 | 4단계 |
| ⚠ 패키지 selenium | 4단계 둘째 줄을 안 함 | 4단계 |
| ⚠ Python 실행기 | `py -3.13` 또는 `python` 이 안 되거나 서로 버전이 다름 | 2단계 확인 |
| ⚠ Node.js / Gemini CLI | 5단계를 안 함 | 🌙 자동 준비를 쓰려면 5단계 |
| ❌ 크롬 실행 파일 | Chrome 이 없음 | 6단계 1번 |
| ⚠ 크롬 프로필 폴더 | 수업 사이트를 아직 안 열어 봄 | 정상. 6단계 2~3번 |
| ❌ 중앙 .env 위치 | OneDrive 로그인·동기화가 아직 | 1단계 |
| ❌ 키 이름 SUPABASE_URL·SUPABASE_SERVICE_ROLE_KEY | 중앙 `.env` 에 그 키 이름이 없음(진도 저장소가 supabase 일 때) | 교사에게 알림. **값을 직접 만들거나 메신저로 주고받지 마세요** |
| ⚠ 데이터 폴더·하위 폴더(flows·units·notebooklm) | 아직 없음 | 서버를 처음 켜면 만들어져요. 집 PC 의 같은 폴더를 OneDrive 로 옮겨 오면 흐름·단원 개관도 그대로 써요 |
| ⚠ OneDrive 폴더 | 로그인·동기화가 아직 | 1단계 |
| ⚠ 5180번 포트 (수업 비서) / 9233번 포트 (수업용 크롬) 닫혀 있음 | 아직 안 켠 것이라 정상 | 8단계 |
| (정상) 지도서 폴더 없음 | 지도서 PDF 는 집 PC 에만 두고, 학교 PC 는 만들어 둔 흐름·단원 개관만 써요 | 할 일 없음 |

## 8. 켜기 — `실행_수업비서.bat`

- `실행_수업비서.bat` 을 더블클릭합니다. 교사 PC 에는 바탕화면에 `수업 준비 비서` 바로가기가 있고, 이 파일을 가리켜요. 학교 PC 에도 같은 이름으로 바로가기를 만들어 두면 편해요(우클릭 → 보내기 → 바탕화면에 바로 가기, **확인 필요**: 화면 이름은 Windows 버전마다 조금 달라요).
- 켜면 자동으로 단원 개관을 갱신하고(12시간에 한 번), 오늘 수업 중 흐름이 없는 차시를 뒤에서 준비해요(Gemini 가 있을 때). 수업 비서 화면은 `http://127.0.0.1:5180/` 에서 열려요.
- 이 창(검은 창)은 **수업 비서가 켜져 있는 동안 닫지 마세요.**
- **확인**: 왼쪽에 수업 비서 화면이 열리고, 위쪽에 오늘 날짜와 교시 탭이 보인다. 이때 `점검_PC.bat` 을 다시 돌리면 `5180번 포트 (수업 비서)` 가 ✅ "수업 비서가 켜져 있어요" 로 바뀝니다.

## 막혔을 때

| 증상 | 먼저 해 볼 것 |
|---|---|
| `python` 을 찾을 수 없다고 나옴 | 2단계의 PATH 체크를 하고 명령 창을 닫았다 다시 열기. `점검_PC.bat` 은 이 경우 설치 주소를 알려 줘요 |
| 한국어가 깨져 보임 | 명령 창에서 `chcp 65001` 입력(두 bat 파일은 이미 해 줘요) |
| 화면이 비었음 | `점검_PC.bat` 결과의 ❌ 부터 고치기 |
| 진도가 안 바뀜 | 중앙 `.env` 의 Supabase 키 이름 두 개가 있는지 `점검_PC.bat` 으로 보기 |
| 수업 사이트 열기가 안 됨 | Chrome 설치(6단계), `selenium` 설치(4단계) 확인 |
| 🌙 자동 준비가 안 됨 | Node.js·Gemini CLI(5단계), Gemini 키 또는 구글 로그인 확인 |
| 그래도 안 됨 | `점검_PC.bat` 결과 화면을 **캡처(값이 보이는 부분이 있으면 가리고)** 해서 교사에게 보내기 |

## 이 안내서가 의존하는 것 (바뀌면 같이 고치기)

`점검_PC.bat`·`실행_수업비서.bat`·`check_setup.py`·`requirements.txt`·`config.example.json` 의 이름과 동작. 점검 항목이나 이 파일들이 바뀌면 이 안내서의 표도 맞춰 주세요. 자세한 점검 항목은 `README.md` 의 "학교 PC 점검" 절에 있어요.
