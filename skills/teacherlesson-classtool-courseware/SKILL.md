# 클래스툴 수업자료 제작

클래스툴에 맞춘 수업자료와 활동 흐름을 만든다. 공통 수업 구조와 출력 형식은 [상위 수업꾸러미 제작 스킬](../teacherlesson-courseware-builder/SKILL.md)의 표준을 따른다. 클래스툴에서는 특히 자료 공개 범위와 학생 클래스 배포 대상을 구분한다.

## 시작 정보

- 필수: 학년/교과/주제, 원하는 활동과 학생 결과, 수업자료 공개 범위(교사 자료실 공유 여부), 배포할 클래스 또는 클래스 선택이 필요한지.
- 응답이 필요하면 수업 중 실시간 답변인지, 수업 후에도 남아 있어야 하는 제출인지 먼저 구분한다.
- 실제 수업 자료 작성 전 사용자가 지정한 클래스, 공개 여부, 비밀번호, 학생 정보 설정을 확인한다. 학생 명단 편집이나 클래스 설정 변경은 별도 요청 없이 하지 않는다.

## 제작 절차

1. 수업 목표와 활동을 정리한 뒤 [클래스툴 매핑 양식](../teacherlesson-courseware-builder/references/course-package-template.md)에 자료를 정리한다.
2. 현재 편집일의 ClassTool 화면과 [기능 확인 기록](references/site-capabilities.md)을 대조한다. 공식 매뉴얼에서 확인한 과거 기능을 현재 화면에서 확인된 것처럼 표현하지 않는다.
3. 수업자료 제목·학교급·학년·학기·교과·차시를 넣고, 공개 또는 비공개 의도를 설정한다. 공개는 교사 수업자료실 공유를 뜻할 수 있으며, 학생 접속은 대상 클래스에 자료를 연결해야 한다.
4. 클래스툴이 제공하는 활동 중 목적에 맞는 것을 순서대로 설계한다: 웹 링크, 콘텐츠 전송, OX, 객관식, 주관식, 화이트보드 등. 웹 링크나 영상·PDF를 포함할 때 실제 접근성을 확인한다.
5. 주관식 응답은 매뉴얼상 학생이 실시간으로 제출하고 교사가 답변을 모아 볼 수 있다. 지속적인 비동기 제출함으로 안내하지 말고, 현재 기능에서 수업 후 결과와 다운로드 범위를 확인한다.
6. 자료가 완성되면 임시 저장/임시보관함 또는 수업 저장/내 수업 자료로 구분한다. 공개 수업자료를 만들었더라도 실제 학생에게 보내거나 수업을 시작하는 단계는 별도다.
7. 입력을 요청받으면 Ego Lite의 `ego-browser` 지침을 확인하고 현재 로그인된 페이지에서 진행한다. 로그인 화면이면 사용자에게 직접 로그인을 부탁하고 비밀번호는 받거나 저장하지 않는다.
8. 수업 활동 미리보기, 학생 응답 흐름, 배포 대상과 공개 설정을 확인한다. 사이트 등록·공개는 사용자가 요청한 경우에만 한다.

## 자료 및 개인정보

- 2025년 3월 공식 매뉴얼은 콘텐츠 전송에서 이미지, 동영상, PDF, 웹 링크를 설명한다. PPTX 지원 여부와 크기 제한은 현재 화면에서 확인한다.
- 학생 이름, 개인 사진, 계정 정보, 실제 학생 답변을 공개 수업자료에 포함하지 않는다.
- 외부 영상/링크는 출처와 대상 학년 적합성을 확인한다.
- 오류·미확인 항목은 `records/` Markdown에 상태와 해결 과정을 기록하되 개인정보는 제거한다.
