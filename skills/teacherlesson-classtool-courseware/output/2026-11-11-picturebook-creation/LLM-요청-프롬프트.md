# 다른 LLM에 전달할 자료 제작 프롬프트

아래 프롬프트는 이 수업을 위한 보조자료 제작용입니다. 기존 그림책 본문·표지·캐릭터를 복제하지 않고 새로 만든 예시만 쓰도록 했습니다. Gem은 이 요청에 포함하지 않았습니다.

## 1. 12차시 교사용 진행 PPTX

```text
초등 3~6학년용 12차시 그림책 창작 수업 「우리 반 그림책 작가 되기」의 교사용 진행 PPTX를 만들어 주세요.

첨부한 `course-package.md`와 `classtool-activity-blueprint.md`를 우선 기준으로 삼고, 차시별 교사 발문·활동 흐름·ClassTool 상호작용을 반영해 주세요. 총 12차시, 1차시 40분 기준입니다. 실제 학년은 미정이므로 쉬운 문장과 선택형 난이도(3~4학년/5~6학년 조정 팁)를 넣어 주세요.

구성:
- 표지 및 수업 철학/안전 약속 2장
- 12차시별 2장: 오늘의 목표·준비물·수업 흐름 / ClassTool에 전송할 학생 질문·활동 안내
- 마무리 2장: 작품 공유 전 개인정보·저작권 확인, 교사 준비 체크리스트
- 차시마다 ClassTool 활동 유형(콘텐츠 전송, 객관식, OX, 주관식, 화이트보드, 링크)을 작은 라벨로 표시하고, ClassTool에 입력할 질문을 그대로 복사할 수 있게 별도 상자에 넣어 주세요.

디자인:
- 초등 교사용, 따뜻한 종이·연필 질감의 편집 디자인, 큰 한글 글자와 높은 대비
- 16:9 와이드, 슬라이드 한 장에 핵심 하나, 표보다 카드/단계 도식 우선
- 흐름 색상: 감상은 파랑, 자기표현은 보라, 함께 쓰기는 노랑, 구상은 초록, 제작은 주황, 나눔은 분홍
- 장식용 원본 그림은 직접 새로 만든 단순한 종이책·연필·추상 도형만 사용

중요한 제한:
- 기존 그림책 페이지, 표지, 작가 캐릭터, 연수 PDF의 이미지/로고를 넣지 마세요. 이름과 서지정보 텍스트만 필요할 때 참고문헌 형태로 적습니다.
- 학생 실명·학교명·학생 답변·개인 사진을 넣지 마세요.
- 개인 경험을 공개시키는 질문은 만들지 마세요. 모든 자기표현 활동에 “상상 인물로 해도 됨 / 공유하지 않아도 됨” 대안을 표시해 주세요.
- 진단·치료 활동으로 표현하지 말고, 여섯 조각과 은유거울은 이야기 창작 기법으로만 안내해 주세요.
- ClassTool의 실시간 응답은 수업 중 형성적 상호작용으로 안내하고, 수업 후 지속 제출함으로 설명하지 마세요.

산출물:
1) 편집 가능한 PPTX
2) 같은 내용의 PDF 미리보기(가능한 경우)
3) 사용한 새 그림/아이콘의 출처 또는 직접 제작 여부 목록
4) 슬라이드 제목과 ClassTool에 복사할 문구가 포함된 TXT 또는 Markdown 대본
```

## 2. 인쇄용 학생 활동지 PDF

```text
첨부한 `course-package.md`와 상세 계획의 A1~A11을 바탕으로 초등학생용 그림책 창작 활동지 PDF를 디자인해 주세요. A12 학생 계획서는 Gem 대신 종이로도 쓸 수 있도록 선택형 양식으로 정리해 주세요.

활동지:
A1 한 장면 메모지, A2 은유거울, A3 장단점/장점 캐릭터 카드, A4 학급 그림책 쪽 틀, A5 여섯 조각 이야기, A6 이야기 구상 카드, A7 8/16/32컷 썸네일·스토리보드, A8 재료 실험 기록, A9 작가의 말·추천의 말, A10 작가 인터뷰, A11 감상 시, A12 그림책 계획서.

편집 조건:
- A4 세로, 흑백 인쇄로도 구분되는 굵은 선/큰 칸/충분한 필기 공간
- 3~4학년용 쉬운 문장, 필요한 곳은 낱말·그림으로 답할 수 있게 함
- 이름·학교·가정사 입력을 요구하지 말 것. 이름 칸이 꼭 필요하면 선택 기입으로 표시.
- 민감한 자기표현은 “상상 인물/가상 상황으로 해도 괜찮아요”, “말하고 싶지 않으면 건너뛰어도 돼요” 문구를 넣음.
- 원작 그림책의 이미지·캐릭터·본문을 복제하지 말고, 비어 있는 프레임과 직접 제작한 단순 아이콘만 사용.
- 표지는 간단하게 하고, 각 페이지 하단에 활동지 번호와 사용 차시를 표시.

산출물은 편집 가능한 원본(가능한 형식)과 PDF, 사용 폰트/아이콘 라이선스 목록입니다. 학생이 실제로 답할 칸은 빈 상태로 둬 주세요.
```

## 3. 완전히 새로 만든 그림 예시 이미지 세트

```text
초등학생에게 그림책 창작 기법을 설명하는 교사용 수업 자료에 쓸 완전히 독창적인 예시 그림 8장을 제작해 주세요. 가로형 16:9, 글자 없이, 인쇄/슬라이드용 고해상도 PNG로 주세요.

장면 주제:
1~4. 같은 가상의 종이배 장면을 네 가지 방식으로 표현: 수수께끼(가려진 모양), 당연한 생각 뒤집기(종이배가 길을 안내), 반복되는 도전(구겨져도 다시 접기), 새 이야기 구조 참고(인물·배경·사건은 독창적).
5~8. 같은 가상 장면을 서로 다른 재료감으로 표현: 색연필, 찢은 종이 콜라주, 점·선만, 두 가지 색만 사용.

제한:
- 기존 그림책, 작가, 애니메이션, 영화의 등장인물·구도·그림체를 모방하지 마세요.
- 그림책 페이지, 표지, 로고, 서명, 글자를 포함하지 마세요.
- 특정 어린이의 실제 사진·얼굴을 사용하지 마세요. 단순한 가상 사물/동물/추상 캐릭터만 그려 주세요.
- 각 이미지에 번호를 붙인 별도 파일과 함께 제작 의도·사용 허용 조건을 텍스트로 제공해 주세요.
```

## 4. LLM 결과를 받은 뒤 확인할 것

- 12차시 구성과 시간, ClassTool 활동 유형이 설계안과 맞는지
- 슬라이드의 질문이 한 번에 하나씩이고 짧은지
- 응답 공개 강요, 개인 신상 질문, 치료·진단 표현이 없는지
- 기존 그림책 그림/표지나 허가 불명확한 폰트·아이콘이 없는지
- PPTX/활동지 파일이 열리고, 한글 글꼴 대체/인쇄 여백이 무너지지 않는지
- 화면 자료에 학생 작품을 추가할 때 학생·보호자 동의와 학교 공개 규칙을 확인했는지
