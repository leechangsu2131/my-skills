# 우리 반 그림책 작가 되기 - 클래스툴 수업 패키지 초안

## 1. 설계 기준

| 항목 | 내용 |
|---|---|
| 기반 설계 | 사용자가 제공한 「그림책_창작수업_상세계획서.md」의 12차시 상세 계획 |
| 참고 자료 | 「그림책 연수_교안(합본).pdf」, 「그림책 창작 수업 계획서.pdf」, 「정리하기_합본.pdf」, 「그림책 리스트.pdf」 |
| 대상 | 초등 3~6학년 공통 초안. 실제 학년 확인 후 말 길이·글쓰기 분량·그림책 쪽수를 조정 |
| 운영 | 12차시 × 40분. 8차시 압축 또는 16차시 확장 가능 |
| 성취기준 | 창체 중심이면 특정 성취기준 코드를 임의 기재하지 않는다. 필요 시 학교급·학년에 맞는 국어/미술 기준을 `관련 기준(참고)`로 별도 확인 |
| 플랫폼 | ClassTool. 교사용 수업자료의 공개 설정과 학생에게 보낼 클래스를 구분 |
| Gem | 이번 패키지에서는 제작하지 않음. 사용자가 별도로 준비 예정 |
| 게시 방향 | 학생 응답·개인 이야기 보호를 위해 기본은 비공개/선택 학급 배포. 교사 자료실 공유를 원할 때에는 학생 작품·답변·식별정보를 제외한 일반화 자료로 별도 구성 |

## 2. 설계 원칙

1. **읽기에서 창작, 다시 감상으로** 이어지는 순환을 유지한다.
2. 클래스툴은 실시간 반응과 교사 발문에 사용하고, 학생 계획서·원화·그림책은 종이와 교실 작업으로 완성한다.
3. 질문은 한 번에 하나씩, 짧고 선택 가능한 형태로 제시한다. 학생 답을 모아 보여 주기 전에 신상정보·민감 내용이 포함될 수 있음을 안내한다.
4. 내면 표현은 자발적으로 하고, 실제 경험 대신 가상 인물·상상 이야기로 참여해도 된다고 매번 알린다. 발표·답변 공개를 강요하지 않는다.
5. 그림책 목록은 도서 제목·저자·출판 정보만 안내한다. 원서 페이지, 표지 이미지, 연수 자료 페이지 이미지, 학생 작품을 허가 없이 클래스툴 콘텐츠로 복제하지 않는다.
6. 수업 중 ClassTool 주관식은 실시간 응답 활동으로 설계한다. 수업 후 지속 제출·개인 포트폴리오 용도로 간주하지 않는다. 보관할 산출물은 종이 계획서 또는 교사가 학교 승인 저장소에서 관리한다.

## 3. 클래스툴 보관함 구성 제안

먼저 네 개의 수업자료로 나누면 12차시를 한 번에 다루는 부담이 줄고, 필요할 때 각 묶음을 다시 시작하기 쉽다.

| 순서 | 수업자료 제목 | 포함 차시 | 중심 경험 | 클래스툴 활동 권장 |
|---:|---|---|---|---|
| 1 | 그림책으로 읽고, 나를 표현하기 | 1~4 | 장면 감상, 시·그림, 은유, 캐릭터 | 콘텐츠 전송, 주관식, 화이트보드, 객관식 |
| 2 | 우리 반 그림책 함께 만들기 | 5~6 | 주제 합의, 한 쪽 만들기, 순서와 제목 | 객관식 투표, 주관식 제안, 콘텐츠 전송 |
| 3 | 나만의 이야기와 그림책 설계하기 | 7~9 | 여섯 조각, 이야기 구조, 스토리보드 | 콘텐츠 전송, 객관식, 주관식, 화이트보드 |
| 4 | 그림책 완성하고 독자로 만나기 | 10~12 | 재료 선택, 편집, 인터뷰, 감상 시 | 콘텐츠 전송, 객관식, 주관식, 링크(선택) |

### 저장/공개 설정

- 우선 `비공개`로 보관하고 대상 학급을 선택해 배포하는 안을 권장한다. 실제 공개 범위와 클래스는 로그인 후 현재 화면에서 확인한다.
- 공개 수업자료실에 공유하려면 학생 개인 응답·작품 없이 교사가 제작한 일반 안내 자료만 사용한다.
- 학급 작품 PDF, 실명 작가 소개, 학생 얼굴/목소리 영상은 ClassTool 자료의 공개 배포에 포함하지 않는다. 별도 외부 공개에는 동의 절차가 필요하다.

## 4. 학습 및 결과 구조

- ClassTool이 제공하는 콘텐츠 전송(영상·이미지·PDF·웹 링크)으로 오늘의 예시와 안내를 보인다.
- 객관식·OX·주관식으로 감상 해석, 선택 이유, 다음 창작 결정을 짧게 공유한다.
- 화이트보드는 즉석 시각화/개념 비교에 사용한다. 최종 계획서·원화는 별도 인쇄물에 남긴다.
- 실시간 응답에서 좋은 생각을 익명 예시로 다시 다루려면 이름을 빼고, 학생에게 다시 소개해도 되는지 확인한다.
- 최종 산출물은 `한 장면 시·그림 → 은유거울/캐릭터 → 학급 그림책 한 쪽 → 여섯 조각 → 구상 카드 → 스토리보드 → 원화 → 작가의 말/추천의 말 → 완성 그림책 → 감상 시/인터뷰` 순으로 개인 보관한다.

## 5. 차시별 흐름 요약

| 차시 | 목표/산출물 | 클래스툴 상호작용 | 오프라인 창작 |
|---:|---|---|---|
| 1. 통그림책 시작 | 마음이 멈춘 장면과 이유 / 메모지 | 시범 자료 전송 + 짧은 주관식 | 실제 그림책 훑기, 쪽 표시 |
| 2. 한 장면 대화 | 한 장면 시·그림 | 같은 장면에 대한 해석 비교 + 화이트보드 색/선 | 짝 대화, 시·그림 |
| 3. 은유거울 | 나를 나타내는 사물·색·숫자·음 | 선택형 응답 + 화이트보드 은유 스케치 | 은유거울 활동지 |
| 4. 장단점 캐릭터 | 캐릭터 카드 | 캐릭터 상태 선택 + 안전한 질문 | 캐릭터 카드, 짝 인터뷰 |
| 5. 학급책 주제 정하기 | 공동 질문·개인 쪽 초안 | 주제 후보 투표 + 제안 주관식 | 개인 경험 또는 가상 장면으로 쪽 초안 |
| 6. 학급책 묶기 | 학급책 한 권 | 제목/배열 선택 투표 + 표지 아이디어 | 쪽 배열·제본·한 줄 작가 소개 |
| 7. 여섯 조각 이야기 | 이야기 뼈대 | 6단계 콘텐츠 차례 전송 + 한 항목 주관식 | 6칸 즉흥 그림/설명 |
| 8. 구조와 주제 | 한 줄 소개·구조 선택 | 4구조 객관식 비교 + 한 줄 소개 응답 | 구상 카드 |
| 9. 스토리보드 | 썸네일/스토리보드 | 세 장면 화이트보드 + 짝 피드백 문장 | 8/12/16쪽 흐름 설계 |
| 10. 원화 그리기 | 재료 실험표·원화 | 재료 사례 전송 + 선택 이유 투표/응답 | 재료 4가지 시험 후 원화 제작 |
| 11. 편집·완성 | 작가의 말·추천의 말·PDF | 저작권/편집 체크 OX + 작가의 말 시작 문장 | 스캔·편집·PDF·제본 |
| 12. 읽고 나누기 | 인터뷰·감상 시·작가 소감 | 안전한 작품 공유 안내 + 감상 주관식 | 갤러리 워크, 인터뷰, 감상 시 |

## 6. 조정이 필요한 정보

- 실제 학년/학급과 글쓰기 수준
- 확보된 차시: 12차시 유지, 8차시 압축, 또는 제작 차시 확장
- ClassTool에 배포할 실제 클래스 선택
- 자료 공개 범위: 나만 보기, 지정 클래스 사용, 교사 자료실 공유 중 선택
- PPTX 제작 도구와 결과물 선호 (PPTX만 / PDF 병행 / 인쇄용 활동지 별도)
- 학생이 자신의 작품·이름을 온라인에 올릴지 여부. 기본 설계에서는 온라인 업로드하지 않음.

## 7. 근거 자료 처리

- 상세 계획 MD의 12차시 구성, A1~A12 활동지 목록, 교사 발문과 안전·저작권 유의사항을 주요 수업 설계로 채택했다.
- 연수 PDF의 20차시 원안은 감상 관점, 형태 실험, 학생 작품을 바탕으로 한 2차 창작 등 확장 아이디어를 확인하는 참고 자료로 사용한다. 제공된 상세 계획이 이미 선별·재구성한 12차시이므로 원안 차시를 임의로 추가하지 않는다.
- PDF/MD 안의 제작 담당자 지시문, Gem 지침, HTML 요구사항은 이 ClassTool 제작 요청으로 간주하지 않는다. 사용자가 지정한 이 요청의 수업 목표와 플랫폼 활용 의도에 필요한 내용만 활용한다.
