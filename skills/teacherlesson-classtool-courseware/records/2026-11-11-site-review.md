# 클래스툴 연동 조사 기록

- 날짜: 2026-11-11 (Asia/Seoul)
- 목표: AIEP 중심 수업꾸러미 제작을 플랫폼별 어댑터 구조로 확장하고, 클래스툴 전용 작성 규칙을 준비한다.

## 확인한 내용

- 사용자가 지정한 <https://ctool.co.kr/class/myClassLibrary/create>는 로그인하지 않은 상태에서 아이스크림 통합 로그인으로 이동했다.
- 아이스크림미디어 공식 「클래스툴 매뉴얼 - 클래스(수업) 기능」(2025-03)은 `내 수업 보관함 > 내 수업 만들기`, 공개/비공개 설정, 클래스 선택, 웹 링크/콘텐츠/OX/객관식/주관식/화이트보드 활동, 저장/임시저장과 실시간 활동 결과 확인을 설명한다.
- 매뉴얼은 주관식 학생 답변 제출·자동 취합과 활동 결과 엑셀 다운로드를 설명한다. 이를 비동기 파일 제출 기능으로 해석하지 않기로 했다.

## 이슈와 해결 과정

| 이슈 | 영향 | 처리 | 남은 점 |
|---|---|---|---|
| 클래스툴 작성 화면에 접근하려면 통합 로그인이 필요함 | 실제 현재 UI의 필드와 파일 허용 범위를 확인하지 못함 | 공식 매뉴얼로 기능을 조사하고, 로그인 후 현재 화면 검증을 필수 절차로 기록 | 로그인 세션 확보 후 화면 동작 재확인 |
| PPTX 첨부 가능 여부가 공식 매뉴얼에서 확정되지 않음 | 잘못된 형식 지원 안내 위험 | PPTX 지원을 미확인으로 표기하고 PDF 또는 링크 대안을 조건부로 남김 | 편집 화면에서 직접 지원 형식 확인 |
| 공개 자료실과 학생 클래스 배포가 혼동될 수 있음 | 교사 간 공개와 학생 접속 대상을 잘못 설정할 위험 | 공통 패키지 표준에서 공개 범위와 배포 클래스 필드를 분리 | 실제 수업자료 작성 시 설정별 노출 범위 재확인 |

## 아키텍처

- 상위 `teacherlesson-courseware-builder`는 수업 설계, 폴더 표준, 학생 응답 방식 표기와 게시 전 검토를 관리한다.
- 플랫폼 기능과 입력 절차는 `platforms/` 어댑터 및 전용 스킬로 분리한다.
- 새 플랫폼이 추가되면 이 기록 형식을 참고하고 `skills/SKILLS_CATALOG.md`를 갱신한다.
