# ClassTool 기능 및 확인 상태

## 대상

- 작성 화면 URL: <https://ctool.co.kr/class/myClassLibrary/create>
- 공식 교사용 매뉴얼: [클래스툴 매뉴얼 - 클래스(수업) 기능, 2025년 3월](https://cdn.ctool.kr/doc/classtool_manual_20250321.pdf)
- 확인일: 2026-11-11

## 공식 매뉴얼에 기재된 작성 흐름

1. `내 수업 보관함 > 내 수업 만들기`에서 수업 자료를 작성한다.
2. 제목, 공개/비공개, 비공개 자료의 비밀번호 사용 여부, 학교급/학년/학기/교과/차시 등의 수업 정보를 설정한다.
3. 해당 수업자료를 보낼 교사 클래스(복수 선택 가능)를 선택한다.
4. 웹 링크, 콘텐츠 전송, OX, 객관식, 주관식, 화이트보드 등의 활동을 추가하고 순서를 설계한다.
5. `수업 저장`은 `내 수업 자료`에, `임시 저장`은 `임시보관함`에 둔다.
6. 공개 수업자료는 수업 자료실에서 교사 간 공유될 수 있다. 학생에게 보내는 클래스 선택/접속 절차와 별도다.

## 수업 중 학생 응답

- 공식 매뉴얼은 OX·객관식·주관식의 학생 답변을 수업 중 자동으로 취합하는 흐름을 설명한다.
- 주관식은 학생이 답변을 제출하고 교사가 답변을 모아 확인할 수 있다. 활동 결과 관리 메뉴에서 활동 기록을 확인하고 엑셀로 내려받는 기능도 기술되어 있다.
- 이 자료는 실시간 상호작용 흐름에 대한 근거다. 비동기 제출, 장기 보관, 개별 학생의 지속 포트폴리오 제출 기능은 확인하지 않았다.

## 콘텐츠 형식

- 매뉴얼은 콘텐츠 전송에 이미지·동영상·PDF 및 웹 링크를 설명한다. 이미지 직접 업로드와 PDF 전송에 관한 형식/용량 예시는 2025년 문서 내용이므로 현재 화면 안내를 우선한다.
- PPTX 직접 첨부는 해당 매뉴얼 텍스트에서 확인되지 않았다. 최신 편집 화면에서 허용 형식을 확인하고, 지원하지 않으면 PDF나 승인된 링크를 검토한다.
- 매뉴얼에 없는 기능이나 제한을 임의로 추가하지 않는다.

## 현재 화면 확인 상태

- 2026-11-11 지정 작성 URL에 접속했을 때 `oauth2.i-screammedia.com/login` 통합 로그인 화면으로 이동했다.
- 통합 로그인 전에는 클래스툴 작성 UI를 직접 확인하지 않았다. 로그인 후 실제 사이트 작업을 요청받으면 생성 화면의 현재 필드, 파일 형식, 공개 옵션, 학생 응답 결과 기능을 다시 확인한다.
- 아이디·비밀번호, 계정 소유자 정보는 기능 기록에 저장하지 않는다.
