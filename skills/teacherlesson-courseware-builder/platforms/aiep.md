# AIEP Courseware 어댑터

경북 AIEP 수업꾸러미는 성취기준·콘텐츠·파일/링크를 차시 행에 배치해 학습자가 보는 꾸러미를 구성한다. 현재 화면에서 보이는 편집 흐름과 상세 점검 규칙은 [AIEP 전용 스킬](../../teacherlesson-aiep-courseware/SKILL.md), 기능 근거는 [AIEP 사이트 기능 기록](../../teacherlesson-aiep-courseware/references/site-capabilities.md)을 따른다.

## 공통 표준에 매핑

- 차시/단원: AIEP 캔버스 행
- 목표/성취기준: 좌측 성취기준 패널. 창체 등 기준이 명확하지 않으면 참고 기준임을 표시한다.
- 학습 자료: LCMS 콘텐츠 또는 파일/링크를 차시 콘텐츠 칸에 배치한다.
- 응답 방식: 학습자 미리보기에서 문서·영상 열람 흐름은 확인할 수 있다. 주관식 입력·지속 제출은 확인되지 않았으므로 기본값을 `자료 열람`으로 둔다.
- 공개 설정: 꾸러미 공개 범위. 사용자가 정한 의도를 확인하고, 전체공개를 기본값으로 두지 않는다.

## 운영 시 주의

- 파일함에 업로드한 자료와 차시 콘텐츠 칸에 배치한 자료는 별도 단계다. 파일함에만 올린 상태를 완성으로 간주하지 않는다.
- 파일 업로드 형식은 현재 화면의 허용 목록을 확인한다. 제목, 설명, 과목, 구매 여부, 저작권 유형도 정확하게 입력한다.
- 최종 등록 전 목차/플레이어 미리보기에서 자료 열기와 순서를 확인한다.
