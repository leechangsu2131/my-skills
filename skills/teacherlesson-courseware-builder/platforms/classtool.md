# ClassTool 어댑터

클래스툴은 교사가 만든 수업자료를 클래스에 연결하고, 실시간 수업 중 링크·콘텐츠·질문 활동을 보내 학생 응답을 받는 상호작용 도구다. 사용자가 지정한 작성 주소는 <https://ctool.co.kr/class/myClassLibrary/create>다.

## 공통 표준에 매핑

- 차시/주제와 공개 범위: 내 수업 보관함의 수업자료 제목, 학교급/학년/학기/교과/차시, 공개·비공개 설정
- 학생 배포: 수업자료를 보낼 교사 클래스 선택. 클래스 접속 코드/QR은 수업자료 공개 설정과 별개다.
- 활동 순서: 웹 링크, 콘텐츠 전송, OX, 객관식, 주관식, 화이트보드 등의 활동을 추가해 순서를 구성한다.
- 응답 방식: 매뉴얼에는 실시간 주관식 답변 제출·자동 취합과 활동 결과 확인/엑셀 다운로드가 설명되어 있다. 이를 비동기 과제 제출이나 학생별 장기 저장으로 해석하지 않는다.
- 저장: 수업 저장은 내 수업 자료에 보관하고, 임시 저장은 임시보관함에 둔다. 공개 수업자료는 수업 자료실에서 교사 간 공유되는 흐름으로, 학생 클래스 접속과 구분한다.

## 자료 형식

2025년 3월 공식 매뉴얼은 콘텐츠 전송 항목에서 이미지, 동영상, PDF, 웹 링크를 설명한다. PPTX 직접 첨부 여부는 해당 매뉴얼에서 확인하지 못했으므로 최신 작성 화면에서 허용 여부를 확인한다. 화면에서 지원이 확인되지 않으면 PDF 변환 또는 교사가 승인한 웹 링크를 대안으로 제시한다. 형식과 용량은 매뉴얼보다 현재 화면의 안내를 우선한다.

## 출처와 확인 상태

- 근거: [클래스툴 클래스(수업) 기능 매뉴얼 (2025-03)](https://cdn.ctool.kr/doc/classtool_manual_20250321.pdf)
- 현재 페이지 확인: 2026-11-11, 작성 주소가 아이스크림 통합 로그인으로 이동했다. 로그인 후 편집 화면은 확인하지 않았다. 실제 사이트 조작 전에 로그인 상태와 현재 필드를 다시 확인한다.
- 자세한 작업 순서와 상호작용 결과 처리는 [클래스툴 전용 스킬](../../teacherlesson-classtool-courseware/SKILL.md)을 따른다.
