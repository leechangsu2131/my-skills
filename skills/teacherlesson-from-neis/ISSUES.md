## 🔵 진행 중

### ISSUE-003: 선택 접수·상신과 중복 창 방지 (2026-11-19)
- **상태**: 🔵 진행 중
- **증상**: 사용자가 처리 도중 비슷한 NEIS 창이 여러 개 열리고 접수가 반복될 수 있다고 보고했다. 중복 실행이 실제 대량 접수의 원인인지는 아직 확인되지 않았다.
- **확인**: 현재 목록에는 대상 두 건이 `접수 · 미상신`, `질병결석`으로 보인다. 신청 내용은 기존에 확인한 내용과 일치한다. 상세/결재 창은 0개이고 목록은 하나다. 결석신고 유형 결재선은 저장되어 있다. 직전 처리 오류 `승인요청 대상 선택을 확인하지 못해 상신하지 않았습니다`는 결재선 화면 전에 발생했으므로 저장 결재선 문제는 아니다.
- **원인**: 기존 코드는 그리드 DOM 체크박스를 클릭한 직후 데이터셋의 `chk` 값으로 선택 여부를 즉시 확인했다. NEIS가 DOM 선택을 데이터셋에 반영하지 못해 선택 검증이 실패했고 승인요청 버튼을 누르지 않았다.
- **조치**: v1.5.0에는 처리대상 미선택, 전체 선택/해제, 질병결석 기본값, 결석 구분 일괄 적용, 신청 검토와 단일 실행, 중복 창/실행 방지가 들어갔다. v1.5.2에서는 NEIS 그리드 `setCheckRowIndex()` / `getCheckRowIndices()`로 행을 선택·검증한다. 접수대기 행에 NEIS `txaShlOpiCn` 교사 사유 입력란을 연결하고, 바뀐 내용은 결석 구분 및 접수 상태와 함께 저장한 뒤 저장 결재선으로 상신한다. 입력 내용은 Chrome 저장소나 처리 로그에 저장하지 않는다.
- **다음 단계**: 확장 프로그램에 v1.5.2를 적용한 뒤 처리 버튼 실행은 사용자가 선택한 대상과 내용을 다시 확인하고 진행한다. 이번 작업 중에는 승인요청하지 않았다.
- **관련 파일**: `extension/absence-workflow.js`, `extension/popup.js`, `docs/student-status.md`, `../admin-neis-bot/SKILL.md`

### ISSUE-004: 확장 재로드 후 무효화된 콘텐츠 스크립트 (2026-11-19)
- **상태**: 🔵 진행 중
- **증상**: Chrome에서 `Uncaught Error: Extension context invalidated`가 플로팅 패널의 뷰어 열기 클릭에서 발생했다.
- **원인**: 확장을 다시 불러왔지만 기존 NEIS 탭의 콘텐츠 스크립트가 이전 확장 컨텍스트로 남아 저장소/메시지 API를 호출했다.
- **조치**: v1.5.0에서 확장 API 호출 오류를 잡고, 저장되지 않은 NEIS 입력 내용을 저장한 뒤 탭을 새로고침하라는 안내를 표시한다.
- **다음 단계**: 확장 새로고침 후 NEIS 탭 재로드 때 오류가 재발하지 않는지 확인한다.
- **관련 파일**: `extension/content.js`, `README.md`

## 🟢 해결됨

### ISSUE-001: 결석신고 유형별 결재선 (2026-11-19)
- **상태**: 🟢 해결 (2026-11-19)
- **증상**: 결석신고 신청 유형마다 승인요청 결재선이 다르므로 고정 결재선으로는 맞는 선을 적용할 수 없음.
- **원인**: 기존 팝업은 수동 입력란 한 개만 제공하고 유형별 저장·분기 기능이 없었음.
- **해결/조치**: NEIS 목록 신청 유형별 결재선을 `chrome.storage.local`에 저장하고, 선택 건을 유형별 묶음으로 나눠 확인·상신하도록 확장. 유형 설정 누락이나 NEIS 지정 결재선 불일치 시 상신을 중단함. Chrome 9222에서 확장 v1.4.1 활성화를 확인했으며, 실제 NEIS 접수·상신은 실행하지 않음.
- **관련 파일**: `extension/popup.js`, `extension/background.js`, `extension/absence-workflow.js`, `docs/student-status.md`, `README.md`

### ISSUE-002: 숨은 MDI 목록에서 상세 화면을 열지 못함 (2026-11-19)
- **상태**: 🟢 해결 (2026-11-19)
- **증상**: 처리 작업이 `선택한 결석신고서 상세 화면을 열지 못했습니다.`로 중단됨.
- **원인**: 결석신고서 목록 앱 인스턴스는 이미 열려 있었지만 다른 MDI 탭 뒤에 숨겨져 있었고, 기존 흐름은 앱 인스턴스가 있으면 활성화하지 않고 즉시 반환함. 숨은 앱의 그리드 DOM 크기가 0이라 이름 셀을 찾지 못함.
- **해결/조치**: 처리 시작 전 그리드가 표시되는지 확인하고, 숨겨져 있으면 NEIS 메뉴 API로 목록 MDI를 활성화한 뒤 진행함. 오류 당시 저장된 결과는 접수 0건·승인요청 0건으로 신청 기록 변경은 없었음.
- **관련 파일**: `extension/absence-workflow.js`, `extension/manifest.json`
