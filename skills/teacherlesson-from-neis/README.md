# NEIS 오늘의 수업 뷰어

NEIS의 `주간학습안내작성` 화면에서 조회한 수업 내용을 날짜와 교시별로 읽어 NEIS 화면 왼쪽 아래 플로팅 패널과 별도 로컬 뷰어에 표시합니다. 기존 `teacherlesson-schedule` 및 Google Sheets 데이터는 수정하지 않습니다.

## 사용 방법

1. `실행_나이스수업뷰어.bat`을 실행합니다. 뷰어 주소는 `http://127.0.0.1:5101`입니다.
2. Chrome에서 NEIS에 로그인하고 `교육과정 > 주간학습안내작성` 화면을 엽니다.
3. NEIS 화면에서 정상적으로 한 번 조회하면 화면의 `dsWeekList`에 등록된 주차를 읽고 현재 주 외의 주도 자동으로 순차 조회합니다. 확장 팝업에서 주마다 가져오기를 누를 필요가 없습니다.
4. NEIS 화면의 왼쪽 아래 플로팅 패널에서 오늘 수업을 확인하거나 로컬 뷰어에서 날짜/주/월을 확인합니다.

첫 설치는 `chrome://extensions`에서 개발자 모드를 켠 다음 **압축해제된 확장 프로그램을 로드**를 선택하고 `extension` 폴더를 지정합니다. 코드를 바꾼 뒤에는 확장 관리 화면에서 새로고침을 누르고 NEIS 탭도 다시 불러와야 변경된 코드가 적용됩니다.

## 조회 범위

- **최초 주차 동기화**: 정상 조회 뒤 현재 주를 먼저 저장하고, NEIS의 `dsWeekList`에 있는 아직 캐시에 없거나 12시간이 지난 주를 차례로 조회합니다. 완료되면 원래 보던 주로 돌아옵니다.
- **이후 자동 갱신**: NEIS에서 다시 조회하면 그 주의 자료를 즉시 갱신합니다. 다른 주는 12시간 캐시가 만료된 뒤 자동으로 다시 조회됩니다.
- **현재 주 가져오기**: 확장 팝업에서 수동으로 다시 동기화할 때 사용합니다.
- **선택한 달 가져오기**: `dsWeekList`에 있는 주차를 대상으로 바로 확인하고 싶은 달을 조회합니다. 완료 후 원래 표시하던 주차로 복원합니다.

`dsWikLrn`에 저장되지 않은 수업내용 변경이 있으면 자동/수동 동기화를 건너뜁니다. 다른 NEIS 데이터셋의 수정 표시는 수업내용 동기화를 막지 않습니다. 주차 목록이 40주를 넘거나 NEIS 조회 구조를 찾지 못하면 자동 주차 조회를 시작하지 않고 팝업의 월간 가져오기를 사용할 수 있습니다. NEIS가 현재 화면에 제공하지 않는 과거 주차는 먼저 해당 기간이 포함된 주차 목록을 불러와야 합니다. 내부 조회 중에도 NEIS에는 저장·수정 요청을 보내지 않습니다.

## 운영 특성

- Chrome 확장 프로그램은 NEIS 화면의 정상 주간 조회가 끝날 때 자동으로 동작합니다. 그 뒤의 주차별 읽기 요청은 같은 로그인 세션 안에서 수행합니다.
- 자료 전송 대상은 같은 PC의 `127.0.0.1:5101`입니다.
- 정규 수업자료는 Chrome의 `storage.local`에 이 PC 전용으로 저장하고, 로컬 서버 메모리에도 전달합니다. 서버를 다시 시작해도 NEIS 화면의 플로팅 패널은 로컬 저장 자료를 표시합니다.
- 자동 갱신과 캐시 조건은 `docs/auto-sync.md`, 정규 레코드 필드와 원본 NEIS 컬럼은 `docs/data-contract.md`를 참고하세요.

## 요구 사항

- Windows, Chrome, NEIS 로그인 세션
- Python 3 및 `requirements.txt`의 Flask

```powershell
python -m pip install -r requirements.txt
```
