# NEIS 오늘의 수업 뷰어

NEIS의 `주간학습안내작성` 화면에서 조회한 수업 내용을 날짜와 교시별로 읽어 NEIS 화면 오른쪽 아래 플로팅 패널과 Chrome 확장 프로그램 안의 뷰어에 표시합니다. 플로팅 패널 제목을 끌어 위치를 옮길 수 있습니다. 기존 `teacherlesson-schedule` 및 Google Sheets 데이터는 수정하지 않습니다.

## 사용 방법

1. `extension` 폴더를 Chrome 확장 프로그램으로 설치합니다. 최초 설치 때만 필요합니다.
2. Chrome에서 NEIS에 로그인하고 `교육과정 > 주간학습안내작성` 화면을 엽니다.
3. NEIS 화면에서 정상적으로 한 번 조회하면 화면의 `dsWeekList`에 등록된 주차를 읽고 현재 주 외의 주도 자동으로 순차 조회합니다. 확장 팝업에서 주마다 가져오기를 누를 필요가 없습니다.
4. NEIS 화면 오른쪽 아래 플로팅 패널에서 오늘 수업을 확인하거나 확장 프로그램 메뉴의 **오늘의 수업 뷰어 열기**에서 날짜/주/월을 확인합니다.

학생 출결과 신청 현황은 확장 팝업에서 **오늘 출결·결석·체험학습 현황 조회**를 눌러 조회합니다. 조회가 끝나면 플로팅 패널이 **학생 현황** 탭으로 전환되어 오늘 출결과 마지막 조회에서 가져온 신청 목록 전체를 보여줍니다. 세 화면 중 일부가 열리지 않아도 성공한 결과는 저장되고, 실패한 구역은 이전 자료를 보존해 갱신 실패로 표시합니다. 오늘 출결은 하루, 결석 신고서는 이번 달, 체험학습 신청서는 NEIS 화면의 기본 조회조건으로 검색합니다.

결석신고서를 처리할 때는 **신청 유형별 결재선 저장·관리**에서 NEIS 신청 유형별 결재자 이름과 순서를 Chrome 로컬에 저장합니다. **결석신고 접수·상신 대상 확인**으로 목록을 새로 조회하면 학생·날짜·신청 사유와 결석 구분을 확인할 수 있습니다. 필요하면 접수대기 행에 담임/교사 결석 사유를 추가합니다. 이 입력은 NEIS의 `결석사유(담임 및 교사)` 칸에 접수와 함께 저장되며 로컬에 보관하지 않습니다. **선택 건 접수 · 결재 상신**을 누르면 접수대기 건은 내용·구분 저장 및 접수 후 저장 결재선으로 승인요청합니다. 이미 접수된 미상신 건은 수정 없이 승인요청만 합니다. v1.5.2에서는 NEIS 그리드 API로 선택 행과 신청 ID를 검증하고, v1.5.3에서는 기안자 행을 결재자와 구분해 보존하도록 바꿨습니다. v1.5.4에서는 결재자 지정 창을 앱 ID뿐 아니라 실제 결재자 그리드가 화면에 열린 상태로 확인합니다. 결재자 창을 확인하지 못했거나 중복 창이 있으면 상신하지 않습니다. 현재 자동 접수·상신은 결석신고서만 지원하며 체험학습 신청서는 조회 전용입니다. 최종 결재는 자동으로 하지 않습니다. 신청 ID와 내용 입력은 현재 팝업 메모리에서만 처리하며 Chrome 저장소에는 기록하지 않습니다.

전체 뷰어는 확장 프로그램 내부 페이지로 열립니다. 별도의 Python 서버를 시작할 필요가 없고, 저장된 수업자료는 Chrome을 닫았다 다시 열어도 유지됩니다.

`server.py`, `web/`, `실행_나이스수업뷰어.bat`은 이전 확장 버전과의 호환을 위해 남겨 둔 파일입니다. 새 확장 버전은 이 파일들을 사용하지 않습니다.

## 뷰어 보기 방식

- **하루**: 교시 순서대로 과목, 단원, 학습내용과 교과서 쪽을 자세히 봅니다.
- **주간**: 월요일부터 금요일까지 날짜별 칸으로 나눠 한 주의 수업과 빈 날을 함께 봅니다. 이전/다음 주 화살표와 기준 날짜로 이동할 수 있습니다.
- **월간**: 월요일 시작 달력에서 날짜별 수업 수와 과목·학습내용 요약을 봅니다. `하루 칸 높이` 조절 막대로 한 번에 더 많은 수업을 표시하고, `+N개 수업`을 눌러 특정 날짜의 수업을 모두 펼칠 수 있습니다. 토·일은 선택해서 숨기거나 다시 표시할 수 있으며, 날짜를 누르면 하루 상세 보기로 이동합니다.
- **학생 현황**: 선택 날짜의 출결과 마지막 조회에서 가져온 결석신고/체험학습 신청 결과 전체를 봅니다. 신청 기간과 처리·결재 상태도 표시합니다.

날짜 선택은 하루·주간·월간 보기의 기준 날짜로 사용됩니다. 월간 보기의 주말 표시와 칸 높이 설정은 이 브라우저에 저장됩니다. 작은 화면의 주간 보드는 날짜별로 쌓이고, 월간 달력은 가로로 이동해 날짜 칸을 읽을 수 있습니다.

첫 설치는 `chrome://extensions`에서 개발자 모드를 켠 다음 **압축해제된 확장 프로그램을 로드**를 선택하고 `extension` 폴더를 지정합니다. 코드를 바꾼 뒤에는 확장 관리 화면에서 새로고침을 누르고 NEIS 탭도 다시 불러와야 변경된 코드가 적용됩니다. 확장 재로드 직후 기존 NEIS 탭에 `Extension context invalidated`가 표시되면 저장되지 않은 NEIS 입력 내용을 먼저 저장하고 탭을 새로고침합니다. 처리 버튼을 누른 뒤에는 완료 상태를 확인할 때까지 확장 팝업을 다시 실행하지 않습니다. 기존 버전에서 `실행_나이스수업뷰어.bat`을 사용했다면 새 버전에서는 실행할 필요가 없습니다.

## 조회 범위

- **최초 주차 동기화**: 정상 조회 뒤 현재 주를 먼저 저장하고, NEIS의 `dsWeekList`에 있는 아직 캐시에 없거나 12시간이 지난 주를 차례로 조회합니다. 완료되면 원래 보던 주로 돌아옵니다.
- **이후 자동 갱신**: NEIS에서 다시 조회하면 그 주의 자료를 즉시 갱신합니다. 다른 주는 12시간 캐시가 만료된 뒤 자동으로 다시 조회됩니다.
- **현재 주 가져오기**: 확장 팝업에서 수동으로 다시 동기화할 때 사용합니다.
- **선택한 달 가져오기**: `dsWeekList`에 있는 주차를 대상으로 바로 확인하고 싶은 달을 조회합니다. 완료 후 원래 표시하던 주차로 복원합니다.

`dsWikLrn`에 저장되지 않은 수업내용 변경이 있으면 자동/수동 동기화를 건너뜁니다. 다른 NEIS 데이터셋의 수정 표시는 수업내용 동기화를 막지 않습니다. 주차 목록이 40주를 넘거나 NEIS 조회 구조를 찾지 못하면 자동 주차 조회를 시작하지 않고 팝업의 월간 가져오기를 사용할 수 있습니다. NEIS가 현재 화면에 제공하지 않는 과거 주차는 먼저 해당 기간이 포함된 주차 목록을 불러와야 합니다. 내부 조회 중에도 NEIS에는 저장·수정 요청을 보내지 않습니다.

## 운영 특성

- Chrome 확장 프로그램은 NEIS 화면의 정상 주간 조회가 끝날 때 자동으로 동작합니다. 그 뒤의 주차별 읽기 요청은 같은 로그인 세션 안에서 수행합니다.
- 수업·학생 현황은 Chrome 확장 프로그램의 `storage.local`에 저장하며, 플로팅 패널과 전체 뷰어가 이 자료를 직접 읽습니다. 별도 서버나 외부 전송은 사용하지 않습니다.
- 학생 현황은 이름·학급·날짜/기간·종류·처리/결재 상태만 저장합니다. 신청 사유는 결석신고 처리 대상을 검토할 때 팝업에만 임시로 표시하고 저장하지 않습니다. 상세 내용, 체험 장소, 보호자 연락처와 학생 식별번호는 가져오지 않습니다. 결석신고 접수·승인요청은 사용자가 선택한 건에서 실행 버튼을 눌러야 시작되며 최종 결재는 하지 않습니다. 데이터 구조는 [docs/student-status.md](docs/student-status.md)에 기록합니다.
- 자동 갱신과 캐시 조건은 `docs/auto-sync.md`, 정규 레코드 필드와 원본 NEIS 컬럼은 `docs/data-contract.md`를 참고하세요.

## 요구 사항

- Chrome 및 NEIS 로그인 세션

## 자동 시험

`extension/popup.js` 의 결재선 정리·결재 묶음 만들기·선택 요약 같은 함수는 가짜 화면과 가짜 `chrome` 으로 시험한다. 실제 NEIS·크롬·학생 정보는 쓰지 않는다. 이 폴더에서:

```
node --test tests/popup.test.js
```

NEIS 페이지에 주입되는 함수(`collectOnNeisPage`·`collectStudentStatusOnNeis`·`scanAbsenceWorkQueueOnNeis`, `absence-workflow.js`)는 크롬 주입 구조상 따로 불러올 수 없어 시험 대상이 아니다. 실제 NEIS 에서 접수·상신이 되는지는 교사 PC 에서 직접 확인한다.
