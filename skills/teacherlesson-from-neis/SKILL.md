# Teacher Lesson From NEIS

이 스킬은 Chrome 확장 프로그램이다. NEIS에서 수업·출결·신청 내용을 읽어 와서 화면에 보여 주고, 교사가 고른 결석신고서(와 체험학습 신청서·보고서)를 접수하고 결재를 올려 준다. **최종 결재는 하지 않는다.**

## 무엇을 하나

- 지금 로그인해 둔 Chrome에서 NEIS의 **주간학습안내** 내용을 읽는다.
- 읽은 수업을 두 곳에 보여 준다.
  - NEIS 화면 오른쪽 아래에 떠 있는 작은 창(플로팅 패널). 끌어서 옮길 수 있다.
  - 확장 프로그램 안의 뷰어.
- 학생 현황(출결·결석신고·체험학습)은 확장 팝업에서 **조회**를 눌러야 추가된다.
- 뷰어는 Chrome 안에 저장된 자료(`storage.local`)를 바로 읽는다. 그래서 Python 서버를 따로 켜지 않아도 된다.
- `teacherlesson-schedule`의 "날짜·교시 중심 보드" 모양을 참고했다. 하지만 Google Sheets 진도표나 수업배치 시트는 건드리지 않는다.

`server.py`, `web/`, `실행_나이스수업뷰어.bat`은 예전 확장 버전과 맞추려고 남겨 둔 것이다. 지금 버전을 날마다 쓸 때는 필요 없다.

## 화면에서 볼 수 있는 것

- **전체 뷰어**: 하루 자세히 보기, 월~금 주간 보드, 날짜별 요약이 있는 월간 달력, 학생 현황.
  - 월간 보기에서는 날짜 칸의 높이를 바꿀 수 있다.
  - `+N개 수업`을 누르면 그날의 수업이 모두 펼쳐진다.
  - 토·일을 보이게 하거나 숨길 수 있다.
  - 고른 날짜의 출결과, 미리 조회해 둔 신청 목록을 함께 볼 수 있다.
- **플로팅 패널(오른쪽 아래 작은 창)**: `오늘의 수업` 탭과 `학생 현황` 탭이 있다. 학생 현황을 조회하면 저절로 그 탭으로 바뀐다.
- **학생 현황 탭**: 오늘 출결과, 마지막 조회에서 가져온 결석·체험학습 신청 결과 전체가 나온다.

## 쓰는 순서

1. Chrome 확장 프로그램을 설치하고 켠다.
2. Chrome에서 NEIS에 로그인하고 `교육과정 > 주간학습안내작성` 화면을 연다.
3. 주간학습안내를 한 번 정상적으로 조회한다. 그러면 이번 주와, 주 목록(`dsWeekList`)에 있는 다른 주까지 자동으로 읽어 온다. 그다음부터는 이번 주만 새로 고치고, **12시간이 지난 주만** 다시 가져온다.
4. 수업은 두 가지 방법으로 본다.
   - NEIS 화면 오른쪽 아래의 작은 창을 끌어서 원하는 곳에 놓는다.
   - 확장 프로그램 메뉴에서 **오늘의 수업 뷰어 열기**를 누른다.
5. 학생 출결·신청 목록이 필요하면 확장 팝업에서 **오늘 출결·결석·체험학습 현황 조회**를 누른다.
   - 작은 창의 **학생 현황** 탭에는 오늘 기준 결과가 나온다.
   - 전체 뷰어에서는 날짜를 바꿔 가며 볼 수 있다.
6. 결석신고서의 첨부 파일이 필요하면, 그 결석신고서 아래 **첨부 확인 · 다운로드**를 누른다.
   - 고른 신청의 NEIS 상세 화면을 다시 열고, 첨부 개수와 다운로드 창의 파일 개수가 같은지 확인한다.
   - 개수가 같으면 그 신청의 첨부만 Chrome 다운로드로 보낸다. 파일 내용은 확장 프로그램 저장소에 복사하지 않는다.
   - 상세 창은 눈으로 확인하라고 열어 둔다. 내려받은 뒤에는 NEIS에서 직접 닫고 다음 파일을 확인한다.
   - 상세 창이 이미 열려 있거나 신청 번호(ID)가 달라졌으면 다운로드를 멈춘다.
7. 결석신고서와 체험학습 신청서·보고서를 접수하고 결재를 올리려면(상신) 다음 순서로 한다.
   1. **신청 유형별 결재선 저장·관리**에서, 신청 유형마다 결재자 이름과 순서를 Chrome에 저장해 둔다.
   2. **결석·체험학습 접수·상신 대상 확인**을 눌러 목록을 새로 조회하고, 학생·날짜·신청 내용(결석신고서는 결석 구분도)을 확인한다.
   3. 필요하면 결석신고서의 접수대기 줄마다 **담임/교사 결석 사유**를 더 적는다. 이 글은 접수를 저장할 때 NEIS의 `결석사유(담임 및 교사)` 칸에 들어간다. 내 컴퓨터에는 저장하지 않는다.
   4. 대상 목록 아래의 **선택 건 접수 · 결재 상신**을 한 번 누른다.
      - 고른 접수대기 건은 결석 구분과 보완 사유를 저장하면서 접수한다. 이어서 NEIS 결재자 지정 창에서 본인(기안) 줄은 그대로 두고, 저장해 둔 결재자를 순서대로 지정해 승인요청한다.
      - 이미 접수됐지만 아직 상신하지 않은 건은 내용을 다시 고치지 않고 승인요청만 한다.
      - 다른 결재자가 미리 지정되어 있으면 본인 줄은 지키고 기존 결재자만 바꾼다. 그런 다음 저장해 둔 목록과 똑같은지 확인한다.
      - 같은 목록·상세·결재 창이 여러 개 열려 있으면 처리를 멈춘다.

**월간 가져오기**는 확장 팝업에서 달을 골라 실행한다. 주 목록(`dsWeekList`)에서 그 달과 겹치는 주를 차례로 조회하고, 끝나면 원래 보던 주를 다시 보여 준다. 수업내용(`dsWikLrn`)에 저장하지 않은 수정이 있으면 자동·수동 동기화를 모두 멈춘다. 다른 화면의 수정 표시는 수업내용 조회를 막지 않는다. 새로 고침과 임시 저장(캐시)의 흐름은 [docs/auto-sync.md](docs/auto-sync.md)에 자세히 있다.

## 파일 지도

- `extension/viewer.html`, `extension/viewer.js`, `extension/viewer.css`: Chrome에 저장된 자료를 바로 읽어 하루·주간·월간·학생 현황을 보여 주는 뷰어
- `extension/manifest.json`: Chrome MV3 확장의 권한과 팝업 설정
- `extension/icons/`: 주소창 옆 확장 아이콘과 Chrome 메뉴에 쓰는 색 아이콘
- `extension/neis-reader.js`: NEIS 조회 알아차리기, 등록된 주를 자동으로 조회하기, 수업 데이터 정리
- `extension/content.js`: NEIS 화면의 작은 창(플로팅 패널), 오늘 수업·학생 현황 보여 주기
- `extension/background.js`: 12시간짜리 주별 임시 저장, 학생 현황과 작은 창 위치 저장, 같은 일이 겹쳐 실행되지 않게 잠그기, 결과가 불확실할 때 기록 남기기, NEIS 쪽 처리 넣기
- `extension/popup.js`: 월간 수업 가져오기, 학생 출결·신청 조회, 결석신고 첨부 다운로드(사용자가 누를 때만), 신청 내용 검토·결석 구분 한꺼번에 바꾸기·선택 실행 화면, 신청 유형별 결재선을 Chrome `storage.local`에 저장·관리, 전체 뷰어 열기
- `extension/absence-workflow.js`: NEIS 목록 창이 하나뿐인지 확인, 고른 결석신고서의 상태·내용 다시 확인, 결석 구분과 접수 저장, 유형별로 저장해 둔 결재자를 NEIS 결재자 창에 지정해 상신(본인(기안) 줄은 그대로 둠)
- `ISSUES.md`: 처리 실패 메시지, 저장해 둔 결재선 확인 결과, 아직 풀리지 않은 조건과 이어서 할 곳
- `docs/student-status.md`: 출결·신청 메뉴, 주소(endpoint), 데이터셋, 내 컴퓨터에 보관하는 항목
- `docs/data-contract.md`: NEIS 항목과 정리된 기록이 어떻게 짝지어지는지
- `docs/auto-sync.md`: 자동 주 동기화, 임시 저장(캐시) 동작, 한계

## 안전과 자료 보관

- **읽기와 쓰기를 나눈다**
  - 수업·현황 조회는 읽기만 하는 것이 확인된 API만 쓴다.
  - 결석신고·체험학습 처리는, 팝업에서 현재 신청을 다시 조회한 뒤 사용자가 체크한 `접수대기` 또는 `접수·미상신` 줄만 처리한다.
  - 고른 학생·날짜·신청 내용·결석 구분과 결재선 기준을 팝업에 보여 준다. NEIS 기록이 실제로 바뀌는 때는 **선택 건 접수 · 결재 상신**을 눌렀을 때뿐이다.
- **접수와 상신**
  - 접수대기 건은 고른 결석 구분으로 정하고 처리상태를 접수로 저장한다. 결석 구분의 기본값은 질병결석이다. 한꺼번에 바꾸거나 줄마다 따로 고를 수 있다.
  - 승인요청 뒤의 **최종 결재는 자동으로 하지 않는다.**
  - 조회한 뒤 상태나 신청 식별값이 바뀌었거나, 같은 목록·상세·결재 창이 여러 개면 처리를 멈춘다.
  - 실행 결과가 분명하지 않으면 자동으로 다시 시도하지 않는다. 대상 목록을 새로 조회해서 NEIS의 지금 상태를 확인한다.
- NEIS 로그인 정보(아이디·비밀번호), 쿠키, 인증 토큰, 원본 네트워크 본문은 읽지도, 따로 저장하지도 않는다.
- NEIS 주간 조회가 끝나면, 이번 주와 주 목록(`dsWeekList`)에서 임시 저장이 없거나 만료된 주를 자동으로 맞춘다. 월간 가져오기는 팝업에서 사용자가 직접 실행한다.
- 정리한 수업 자료는 Chrome 확장 저장소에 이 PC 전용으로 보관한다. 작은 창(플로팅 패널)과 전체 뷰어가 같은 저장 자료를 바로 읽으므로 서버가 켜져 있는지와 상관없다.
- **학생 현황으로 저장하는 것**
  - 확장 저장소에는 이름, 반, 날짜·기간, 출결·신청 종류, 일수, 처리·결재 상태만 기록한다.
  - 처리 후보의 결석신고서 ID, 신청 사유, 교사가 더 적은 사유는 검토와 접수 저장에만 쓴다. 지금 열린 팝업과 처리 중인 메모리에만 두고, 확장 저장소에는 저장하지 않는다.
  - 체험학습의 상세 내용·장소, 보호자 연락처, 서명, 학생 식별번호, 생년월일은 가져오지 않는다.
- 결석신고 첨부는 사용자가 신청 하나의 다운로드 버튼을 눌렀을 때만, NEIS 상세를 열어 내려받는다. 파일 이름과 내용은 확장 저장소나 로그에 남기지 않는다. 파일은 Chrome의 기본 다운로드 방식으로 처리한다.
- **승인요청 결재선**
  - NEIS 목록에 나오는 신청 유형을 이름표로 삼아 `teacherlessonNeisApprovalProfiles`에 저장한다. 결재자 이름과 순서는 지금 쓰는 Chrome 프로필의 `storage.local`에만 둔다.
  - 실행할 때 기안 창의 이름 입력란은 쓰지 않는다. `btnSelectSancr.click()`으로 결재자 지정 창을 열고, 거기서 이름을 조회한다.
  - 같은 이름이 여러 명이면 멈춘다. 지금 설정에는 직위·사용자 ID로 가르는 기준이 없어서, 아무나 고르지 않는다.
  - 사람을 추가하기 전에 `rdbCn` 구분을 먼저 고른다. 그다음 `grdUserListFrom.selectRows([행])`와 `btn1.click()`을 한 번만 부른다.
  - 오른쪽 `dsParam`의 `atrzScNm`·`atrzSeqSn`을 사람마다 확인하고, `btn4`로 저장한 뒤 기안 창의 결재선도 다시 맞춰 본다. 이름·구분·순서 중 하나라도 다르면 상신하지 않는다.
  - 이미 접수된 미상신 건과 새로 접수한 건에 같은 방식을 쓴다.
  - 체험학습 신청서·보고서도 같은 결재선으로 상신한다(v1.7.0). 접수는 상세 창 아래의 [접수] 버튼으로 하고, 신청서는 [저장]을 먼저 한다. 결석 구분과 교사 사유는 결석신고서에만 있다.
- 주간학습 데이터셋 `dsWikLrn`에 수정 표시가 있으면 동기화를 멈춘다. 다른 데이터셋의 수정 표시는 수업내용 동기화를 막지 않는다.
