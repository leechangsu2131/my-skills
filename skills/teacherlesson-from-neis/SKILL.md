# Teacher Lesson From NEIS

NEIS의 주간학습안내 데이터를 현재 로그인된 Chrome 세션에서 읽어 NEIS 화면의 오른쪽 아래 이동식 플로팅 패널과 확장 프로그램 안의 뷰어에 표시합니다. 학생 현황은 확장 팝업에서 일일 출결·결석신고·체험학습 조회를 실행해 추가합니다. 뷰어는 Chrome `storage.local`을 직접 읽으므로 별도 Python 서버를 켤 필요가 없습니다. `teacherlesson-schedule`의 날짜·교시 중심 보드 구성을 참고하지만 Google Sheets 진도표나 수업배치 시트에는 접근하지 않습니다.

`server.py`, `web/`, `실행_나이스수업뷰어.bat`은 이전 확장 버전과의 호환용이며 현재 버전의 일상 사용에는 필요하지 않습니다.

전체 뷰어는 하루 상세, 월~금 주간 보드, 날짜별 요약이 있는 월간 달력, 학생 현황 보기를 제공합니다. 월간 보기에서는 날짜 칸 높이를 조절하고 `+N개 수업`을 눌러 그날의 전체 수업을 펼치거나 토·일 표시를 전환할 수 있습니다. 플로팅 패널도 `오늘의 수업`과 `학생 현황` 탭을 제공하며, 학생 현황을 조회하면 자동으로 해당 탭으로 전환합니다. 학생 현황에는 오늘 출결과 마지막 조회에서 가져온 결석·체험학습 신청 결과 전체가 표시됩니다. 전체 뷰어에서는 선택 날짜의 출결과 조회된 신청 목록을 함께 확인할 수 있습니다.

## 사용자 흐름

1. Chrome 확장 프로그램을 설치/활성화합니다.
2. Chrome에서 NEIS에 로그인하고 `교육과정 > 주간학습안내작성` 화면을 엽니다.
3. 주간학습안내에서 한 번 정상 조회하면 현재 주와 `dsWeekList`에 있는 나머지 주차까지 자동으로 읽어옵니다. 이후 조회에서는 현재 주를 갱신하고 12시간 지난 주만 다시 가져옵니다.
4. NEIS 화면 오른쪽 아래 플로팅 패널을 끌어 원하는 위치에 놓거나, 확장 프로그램 메뉴의 **오늘의 수업 뷰어 열기**에서 수업을 확인합니다.
5. 학생 출결·신청 목록이 필요하면 확장 팝업의 **오늘 출결·결석·체험학습 현황 조회**를 누릅니다. 플로팅 패널의 **학생 현황** 탭에는 오늘 기준 결과가 표시되고, 전체 뷰어에서는 날짜를 바꿔 볼 수 있습니다.
6. 결석신고서 목록을 확인할 때 파일이 필요하면 해당 결석신고서 아래 **첨부 확인 · 다운로드**를 누릅니다. 선택한 신청의 NEIS 상세를 다시 열어 첨부 수와 다운로드 창의 파일 수가 일치하는지 확인한 뒤, 그 신청의 첨부만 Chrome 다운로드로 보냅니다. 파일 내용은 확장 저장소에 복사하지 않습니다. 상세창은 화면 확인을 위해 열어 두므로 내려받은 뒤 NEIS에서 직접 닫고 다음 파일을 확인합니다. 상세창이 이미 열렸거나 신청 ID가 달라진 경우 다운로드를 멈춥니다.
7. 결석신고서(와 체험학습 신청서·보고서)를 접수·상신하려면 **신청 유형별 결재선 저장·관리**에서 신청 유형별 결재자 이름과 순서를 Chrome에 저장합니다. **결석·체험학습 접수·상신 대상 확인**으로 목록을 새로 조회하고 학생·날짜·신청 내용(결석신고는 결석 구분도)을 확인합니다. 필요하면 결석신고서의 각 접수대기 행에 **담임/교사 결석 사유**를 보완 입력합니다. 이 값은 접수 저장 시 NEIS의 `결석사유(담임 및 교사)` 칸에 들어가며 로컬에 저장되지 않습니다. 대상 목록 아래 **선택 건 접수 · 결재 상신**을 한 번 누르면 선택된 접수대기 건은 구분/보완 사유를 저장하며 접수한 뒤, NEIS 결재자 지정 창에서 본인(기안) 행은 유지하고 저장한 결재자를 순서대로 지정해 승인요청합니다. 이미 접수된 미상신 건은 내용을 다시 수정하지 않고 승인요청합니다. 다른 결재자가 미리 지정되어 있으면 본인 행을 보존하면서 기존 결재자만 교체하고, 저장 목록과 정확히 일치하는지 확인합니다. 중복 목록/상세/결재 창이 있으면 처리를 멈춥니다.

월간 가져오기는 확장 팝업에서 달을 선택해 실행할 수 있습니다. `dsWeekList`에서 해당 월과 겹치는 주차를 골라 순차 조회한 뒤 원래 주차를 다시 표시합니다. `dsWikLrn`에 미저장 수업내용 변경이 있으면 자동/수동 동기화를 중단합니다. 다른 화면 데이터셋의 변경 상태는 수업내용 조회를 막지 않습니다. 자세한 갱신·캐시 흐름은 [docs/auto-sync.md](docs/auto-sync.md)를 참고합니다.

## 파일 지도

- `extension/viewer.html`, `extension/viewer.js`, `extension/viewer.css`: Chrome 저장자료를 직접 읽는 하루/주간/월간/학생 현황 뷰어
- `extension/manifest.json`: Chrome MV3 권한과 팝업 정의
- `extension/icons/`: 주소창 옆 확장 아이콘과 Chrome 메뉴용 색상 아이콘
- `extension/neis-reader.js`: NEIS 조회 감지, 등록 주차별 자동 조회, 수업 데이터 정규화
- `extension/content.js`: NEIS 페이지의 이동식 플로팅 패널과 오늘 수업·학생 현황 표시
- `extension/background.js`: 12시간 주별 캐시, 학생 현황과 플로팅 위치, 중복 실행 잠금과 불확실한 결과 기록, NEIS 처리 주입
- `extension/popup.js`: 월간 수업 가져오기, 학생 출결·신청 조회, 결석신고 첨부의 사용자 요청 다운로드, 신청 내용 검토·일괄 결석 구분·선택 실행 UI, 신청 유형별 결재선 프로필의 Chrome `storage.local` 저장·관리, 전체 뷰어 열기
- `extension/absence-workflow.js`: 단일 NEIS MDI 목록 확인, 선택한 결석신고서의 상태·내용 재검증, 결석 구분과 접수 저장, 본인(기안) 행을 보존하며 유형별 Chrome 저장 결재자를 화면에 열린 NEIS 결재자 창에 지정해 상신
- `ISSUES.md`: 처리 실패 메시지, 저장된 결재선 확인 결과, 미해결 사전조건과 재개 지점
- `docs/student-status.md`: 출결/신청 메뉴, endpoint, 데이터셋과 로컬 보관 필드
- `docs/data-contract.md`: NEIS 필드와 정규 레코드 매핑
- `docs/auto-sync.md`: 자동 주차 동기화와 캐시 동작, 제한사항

## 안전과 데이터 보관

- 수업과 현황 조회는 확인된 읽기 API를 사용합니다. 결석신고 처리 기능은 팝업에서 현재 신청을 다시 조회하고, 사용자가 체크한 `접수대기` 또는 `접수·미상신` 행만 처리합니다. 선택 학생·날짜·신청 내용·결석 구분과 결재선 기준을 팝업에 표시하며, **선택 건 접수 · 결재 상신**을 눌렀을 때 NEIS 기록이 바뀝니다.
- 접수대기 건에는 선택한 결석 구분을 설정하고 처리상태를 접수로 저장합니다. 결석 구분 기본값은 질병결석이며, 일괄 변경하거나 행별로 조정할 수 있습니다. 승인요청 후 최종 결재는 자동으로 수행하지 않습니다. 조회 후 상태나 신청 식별값이 바뀌거나 같은 목록/상세/결재 창이 여러 개면 처리를 중단합니다. 실행 응답이 불명확하면 자동 재시도하지 않고 대상 목록을 다시 조회해 NEIS 현재 상태를 확인합니다.
- NEIS 자격 증명, 쿠키, 인증 토큰, 원본 네트워크 본문을 읽거나 별도 저장하지 않습니다.
- NEIS 주간 조회가 끝나면 현재 주와 캐시가 없거나 만료된 `dsWeekList` 주차를 자동 동기화합니다. 월간 가져오기는 팝업에서 사용자가 실행합니다.
- 정규 수업자료는 Chrome 확장 저장소에 이 PC 전용으로 보관합니다. 플로팅 패널과 전체 뷰어가 같은 저장자료를 직접 읽어 서버 실행 여부에 영향을 받지 않습니다.
- 학생 현황은 이름, 반, 날짜/기간, 출결·신청 종류, 일수, 처리/결재 상태만 확장 저장소에 기록합니다. 처리 후보의 결석신고서 ID, 신청 사유, 교사 보완 사유는 현재 팝업/처리 메모리에서 검토 또는 접수 저장에만 사용하고 확장 저장소에는 저장하지 않습니다. 체험 상세내용/장소, 보호자 연락처, 서명, 학생 식별번호와 생년월일은 가져오지 않습니다.
- 결석신고 첨부는 사용자가 개별 신청의 다운로드 버튼을 눌렀을 때만 NEIS 상세를 열어 내려받습니다. 파일명·파일 내용은 확장 저장소나 로그에 남기지 않으며, 파일은 Chrome의 기본 다운로드 흐름으로 처리합니다.
- 승인요청 결재선은 NEIS 목록에 표시되는 신청 유형을 키로 `teacherlessonNeisApprovalProfiles`에 저장합니다. 결재자 이름·순서는 현재 Chrome 프로필의 `storage.local`에만 보관합니다. 실행 시 기안창의 이름 입력란은 쓰지 않고 `btnSelectSancr.click()`으로 결재자 지정 창을 엽니다. 목록에 이름을 조회합니다. 이름이 여러 명과 일치하면 현재 설정에는 직위·사용자 ID 기준이 없으므로 임의로 고르지 않고 중단합니다. 사람을 추가하기 전에 `rdbCn` 구분을 지정한 뒤 `grdUserListFrom.selectRows([행])`와 `btn1.click()`을 한 번만 호출합니다. 오른쪽 `dsParam`의 `atrzScNm`·`atrzSeqSn`을 사람마다 확인하고 `btn4` 저장 후 기안창 결재선도 다시 대조합니다. 이름·구분·순서가 하나라도 다르면 상신하지 않습니다. 이미 접수된 미상신 건과 새로 접수한 건 모두 같은 방식으로 적용합니다. 체험학습 신청서·보고서도 같은 결재선으로 상신합니다(v1.7.0). 접수는 상세창 아래 [접수] 버튼으로 하며 신청서는 [저장]을 먼저 합니다. 결석 구분과 교사 사유는 결석신고서에만 있습니다.
- 주간학습 데이터셋 `dsWikLrn`에 수정 표시가 있으면 동기화를 중단합니다. 다른 데이터셋의 수정 표시는 수업내용 동기화를 막지 않습니다.
