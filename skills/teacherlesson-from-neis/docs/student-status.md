# 학생 출결·신청 현황

## 사용 흐름

1. Chrome에서 NEIS에 로그인합니다.
2. NEIS 탭에서 **NEIS 오늘의 수업** 확장 팝업을 엽니다.
3. **오늘 출결·결석·체험학습 현황 조회**를 누릅니다. 확장은 NEIS의 조회 화면 세 곳을 열어 조회하고, 결과를 Chrome 확장 저장소에 기록합니다.
4. 플로팅 패널은 조회 후 **학생 현황** 탭으로 전환합니다. 패널과 뷰어에는 오늘 출결과 마지막 조회에서 가져온 신청 결과 전체가 표시됩니다.

학생 출결은 현재 날짜 하루를 조회합니다. 결석신고서는 현재 달의 기간을 조회하고, 체험학습 신청서는 NEIS 화면의 기본 조회조건(학년도·학급 등)을 사용합니다. 출결은 선택 날짜를 기준으로 보이고 신청서는 이번 조회에서 가져온 전체 결과를 표시합니다. 조회가 끝나면 패널이 학생 현황 탭으로 자동 전환됩니다. NEIS 결과가 바뀌었을 때 확장 팝업에서 다시 가져오기를 눌러 캐시를 갱신합니다. 조회 구역 중 일부가 실패해도 성공한 구역은 저장하며, 실패한 구역은 기존 저장자료를 보존하고 화면에 갱신 실패로 표시합니다. 뷰어와 플로팅 패널은 Chrome 저장소 값이 바뀌면 자동으로 다시 표시합니다.

가져오기는 Index 앱의 `doOpenMenuToMdi`를 우선 호출해 NEIS MDI 메뉴를 연 뒤, 화면 조회 버튼 또는 조회 제출 객체를 호출합니다. 해당 경로에서 화면이 열리지 않으면 보조 `window.openMdiMenu` 경로를 재시도합니다. 화면의 검색조건과 마지막 열린 NEIS 메뉴가 바뀔 수 있습니다.

## 선택한 결석신고서 접수·상신

팝업의 **신청 유형별 결재선 저장·관리**에서 신청 유형별 결재자 이름과 순서를 저장합니다. 결재자 이름은 Chrome `storage.local`의 `teacherlessonNeisApprovalProfiles`에 이 PC 전용으로 저장됩니다. 신청 유형 문자열이 같은 신청에만 해당 결재선을 연결합니다. 프로필 저장 단계에서는 NEIS에 전송하지 않으며, 사용자가 승인요청을 확인하고 실행할 때 NEIS 결재자 지정 창에서 이 이름들을 순서대로 추가합니다.

**결석신고 접수·상신 대상 확인**은 현재 선택 월의 결석신고서를 다시 조회하고 `접수대기` 또는 `접수 · 미상신` 상태만 후보로 표시합니다. 신청 ID(`abeDclrId`)가 중복되거나 없으면 후보를 비활성화합니다. 목록에는 학생·반·날짜·학부모 신청 사유·현재 교사 사유와 결석 구분을 표시합니다. 처음에는 행이 선택되지 않습니다. 모두 선택/해제할 수 있고, 결석 구분 드롭다운은 기본 `질병결석`이며 값을 바꾸면 체크한 접수대기 행에 즉시 일괄 적용됩니다. 각 행에서도 구분을 따로 조정할 수 있습니다. **담임/교사 결석 사유** 입력란은 접수대기 행에서만 수정할 수 있으며 NEIS 상세창의 `txaShlOpiCn`(`결석사유(담임 및 교사)`)에 연결됩니다. 기존 NEIS 값이 있으면 입력란에 먼저 표시하고, 수정하지 않으면 그대로 보존합니다. 추가 사유는 접수 저장과 함께 NEIS에 기록되며 Chrome 저장소에는 보관하지 않습니다. 접수·미상신 행에는 내용을 수정하지 않습니다. 화면에 선택 건과 결재선이 표시된 상태에서 **선택 건 접수 · 결재 상신**을 한 번 누르면 접수대기 건은 접수 저장 후 상신하고, 접수·미상신 건은 저장된 결재선을 지정해 상신합니다. 서로 다른 신청 유형을 함께 선택하면 유형별로 나눠 상신합니다. 자동으로 들어오는 `기안` 행은 본인 행으로 구분해 보존하고, 현재 결재자 행만 필요 시 교체한 뒤 Chrome에 저장한 이름·순서와 일치하는지 확인합니다.

- `접수대기`: 상세 팝업에서 사용자가 선택한 결석 구분(기본 `질병결석`)을 설정하고 처리 상태를 `접수`로 바꾸어 저장합니다. 신청 내용은 수정하지 않습니다.
- `접수 · 미상신`: 선택한 행만 승인요청 대상으로 체크하고, NEIS의 `기안` 행은 유지한 채 Chrome에 저장한 결재자 이름을 순서대로 지정해 상신합니다.
- 실행 전 NEIS에서 목록을 다시 조회해 신청 ID와 처리 상태를 검증합니다. 대상이나 상태가 달라졌거나 중복이면 중단합니다.
- 기존 결석신고서 목록이 다른 MDI 탭 뒤에 숨겨져 있으면 처리 전에 목록 화면을 활성화하고 그리드 표시 여부를 확인합니다.
- 같은 결석신고서 목록 인스턴스가 여러 개 있거나 처리 시작 전에 상세/결재 창이 열려 있으면 중복 동작을 막고 중단합니다. 확장 서비스 워커와 로컬 저장소 잠금으로 빠른 중복 클릭/팝업 재실행도 차단합니다.
- 접수 후 상태와 승인요청 상태를 다시 조회해 결과를 확인합니다. 확인 실패 시 자동 재시도하지 않으며, 사용자는 NEIS 현재 상태를 확인해야 합니다.
- 처리 중 브라우저 응답이 끊겨 반영 건수를 알 수 없으면 `0건`으로 표시하지 않습니다. 재실행을 차단하고 대상 목록을 새로 조회해 현재 NEIS 상태를 확인한 뒤에만 잠금을 풉니다.
- 최종 결재는 실행하지 않습니다. 팝업을 닫으면 후보 ID와 선택 상태는 남지 않습니다.

## 확인된 NEIS 데이터 계약

2026-11-19에 로그인된 업무포털에서 실제 메뉴를 열고 정상 조회 요청의 endpoint, 앱 ID, 데이터셋 컬럼 구성을 확인했습니다. 확인 과정에서 학생 이름이나 사유 등 행의 개인정보는 터미널/파일에 출력하지 않았습니다.

| 범위 | 메뉴 | 앱 ID | 조회 endpoint | 데이터셋 |
|---|---|---|---|---|
| 일일 출결 | 결석자및개인별출결현황 | `edu/sw/els/srg/aa/els_srgaa02_m06` | `/els_srg_aa02_010.do` | `dsListAbeYmdAbeStu` |
| 결석 신청 | 결석신고서관리 | `edu/sa/eds/eaa/ae/eds_eaaae03_m01` | `/eds_eaa_ae03_002.do` | `dsStdntListForAbe` |
| 체험학습 신청 | 교외체험학습신청서관리 | `edu/sa/eds/eaa/ae/eds_eaaae01_m01` | `/eds_eaa_ae01_002.do` | `dsStdntListForAply` |

결석신고서 처리 선택에는 `abeDclrId`를 사용합니다. 이 ID는 처리 후보를 다시 NEIS 데이터셋 행과 연결할 때만 팝업 메모리에 두며 확장 저장소에는 남기지 않습니다. 결석신고 처리 화면 컬럼을 다시 확인한 결과 `abeDclrId`가 신청 단위 식별자이고 `stuInvlNo`는 학생 식별자이므로, 처리에는 전자를 사용하고 후자는 읽지 않습니다.

출결 요약은 `gyulsuk*`, `late*`, `chotoe*`, `gyulgwa*` 일수 컬럼을 결석·지각·조퇴·결과로 정규화합니다. 신청 목록은 학생 이름, 반, 신청 종류, 기간, 처리 상태와 결재 상태만 정규화합니다.

## 로컬 보관 필드와 제외 필드

보관 필드는 학생 이름, 학급 표시, 날짜/기간, 출결 종류와 일수, 신청 종류, NEIS 처리 상태 및 결재 상태입니다. `chrome.storage.local`의 `teacherlessonNeisStudentStatus`에 저장합니다. 신청 ID는 선택 작업 중 팝업·서비스워커 메모리에만 있으며 저장되지 않습니다. 마지막 처리 결과에는 시각, 접수/승인요청 건수와 오류 안내만 저장하며 이름과 신청 ID는 기록하지 않습니다.

출결/신청 현황 캐시에는 신고 사유, 활동 내용, 체험 장소, 보호자 이름·관계·연락처, 서명, 파일 참조 ID, 학생 고유번호와 생년월일을 저장하지 않습니다. 처리 후보를 검토할 때 결석신고 사유는 현재 팝업 메모리에만 읽어 표시하고 저장하지 않습니다. Chrome 확장 저장소는 현재 브라우저 프로필의 로컬 저장소이며 외부 서버로 전송하지 않습니다. 결석신고서는 유형별 승인요청을 지원하고, 체험학습 신청서는 조회 전용입니다.

## 구현 위치

- `extension/popup.js`: 세 화면 조회와 최소 필드 추출, 처리 후보 검토·선택·일괄 결석 구분·교사 사유 입력·실행, 유형별 결재선 로컬 저장·관리
- `extension/absence-workflow.js`: 선택 건의 NEIS 상태/내용 재검증, 접수 시 결석 구분·교사 사유 저장, 그리드 API로 선택 건 확인, 본인(기안) 행 보존, 저장된 결재자 지정 및 상신
- `extension/background.js`: 필드 검증과 로컬 캐시 저장, 백그라운드 처리 실행, 처리 후 결석신고 현황 갱신
- `extension/viewer.html`: 학생 현황 보기 탭
- `extension/viewer.js`: 선택 날짜에 맞는 출결/신청 행 표시
- `extension/viewer.css`: 출결 종류·신청 종류별 색 구분
