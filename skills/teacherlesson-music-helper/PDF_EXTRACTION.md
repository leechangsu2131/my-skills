# 지도서 PDF 발췌 방법

큰 지도서 PDF에서 수업에 필요한 부분만 따로 만들 때는 Python의 PyMuPDF(`fitz`)로 페이지를 추출한다.

## 작업 순서

1. 원본 PDF를 `fitz.open()`으로 연다.
2. PDF 안의 텍스트를 읽어 인쇄된 쪽수와 실제 PDF 쪽수의 차이를 확인한다. 표지나 앞부분 때문에 두 쪽수가 다를 수 있으므로, 인쇄 쪽수만 보고 바로 페이지 인덱스를 계산하지 않는다.
3. 필요한 연속 구간은 `insert_pdf()`로 새 문서에 복사한다. 떨어진 구간이면 각 구간을 차례로 추가한다.
4. 원본 페이지를 그대로 복사한 결과가 지나치게 크면 각 페이지를 150dpi JPEG(품질 88) 이미지로 렌더링해 새 PDF 페이지에 넣는다. 이 방식은 페이지 모양을 유지하면서 용량을 크게 줄인다. 결과 페이지의 글자는 이미지이므로 텍스트 검색/복사는 되지 않는다.
5. 저장 후 PDF를 다시 열어 페이지 수와 파일 크기를 확인한다. 파일별 30MB 미만이 목표라면 여유 있게 29MiB 이하로 나누고, 한 페이지 자체가 기준을 넘는 경우에도 이미지 압축본으로 만든다.

## 음악 3단원 작업 기록

원본: `C:\Users\user\Downloads\(동아출판) 22개정_초등 음악3_지도서.pdf` (240쪽)

이 원본에서는 인쇄 쪽수 146이 PDF 96쪽에 해당했다. 즉 인쇄 쪽수와 PDF 쪽수는 50쪽 차이가 났다.

- 3단원 개관 인쇄 146~148쪽: PDF 96~98쪽
- `리듬 악기 노래` 지도 내용과 활동지 인쇄 177~182쪽: PDF 127~132쪽
- 3단원 전체 인쇄 146~195쪽: PDF 96~145쪽

결과 파일은 `C:\Users\user\Documents\지도서`에 만들었다.

- `음악3_3단원_개관146-148_리듬악기노래177-182.pdf`: 9쪽, 약 2.15MiB
- `음악3_3단원_전체_쪽146-195.pdf`: 50쪽, 약 11.83MiB

두 결과는 150dpi JPEG 페이지로 다시 구성했다. 이후 같은 방식으로 작업할 때는 원본별 인쇄 쪽수와 PDF 쪽수의 대응을 새로 확인하고, 페이지 수와 최종 용량도 다시 검증한다.
