# util-bat-launcher — 스킬 실행기

스킬마다 흩어진 bat 파일을 찾아다니지 않도록, `skills/` 아래의 `.bat`·`.cmd` 를 실행할 때마다 새로 모아
한 창에 보여 준다. 실행은 탐색기에서 더블클릭한 것과 같다(그 bat 이 있는 폴더에서).

## 언제 쓰나
- 스킬 bat 을 자주 실행하는데 폴더를 매번 찾아가기 번거로울 때
- 쓰지 않음: bat 이 없는 스킬(Claude 에게 말로 시키는 스킬)은 목록에 나오지 않는다.

## 준비
- Windows, Python 3.10+, `pip install -r requirements.txt` (실행.bat 이 없으면 알아서 설치)
- 즐겨찾기·최근 실행은 `내 문서\my-skills-data\util-bat-launcher\config.json` 에 저장된다.

## 사용법
```powershell
.\실행.bat                      # 창 열기. 처음 한 번 '바탕화면 바로가기'를 눌러 두면 다음부터 바탕화면에서
python launcher.py --list       # 화면 없이 찾은 실행 파일과 설명만 출력
```

| 하고 싶은 일 | 방법 |
|---|---|
| 실행 | 더블클릭 또는 Enter. 처음 실행하는 파일은 한 번 묻는다("내용 먼저 보기"로 메모장 확인 가능) |
| 찾기 | 위 칸에 낱말(여러 개면 모두 들어간 것만). 스킬 이름·파일 이름·설명·분야에서 찾는다 |
| 즐겨찾기 | 오른쪽 클릭 → 즐겨찾기 추가. 맨 위 '★ 즐겨찾기'에 모인다 |
| 최근 실행 | 실행한 것 8개가 '🕘 최근 실행'에 자동으로 모인다 |
| 폴더 열기·내용 보기·경로 복사 | 오른쪽 클릭 |

- 설명 칸: 스킬 줄은 SKILL.md 의 summary, 파일 줄은 bat 안의 `title` → `rem`/`::` → `echo` 첫 설명.
  bat 맨 위에 `rem 한 줄 설명` 을 적어 두면 그대로 보인다.
- 빼는 폴더: `node_modules`, `.venv`, `venv`, `scratch`, `dist`, `build`, `__pycache__`, 점으로 시작하는 폴더, `_shared`.

## 주의
- 목록에는 프린터 설정 초기화, 크롬 강제 종료처럼 무언가를 바꾸는 bat 도 섞여 있다. 처음 쓰는 것은 오른쪽 클릭 → 내용 보기로 먼저 확인한다.
