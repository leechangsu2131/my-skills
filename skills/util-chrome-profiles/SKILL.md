# util-chrome-profiles — Chrome·Edge 프로필 매니저

Chrome·Edge 를 평소처럼 실행하고(로그인 유지) Windows API 로 창을 다루는 작은 데스크톱 앱이다.
창이 어느 프로필인지는 브라우저가 창마다 붙이는 작업표시줄 앱 ID 로 알아낸다
(Chrome 기본 `Chrome`, Profile 4 `Chrome.UserData.Profile4` / Edge 기본 `MSEdge`, Profile 1 `MSEdge.UserData.Profile1`).
Edge 프로필은 트리에 `Edge · 이름` 으로 보이고 Chrome 프로필과 똑같이 그룹·열기·닫기·입력이 된다. 그래서 매니저 밖에서 연 창,
매니저를 켜기 전부터 열려 있던 창도 프로필별로 잡힌다.

## 언제 쓰나
- Chrome 프로필이 많아 골라 열기·묶어 열기·창 찾기가 번거로울 때
- 여러 계정 창에 같은 글을 넣거나, 오래 걸리는 화면(대기열·업로드)을 지켜볼 때
- 쓰지 않음: 웹 페이지 자동 조작(→ `ego-browser`, `_shared/cdp_tab.py`), 학교 사이트 일괄 처리(각 업무 스킬)

## 준비
- Windows, Python 3.10+, `pip install -r requirements.txt` (PySide6-Essentials, pywin32, uiautomation)
- 설정 키(선택): 중앙 `.env` 의 `CHROME_USER_DATA_DIR`·`EDGE_USER_DATA_DIR` — 기본 `%LOCALAPPDATA%\Google\Chrome\User Data`, `%LOCALAPPDATA%\Microsoft\Edge\User Data`. 설치 안 된 브라우저는 건너뛴다.
- **다른 PC에서 써도 됨**: 설정은 프로필 폴더 이름(Profile 4)이 아니라 **계정 이메일 기준**(`acct:이메일`, Edge 는 `edge:acct:이메일`)으로 저장한다. PC 마다 폴더 순서가 달라도 같은 계정이면 같은 그룹·시작 URL·작업 시간, 그 PC 에 없는 계정 설정은 지우지 않고 남겨 둔다. 로그인 안 한 프로필만 폴더 이름 기준(PC 가 다르면 다른 프로필일 수 있음). 설정 파일을 다른 PC 로 복사하거나 OneDrive 로 함께 써도 된다(단 두 PC 를 동시에 켜 두면 마지막에 저장한 쪽이 이김). `python chrome_profiles.py --check` 로 '설정 저장 이름' 확인.
- 그룹·시작 URL·감시 시간·작업 시간은 `내 문서\my-skills-data\util-chrome-profiles\config.json`, 다시 쓸 시각은 같은 폴더 `pauses.json` 에 저장된다. 페이지 글 자체는 저장하지 않는다(일시 중지 안내 줄 앞 120자만).

## 사용법
```powershell
# 실행 (콘솔 창 없이)
.\실행.bat
# 화면 없이 점검: 프로필 목록과 열린 창 ↔ 프로필 짝을 출력
python chrome_profiles.py --check
```

| 하고 싶은 일 | 방법 |
|---|---|
| 프로필 열기 | 더블클릭, 또는 골라서 "열기". 이미 열려 있으면 그 창을 앞으로(Shift+열기 = 늘 새 창) |
| 그룹 통째로 열기 | 그룹을 고르고 "열기" (0.4초 간격으로 하나씩) |
| 그룹 만들기·이름 바꾸기·지우기 | "그룹 추가", 그룹 고르고 F2, "그룹 삭제"(안의 프로필은 미분류로) |
| 그룹 옮기기 | 프로필을 다른 그룹으로 끌어다 놓기(여러 개 골라서도 됨) |
| 시작 URL 일괄 변경 | 프로필·그룹 여러 개 고르고 "시작 URL" (열 때 그 주소로 연다. Chrome 설정 자체는 안 바꿈) |
| 창 미리보기 | 오른쪽에 열린 창이 트리 순서대로. 클릭 = 창 앞으로. "트리에서 고른 것만 미리보기"로 거르기 |
| 사이트 이동 | "사이트 이동"(또는 미리보기 오른쪽 클릭) → 주소 입력(최근 주소 10개 기억, `naver.com` 처럼 써도 됨). 방식 둘: ① 지금 보는 탭을 그 주소로 — 창마다 앞으로 와서 Ctrl+L → 주소 → Enter, 기타 창도 됨 ② 새 탭으로 열기 — 창 전환 없이 프로필마다 새 탭, 안 열린 프로필은 새 창. 대상: 미리보기에서 고른 창 → 트리에서 고른 프로필 → 아무것도 안 고르면 열린 프로필 창 전체 |
| 탭 정리 | "탭 정리 ▾"(또는 미리보기 오른쪽 클릭 → 탭 정리) → 다른 탭 / 오른쪽 탭 / 왼쪽 탭 닫기. 창마다 지금 보는 탭 기준. 창 전환·마우스 없이 화면 읽기(UI 자동화)로 탭 줄을 읽어 X 단추만 누른다. 닫기 전에 창별 개수를 보여 주고 묻는다. 대상은 사이트 이동과 같다 |
| 일괄 입력 | "일괄 입력" → 열린 창(고른 프로필이 있으면 그 창들)에 넣기. **기본: 입력칸을 찾아서**(커서가 없어도 — 창마다 웹 페이지의 글칸 중 여러 줄·맨 아래·넓은 칸 = 채팅 입력 막대를 골라 초점을 주고 글 끝에 이어 씀, 검색칸은 뒤로). "칸 이름"에 `답글` 처럼 낱말을 넣으면 이름·자리표시 글에 그 낱말이 든 칸만. 칸을 못 찾은 창은 건너뜀. "지금 커서가 있는 자리에"를 고르면 예전처럼<br>특수 키는 중괄호로: `{Enter}` `{Tab}` `{Esc}` `{Ctrl+A}` `{Shift+Enter}` `{Up}` `{F5}` `{대기 1.5}`(초, 최대 10). 창 아래 단추로 넣을 수 있고, 아래 줄에 실행 순서가 미리 보인다. 중괄호 글자는 `{{` `}}`. 마지막에 쓴 내용은 다음에 그대로 뜬다 |
| 미리보기에서 여러 개 고르기 | 미리보기 위를 드래그하거나 Shift+클릭. 고른 창은 위의 "고른 창 닫기"·Del 키로 닫고, 오른쪽 클릭으로 감시·타이머·일괄 입력을 한꺼번에 |
| 일괄 닫기 | 트리에서 프로필·그룹 고르고 "일괄 닫기"(안 고르면 프로필 창 전체, 기타 창은 직접 고를 때만). 확인 창 뒤 X 버튼과 같은 닫기. 한 창만은 미리보기 오른쪽 클릭 → "이 창 닫기" |
| 기타 브라우저 창 관리 | 트리 맨 아래 "기타 브라우저 창" 그룹에 앱 ID 별로 보인다. 고르면 미리보기 거르기·일괄 닫기·일괄 입력 대상이 되고, 더블클릭 = 창 앞으로, F2 = 알아보기 쉬운 이름 붙이기(저장됨) |
| 작업 시간 재기 | 트리의 프로필·그룹 오른쪽 클릭 → "작업 시간 재기 시작"(+ 알림 1~8시간·직접 입력). 트리 '작업' 칸에 지난 시간(시:분)이 보이고, 정한 시간이 지나면 트레이 알림·소리·작은 안내 창, 칸이 빨갛게. 미리보기 오른쪽 클릭으로도 시작/멈춤. 매니저를 껐다 켜도 이어진다. 기본 알림 시간은 아래 '작업 알림(시간)'(0 = 끔) 알림 시간이 지난 작업이 있으면 미리보기 위에 **"⏱ 시간 다 된 창 닫기 (n)"** 단추 — 그 프로필(그룹이면 그룹 안 모든 프로필)의 열린 창을 묻고 닫은 뒤 작업 시간도 멈춤. 트리 오른쪽 클릭 "이 작업의 창 모두 닫고 작업 시간 멈춤"도 |
| 단축키(어디서든) | `Ctrl+Alt+T` = 작업 시간 보기(지금 창 프로필·그룹 먼저, 나머지도). `Ctrl+Alt+S` = 맨 앞 Chrome·Edge 창 프로필의 작업 시간 시작/멈춤. 다른 프로그램과 겹치면 config.json 의 `hotkeys` 에서 바꾼다(예: `"show": "Ctrl+Shift+F9"`) |
| 사용량 일시 중지 시각 | "사용량 일시 중지 시각 찾기"(기본 켬)를 켜 두면 20초마다 열린 창 페이지 **끝부분**을 읽어 "일시 중지됨: 무료 사용량은 오후 12:10 이후 다시 제공됩니다", "오후 6:00까지 무료 메시지를 모두 사용했습니다", "18시까지 …", "Resets at 3:00 PM" 같은 안내를 찾는다. 찾으면 그 시각을 적고(`pauses.json`, `usage_pause.py`) 미리보기에 `⏸ 12:10까지 (35분)`, 트리 '작업' 칸에 `⏸12:10`. 오른쪽 미리보기 맨 위에 **다시 쓸 시각 요약 줄**(`⏸ 18:00 (2시간): 소연·은정 외 2 │ 20:30: …`, 트레이 아이콘 말풍선에도). 그 시각이 되면 트레이·소리·안내 창으로 알리고 지운다. 미리보기 오른쪽 클릭 → 직접 적기·지우기. 대화 위쪽에 인용된 문구는 무시한다 |
| 글자 감시 | 미리보기 오른쪽 클릭 → "글자 감시…" → 찾을 글(쉼표로 여러 개). 20초마다 지금 탭 페이지에 그 글이 새로 나타나면 알림 |
| 문구 찾아 누르기 | 미리보기 오른쪽 클릭 → "문구 찾아 누르기…" → 글(예: `계속`, `다시 시도`). 고른 창들에서 그 이름의 단추·링크를 찾아 보여 주고, 확인하면 누른다(창 전환 없이 누르기 → 안 되면 그때만 창을 앞으로 가져와 클릭) |
| 자동화: 프로젝트 지침 일괄 바꾸기 (claude.ai) | 작업자 창이 claude.ai 의 아무 페이지(채팅 등)에 있으면 됨 — 프로젝트 페이지가 아니면 claude.ai/projects 로 가서 '프로젝트 이름에 든 낱말'로(비우면 목록 맨 위) 골라 들어가고, 끝나면 원래 보던 페이지로 돌아감(뒤로). claude.ai 가 아닌 창은 건너뜀 → "자동화 ▾"(또는 미리보기 오른쪽 클릭) → 새 지침 전체를 한 번 붙여 넣기(첫 줄이 `[이름]` 줄이면 자동으로 빼고, 창마다 원래 이름 줄을 남김) → 맨 위 몇 줄(기본 1) 남길지. ① 창마다 '지침 편집'을 열어 지금 지침을 읽고 취소 → ② 창별 '남길 첫 줄·글자 수 변화'를 보여 주고 묻기 → ③ 전체 선택·붙여넣기 → 글칸 확인 → '지침 저장' → 페이지 새로 고침 후 다시 읽어 확인. 기본으로 첫 줄이 `[` 로 시작하는 창만 바꾼다. "미리보기만"을 켜면 넣어 보고 원래 글로 되돌린 뒤 취소(저장 안 함) |
| 답글 모아보기 (claude.ai) | "답글 모아보기" 단추 → 창마다 상태(✍ 답하는 중 · ✅ 끝남 · ❓ 내 답 필요 · ⌛ 보낸 뒤 대기 · 일시 중지)·언제·마지막 답. 줄을 누르면 아래에 최근 메시지(화면 근처 몇 개), 두 번 누르면 그 창을 앞으로. "답글 모으기·답 끝남 알림"(기본 켬)이면 20초마다 읽고, 답하는 중 → 끝남으로 바뀌면 트레이 알림. 글은 메모리에만 두고 "모아 둔 답 저장(.md)"을 눌렀을 때만 `replies\날짜.md` 에 덧붙임 트리 **'작업·상태' 칸**에도 프로필마다 `✍ 진행 중`(분석·응답 생성 중)·`✅ 대기`(끝나고 기다림)·`❓ 답 필요`·`⌛ 보냄`·`⏸18:00`(그 시각까지 못 씀)이, 그룹 줄에는 `✍2 ✅3 ⏸1` 처럼 개수가 보인다(마우스를 올리면 창별로) |
| 프로젝트 대화로 들어가기 (claude.ai) | 자동화 ▾(또는 미리보기 오른쪽 클릭) → "프로젝트 대화 목록의 맨 아래(맨 위) 대화로 들어가기". 프로젝트 페이지가 아니면 목록에서 골라(이름 낱말 또는 지금/맨 위) 들어간 뒤 가운데 대화 목록(사이드바 빼고)의 맨 아래 대화로 |
| '계속'·'다시 시도' 자동으로 누르기 | 체크 상자(기본 끔)를 켜면 20초마다 창을 볼 때 이름이 **정확히 같은** 단추가 보이면 누름. 답을 쓰는 중이면 안 누르고, 같은 창은 2분에 한 번, 누를 때마다 알림. 이름은 자동화 ▾ → '자동으로 누를 단추 이름' (답마다 붙는 '재시도'·'편집'은 넣지 말 것) |
| 창 최대화 | 체크 상자(기본 켬): 프로필을 열 때 최대화로 열고, 일괄 입력·지침 바꾸기·대화 들어가기 전에 창을 최대화(작은 창은 페이지 모양이 달라 틀리기 쉬움). 미리보기 오른쪽 클릭 "창 최대화"도 |
| 그룹 진행: 이전 작업 이어서 / 새로 진행 (claude.ai) | 트리에서 그룹을 오른쪽 클릭(또는 그룹을 고르고 자동화 ▾). **이어서**: 창마다 프로젝트 목록 맨 위·왼쪽 프로젝트 → 그 프로젝트의 가장 최근 대화 → '계속'·'다시 시도' 단추가 있으면 누르고, 답하는 중이면 그대로, 아니면 그룹의 '이어서 보낼 말'(기본 `다음`) + Enter. **새로 진행**: 같은 프로젝트 페이지 입력칸에 그룹의 시작 프롬프트 + Enter(새 채팅). 프롬프트는 '그룹별 프롬프트 설정'에서 그룹마다(같은 그룹 창은 같은 글). 보내기 전에 그룹별 창 수·글을 보여 주고 묻는다 |
| 타이머 | 미리보기 Ctrl+클릭 → 지정한 분이 지나면 트레이 알림·소리·빨간 표시. 다시 Ctrl+클릭 = 취소 |
| 변화 없음 감시 | 미리보기 오른쪽 클릭 → "변화 감시 켜기". 지정한 초 동안 화면이 안 바뀌면 알림 |

## 주의
- 여러 창에 차례로 하는 일(일괄 입력·사이트 이동·지침 바꾸기)은 진행 창이 뜨고 '멈추기'로 언제든 멈출 수 있다. 오류는 `error.log`(데이터 폴더)에 남는다.
- 프로젝트 지침 바꾸기는 작업자 계정의 claude.ai 설정을 실제로 바꾼다. 처음엔 "미리보기만"으로, 그다음 한 창만 골라 저장해 본다. claude.ai 는 편집 창에서 취소해도 쓴 글이 그 페이지에 남아 있다가 다음 저장에 들어갈 수 있어, 미리보기·실패 때는 원래 글로 되돌린 뒤 취소한다.
- 일괄 입력은 창을 하나씩 앞으로 가져와 Ctrl+V 한다. 그동안 마우스·키보드를 쓰지 않는다.
  앞으로 못 가져온 창은 엉뚱한 곳에 붙지 않게 건너뛰고 상태 표시줄에 알린다. 클립보드는 끝나면 되돌린다.
- `{Enter}` 를 넣으면 여러 창에서 한꺼번에 보내기·제출이 될 수 있어, 보내기 전에 순서를 보여 주고 한 번 더 묻는다.
- 넣는 도중 다른 창이 앞으로 오면(마우스를 건드리는 등) 그 창은 그 자리에서 멈추고 상태 표시줄에 알린다.
- **미리보기가 멈추는 경우 두 가지**: ① 최소화된 창 — Chrome 이 아예 그리지 않음. 미리보기에 "🗕 최소화 — 그림 멈춤"이 붙고, 미리보기 위 "최소화된 창 펼치기"(또는 "최소화된 창 자동으로 뒤에 펼쳐 두기")로 앞을 가리지 않게 뒤쪽에 펼치면 다시 찍힌다. ② 다른 프로그램 창에 완전히 가려진 창 — Chrome 절약 기능이 그리기를 멈춤. "가려진 창도 계속 그리기"(기본 켬)는 프로필을 열 때 실행 옵션(`--disable-features=CalculateNativeWinOcclusion --disable-backgrounding-occluded-windows`)을 붙이는데, 브라우저가 처음 켜질 때만 먹어 **Chrome·Edge 를 모두 닫고 이 매니저로 다시 열어야** 적용된다(안 됐으면 미리보기 위에 안내). 글로 읽는 기능(답글 모아보기·일시 중지 감지·자동 누르기)은 최소화·가려짐과 상관없이 된다.
- 다른 user-data-dir 로 띄운 Chrome(자동화용 등)·프로필 선택 창·앱 창은 "기타 브라우저 창"으로 보인다. 새로 띄우기는 못 하고(어느 폴더인지 몰라서) 앞으로·닫기·입력만 된다.
