# 📍 스마트 경로 조회 앱 (카카오맵 버전)

카카오맵 API 기반으로 4가지 경로 분석을 제공하는 Streamlit 앱:

| 탭 | 기능 |
|---|---|
| 🚗 **Tab 1** | 단일 출발 → 여러 장소 (엑셀 기반) |
| 📊 **Tab 2** | 여러 출발 → 여러 도착 (매트릭스 계산) |
| 📍 **Tab 3** | 최적 중간지점 탐색 (참여자 기준) |
| 🛣️ **Tab 4** | 경유지 비교 A→X→B (출장지 후보 비교) |

엑셀에 저장된 장소들까지의 **거리, 소요시간**을 카카오맵 API로 계산합니다.

---

## 🚀 실행 방법

### 1단계: 패키지 설치
```bash
pip install -r requirements.txt
```

### 2단계: API 키 설정 (.env 파일)
```bash
copy .env.example .env
```
`.env` 파일을 열어서 발급받은 카카오 API 키를 입력:
```
KAKAO_API_KEY=your_kakao_rest_api_key_here
```

### 3단계: 앱 실행
```bash
streamlit run app.py
```

→ 브라우저에서 `http://localhost:8501` 자동 오픈

---

## 🔑 API 키 발급 (단 하나!)

네이버와 달리 **REST API 키 하나**로 장소 검색 + 길찾기 모두 사용 가능합니다.

### 1단계: 카카오 개발자 센터 가입 & 앱 생성
1. https://developers.kakao.com 접속 (카카오 계정으로 로그인)
2. 상단 메뉴 `내 애플리케이션` → `애플리케이션 추가하기`
3. 앱 이름/사업자명 입력 후 저장
4. 생성된 앱 클릭 → `앱 키` 탭 → **REST API 키** 복사
5. `.env` 파일의 `KAKAO_API_KEY`에 붙여넣기

### 2단계: 카카오 모빌리티 길찾기 API 활성화
1. 앱 설정 → `카카오 로그인` 비활성화 상태여도 무관
2. `카카오내비` 항목이 있다면 활성화
3. 없다면 로컬 API(장소검색)만 사용하고, 길찾기는 직선거리로 대체됨

> ✅ 로컬 검색 API: **하루 300,000건 무료**  
> ✅ 길찾기 API: **하루 300건 무료** (기본 제공)

> 💡 **팁**: `.env` 파일 없이도 UI에서 직접 API 키를 입력할 수 있습니다.

## 📋 엑셀 파일 형식 (자유로운 구조 OK)

| 번호 | 장소명 | 방문시간 | 담당자 | 비고 |
|------|--------|----------|--------|------|
| 1 | 강남초등학교 | 09:00 | 홍길동 | 정기방문 |
| 2 | 서초중학교 | 11:30 | 김철수 | 상담 |

- 열 순서/위치 자유 → 실행 시 사용자가 직접 지정
- 헤더 행이 1행이 아니어도 설정 가능
- 장소명: 학교명, 건물명, 지하철역명 등 검색 가능한 이름이면 OK

---

## 💡 검색 정확도 향상 팁

지역 접두사 기능을 활용하세요:
- `"강남초등학교"` → 검색 결과가 여러 지역에 흩어질 수 있음
- `"서울시 강남구"` 접두사 설정 시 → `"서울시 강남구 강남초등학교"` 로 검색

## �️ 트러블슈팅

| 문제 | 원인 | 해결 방법 |
|------|------|-----------|
| `출발 위치를 찾을 수 없습니다` | 지명이 너무 짧거나 광범위함 | **지역 접두사** 추가 (예: `화정초등학교` → `경주 화정초등학교`) |
| `장소 미발견` (목적지) | 동일한 이름의 장소가 전국에 다수 존재 | 지역 접두사로 특정 지역으로 좁힘 |
| 거리는 나오는데 소요시간이 `-` | 길찾기 API 무료 쿼터(300건/일) 초과 | 다음 날 재시도하거나 직선거리로 확인 |
| `Session state does not function` | `python app.py`로 실행함 | 반드시 **`streamlit run app.py`** 로 실행 |

### 테스트 예시 (경주시)

#### Tab 1 — 단일 출발 → 여러 장소

| 번호 | 장소명 | 방문시간 |
|------|--------|----------|
| 1 | 첨성대 | 09:00 |
| 2 | 불국사 | 11:00 |
| 3 | 경주역 | 14:00 |

**출발 위치**: `경주 황성공원`  
**지역 접두사**: `경주`

→ 각 장소까지의 거리와 소요시간이 계산되어 출력됩니다.

#### Tab 4 — 경유지 비교 (A→X→B)

- **A (출발지/근무지)**: `경주 황성공원`
- **B (도착지/집)**: `경주역`
- **경유지 X 후보** (직접 입력 또는 엑셀):
  - 첨성대
  - 불국사
  - 동궁과 월지

→ 각 경유지별 A→X→B 총 소요시간과 직행 대비 추가 시간(분)이 비교되어 출력됩니다.

## 📊 결과 출력

### Tab 1 — 단일 출발 → 여러 장소

| 장소명 | 검색 결과 | 주소 | 저장시간 | 거리(km) | 소요시간(분) |
|--------|-----------|------|----------|----------|-------------|
| 첨성대 | 첨성대 | 경주... | 09:00 | 🟢 2.1 | 8 |
| 불국사 | 불국사 | 경주... | 11:00 | 🟠 12.5 | 25 |
| 경주역 | 경주역 | 경주... | 14:00 | 🟠 6.3 | 15 |

🟢 5km 이내 · 🟠 5~15km · 🔴 15km 초과  
길찾기 API 실패 시 직선거리로 자동 대체 (비고란에 표시)

### Tab 4 — 경유지 비교 (A→X→B)

| 경유지(X) | 주소 | A→X 시간 | X→B 시간 | 총 시간(분) | 직행 대비 +분 |
|-----------|------|----------|----------|-------------|---------------|
| 경주교육지원청 | 경주... | 12분 | 18분 | 30 | +5분 |
| 경주시청 | 경주... | 8분 | 25분 | 33 | +8분 |
| 경주경찰서 | 경주... | 15분 | 10분 | 25 | +0분 |

"직행 대비 +분"이 핵심 비교값입니다. A→B 직행 대비 몇 분이 더 소요되는지 한눈에 확인합니다.
