# 📍 스마트 경로 조회 앱 (카카오맵 기반)

카카오맵 API를 활용하여 엑셀 데이터의 장소들을 지도에 시각화하고 최적의 경로 및 이동 시간을 분석해주는 로컬 웹 애플리케이션입니다.

## ✨ 주요 기능 및 탭 안내

| 탭 | 기능 | 특징 |
|---|---|---|
| 🚗 **Tab 1** | **단일 출발 → 여러 장소** | 기준 출발지에서 엑셀 내 여러 목적지까지의 거리/시간 계산 |
| 📊 **Tab 2** | **다대다 매트릭스** | 여러 출발지 × 여러 도착지 간의 모든 이동 경우의 수 일괄 계산 |
| 📍 **Tab 3** | **최적 중간지점 탐색** | 여러 참여자의 위치를 기반으로 이동 시간이 가장 적은 중간 후보지 도출 |
| 🛣️ **Tab 4** | **경유지 비교 (A→X→B)** | 출장 시 직행 대비 경유지를 거칠 때 추가되는 소요시간 비교 |

### 🚀 강력해진 엑셀 및 UI 지원
- **스마트 엑셀 파싱**: 다중 시트 자동 인식, 데이터 시작행 자동 감지(순번 '1' 탐색), 병합 셀 헤더(2행) 자동 결합 복원.
- **다이나믹 지도 팝업**: 엑셀의 다양한 열(학습주제, 차시, 비고 등)을 원클릭 태그 버튼으로 지도 마커 팝업과 결과 표에 즉시 추가/제거 가능.
- **빠른 위치 입력**: `.env`에 등록된 회사/집 주소를 원클릭으로 텍스트 입력란에 자동 채움.
- **자동 지역 접두사**: 시/군 단위 검색 시 불필요한 입력란을 자동 숨김 처리하여 UI 간소화.

## 🚀 실행 방법

### 1단계: 패키지 설치
```bash
pip install -r requirements.txt
```

### 2단계: 환경 설정 (.env 파일)
프로젝트 폴더에 `.env` 파일을 생성하고 아래 내용을 환경에 맞게 입력합니다:
```ini
KAKAO_API_KEY=발급받은_카카오_REST_API_키
DEFAULT_HOME=집_주소_또는_명칭
DEFAULT_WORK=회사_주소_또는_명칭
DEFAULT_REGION_CITY=경주
DEFAULT_REGION_PROVINCE=경북
DEFAULT_SCOPE=city
```

### 3단계: 앱 실행
```bash
# 윈도우 사용자
start.bat 더블클릭

# 또는 터미널에서 직접 실행
python start.py
```
→ 서버가 구동되며 브라우저에서 `http://localhost:5020` 주소로 앱이 자동 실행됩니다.

## 🔑 카카오 API 키 발급 (무료)

본 앱은 **REST API 키 하나**로 장소 검색과 길찾기를 모두 수행하며 자체 프록시를 통해 CORS 문제를 자동 해결합니다.

1. [Kakao Developers](https://developers.kakao.com) 접속 및 로그인
2. `내 애플리케이션` → `애플리케이션 추가하기`
3. 생성된 앱의 **REST API 키** 복사하여 `.env` 파일에 붙여넣기
4. (선택) 앱 설정 → `카카오내비` 항목이 있다면 활성화하여 정밀한 길찾기 지원 (비활성화 시 직선거리로 자동 대체됨)
   - *로컬 검색 API: 일 300,000건 무료 / 길찾기 API: 일 300건 무료*

## 📋 엑셀 파일 규칙 및 팁

- **형식 자유**: 엑셀 열의 순서나 이름이 정해져 있지 않습니다. 파일을 불러온 뒤 장소명이 있는 열을 드롭다운에서 선택만 하면 됩니다.
- **복잡한 양식 지원**: 교육청 공문 등 상단에 결재란이나 빈칸이 많은 엑셀도 앱이 스스로 첫 번째 데이터 행(숫자 1이 적힌 행)을 찾아냅니다.
- **정확도 향상**: `"강남초등학교"` 보다 `"서울시 강남구 강남초등학교"`가 정확합니다. 설정에서 "지역 접두사 자동 적용"을 활용하세요.

## 🛠 트러블슈팅

| 증상 | 해결 방법 |
|------|-----------|
| `출발 위치를 찾을 수 없습니다` | 지명이 너무 광범위할 수 있습니다. 수동으로 `지역 접두사`를 명시해보세요. |
| 거리는 나오는데 소요시간이 `-`로 뜸 | 길찾기 API 일일 한도(300건) 초과 시 발생합니다. 직선 거리 데이터로 대체됩니다. |
| 포트 충돌 에러가 발생함 | `server.py` 내부의 `PORT = 5020` 값을 다른 번호로 변경하고 재실행하세요. |
| 엑셀 파일이 읽히지 않음 | 파일이 손상되었거나 최신 기능이 들어간 경우 파일 형식을 `.xls` 대신 `.xlsx`로 다시 저장하여 시도해보세요. (앱 내부적으로 `openpyxl`, `calamine`, `xlrd` 순으로 폴백하며 안전하게 읽어옵니다.) |
