# 트러블슈팅 가이드

## 출발 위치를 찾을 수 없습니다

**원인**: 지명이 너무 짧거나 광범위하여 카카오 API에서 유일한 결과를 찾지 못함

**해결 방법**:
- 출발 위치 지역 접두사 추가
  - `화정초등학교` → `경주 화정초등학교`
  - `황성공원` → `경주 황성공원`
- 더 구체적인 주소 입력
  - `경상북도 경주시 황성동 1-1`

## 장소 미발견 (목적지)

**원인**: 동일한 이름의 장소가 전국에 다수 존재

**해결 방법**:
- 지역 접두사로 특정 지역으로 좁힘
  - `강남초등학교` → `경주 강남초등학교`

## 거리는 나오는데 소요시간이 `-`

**원인**: 길찾기 API 무료 쿼터(300건/일) 초과

**해결 방법**:
- 다음 날 재시도
- 직선거리로 대체 확인 (비고란에 "직선거리" 표시됨)

## `Session state does not function` 경고

**원인**: `python app.py`로 실행함

**해결 방법**:
- 반드시 `streamlit run app.py` 로 실행

## HTTP 403 - `disabled OPEN_MAP_AND_LOCAL service`

**원인**: 카카오 개발자 센터에서 해당 앱의 **카카오맵 API** 권한이 비활성화됨

**해결 방법 (현재 콘솔 기준)**:
1. https://developers.kakao.com/console/app 접속 → 해당 앱 선택
2. 좌측 메뉴에서 **[카카오맵]** (또는 `[제품 설정] > [카카오맵]`)으로 이동
3. **[사용 설정]** (또는 `[활성화 설정]`) 상태를 **[ON]**으로 변경

**추가 기능 신청이 필요한 경우**:
- 해당 오너 계정으로 이미 카카오맵 API를 ON으로 켠 다른 앱이 있다면, 새 앱에서는 바로 켤 수 없습니다.
- 이 경우 좌측 메뉴의 **[앱] > [추가 기능 신청]**으로 이동해 심사를 거쳐 권한을 획득해야 합니다.

**카카오내비(길찾기) 안내**:
- 현재 콘솔에는 **카카오내비를 따로 ON/OFF하는 활성화 버튼이 없습니다**.
- 별도의 스위치 활성화 없이, REST API 키를 그대로 사용하거나 `https://map.kakao.com/link/to/` 형태의 URL로 웹 길찾기를 구현할 수 있습니다.

## 지도 안 보임 / 깜빡임

**원인**: `streamlit-folium` 미설치 또는 `st_folium` interaction으로 인한 rerun

**해결 방법**:
- `pip install folium streamlit-folium` 설치 후 재시작
- 최신 버전에서는 지도 interaction이 rerun을 유발하지 않도록 `returned_objects=[]` 처리됨

## 장소 오매칭 (검색 결과가 다른 동명 장소)

**원인**: 지역 접두사 없이 짧은 이름으로 검색하면 전국에 같은 이름의 장소가 검색됨

**해결 방법**:
- 사이드바의 **장소 유사도 임계점** 슬라이더를 확인
  - 0.3~0.5: 보통. 지역 접두사가 있으면 정확히 매칭
  - 0.7 이상: 매우 엄격. 철자가 정확히 일치해야 함
- 접두사를 붙여 검색하세요 (예: `경주 황성공원`)

## 탭 4 — 경유지 비교 (A→X→B) 시 API 쿼터

**원인**: 경유지 X 후보 1곳마다 A→X, X→B 2회 호출 + A→B 직행 1회 = 후보 수×2+1회 소모

**해결 방법**:
- 후보지를 10개 이내로 제한하면 21회 소모 (300건 한도 내 여유)
- 길찾기 API 오류 발생 시 직선거리로 자동 대체되며, 이 경우 API를 소모하지 않음

## 탭 3 — 중간지점 탐색 시 API 쿼터 절약

**원인**: 후보지가 많으면 길찾기 API 호출이 급증 (참여자 수 × 후보지 수)

**해결 방법**:
- **상위 N개 후보에 대해 실제 길찾기 수행** 값을 낮게 설정 (기본 5)
  - 직선거리로 먼저 총 이동시간이 짧은 후보를 빠르게 추린 뒤, 그 중 N개만 실제 API 호출
  - 5~10개 정도만 해도 실제 최적 지점과 거의 동일한 결과를 얻을 수 있습니다
