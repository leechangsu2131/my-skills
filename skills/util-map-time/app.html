스마트 경로 조회 카카오맵 기반

최초 설정 (1회):
1. developers.kakao.com 로그인 → 내 애플리케이션 → 앱 추가 → REST API 키 복사
2. 이 폴더에 .env 파일 생성: KAKAO_API_KEY=복사한키
3. 터미널에서 python server.py 실행
4. 브라우저에서 http://localhost:5020 접속 (서버가 API 키를 .env에서 읽고 프록시 처리)
✅ 프록시 서버 사용 시 Web 도메인 등록 불필요 (CORS + 인증 자동 처리)
검색 범위 .env 기본 지역을 불러오는 중...
