# 📍 스마트 경로 조회 앱 v3

카카오맵 기반 3-in-1 경로 분석 Streamlit 앱

---

## 🚀 실행 방법

```bash
pip install -r requirements.txt
streamlit run app.py
```

---

## 📑 기능 3가지 (탭으로 구성)

### 탭 1 — 🚗 단일 출발 → 여러 장소
- 내 위치를 입력하면 엑셀의 장소 목록까지 거리·소요시간 일괄 계산
- 결과 테이블 (거리 기준 컬러 강조) + Folium 지도 시각화

### 탭 2 — 🔀 여러 출발 → 여러 도착 (매트릭스)
- 여러 출발지 × 여러 목적지의 전체 경로 표 생성
- 소요시간·거리 매트릭스 → 엑셀 다운로드

### 탭 3 — 📍 최적 중간지점 탐색
- 여러 사람 위치 입력 → 총 이동시간이 가장 적은 중간지점 탐색
- **A안**: 엑셀에 저장된 장소들 중에서 선택
- **B안**: 위경도 격자 탐색으로 수학적 최적점 계산
- **A+B**: 둘 다 사용

---

## 🔑 API 키 발급

1. [카카오 개발자 센터](https://developers.kakao.com) 접속
2. 내 애플리케이션 → 앱 추가 → **REST API 키** 복사
3. (길찾기 사용 시) 카카오내비 활성화 필요

```
# .env 파일 생성 시 (선택, 매번 입력 생략 가능)
KAKAO_API_KEY=your_rest_api_key_here
```

### 무료 한도
| API | 한도 |
|-----|------|
| 키워드 검색 | 300,000건/일 |
| 길찾기 | 300건/일 |

---

## 💡 탭 3 중간지점 탐색 — API 절약 전략

길찾기 API 한도(300건/일)를 아끼기 위해 **2단계 필터링** 사용:

1. **직선거리**로 전체 후보 정렬 (API 호출 없음)
2. 상위 N개 후보만 **실제 길찾기 API** 호출

→ 후보 100개 중 상위 5개만 계산 시: 참여자 4명 × 5 = **20건** 소비

## 🛠️ 트러블슈팅

| 문제 | 해결 |
|------|------|
| 장소 미발견 | 지역 접두사 추가 (예: `경주 건천초등학교`) |
| 소요시간 모두 `-` | 카카오내비 API 활성화 필요 (사이드바 테스트 버튼으로 확인) |
| 지도 안 보임 | `pip install folium streamlit-folium` |
| `streamlit: command not found` | `pip install streamlit` 후 재시도 |
