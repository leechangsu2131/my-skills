📄 간지 템플릿 HWPX 만들기

스크립트가 인쇄 전에 이 파일의 플레이스홀더를 자동으로 교체합니다.
한 번만 만들어 두면 됩니다.

① 한글에서 새 문서 열기

파일 → 새 문서 (Ctrl+N)

② 아래 내용을 입력 (폰트 크게!)

{{학년}}학년 {{반}}반
총 {{학생수}}명
중괄호 두 개 {{ }} 안의 텍스트가 실제 값으로 자동 교체됩니다.
폰트는 36~48pt 정도로 크게 설정하면 프린터 앞에서 한눈에 보입니다.

③ 사용 가능한 플레이스홀더

입력할 텍스트교체되는 값예시 결과
{{학년}}학년 숫자3
{{반}}반 숫자2
{{학생수}}해당 반 학생수17

예시: {{학년}}학년 {{반}}반 → 3학년 2반

④ HWPX로 저장

파일 → 다른 이름으로 저장 → 파일 형식: HWPX (*.hwpx) 선택
파일명: 간지_템플릿.hwpx

⑤ 스크립트 설정

batch_print_v2.py 상단의
SEPARATOR_TEMPLATE = r"C:\...\간지_템플릿.hwpx"
를 실제 저장 경로로 수정

최종 출력 결과

출력 순서내용매수
1🟨 간지: 3학년 1반 · 17명1장
2안내장17장
3🟨 간지: 3학년 2반 · 18명1장
4안내장18장
………
간지를 색지 트레이(트레이2)에서 나오도록 설정하면 더 직관적입니다.
프린터 속성 → 용지 소스에서 트레이를 지정하거나, 간지 문서 자체에서 색지 트레이를 설정하세요.
